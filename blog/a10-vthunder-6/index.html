Thunder® Application Delivery Controller (ADC)

Thunder® 应用交付控制器 (ADC)

应用交付与负载均衡

Thunder ADC 的优势

高性能的高级负载均衡解决方案，使您的应用程序具备高可用性、加速性能和安全性

  • 增强的应用可用性

    确保跨多个数据中心和云高效且可靠地交付应用 (sysin)。最大限度减少网络延迟和停机时间，提升终端用户体验。

  • 全面的应用安全性

    通过高级 SSL/TLS 卸载、单点登录 (SSO)、DDoS 保护 和 Web 应用防火墙 (WAF) 增强应用安全性。

  • 完整的应用可见性

    集成 A10 Control，获得每个应用的深度可见性和全面控制，确保在本地数据中心、公有云、私有云和混合云中安全交付应用。

主要功能

Key Features

  • 高级服务器负载均衡

    通过全代理 L4-7 负载均衡，实现灵活的流量控制、可定制的服务健康检查和 aFleX® 脚本。

  • 多租户软件

    支持强隔离或高密度多租户解决方案，具备基于角色的访问控制 (RBAC) 和可自定义策略，实现设备整合。

  • 任意云部署

    支持在硬件、虚拟机、云、裸机和容器中部署 (sysin)，并通过 FlexPool 实现多云部署中的许可证灵活性。

  • 应用性能加速

    通过缓存和 TCP 优化提升用户体验，加速内容传输，并支持现代 ECC 密码的 TLS/SSL 卸载。

  • Web 和 DNS 保护

    通过集成安全功能（如单点登录、CAPTCHA、Web 和 DNS 防火墙以及 DDoS 保护），保障服务安全并满足合规要求。

  • 按应用分析

    集成 A10 Control，实时洞察用户体验、流量特征和健康检查，主动监控性能。

  • aXAPI® 基于 REST 的可编程性

    实现与多种 DevOps、自动化管理工具的轻松集成，具备 100% API 覆盖率。

  • 全局服务器负载均衡 (GSLB)

    扩展全球负载均衡，实现多云环境下的全球业务连续性，加速本地化服务器响应。

DevOps 集成与自动化

网络自动化部署，提升速度、灵活性和一致性。

  • DevOps 工具

    通过 Terraform 和 Ansible 等自动化工具集成至 CI/CD 流水线。

  • 自动服务发现

    在 Kubernetes 环境中，使用 Thunder Kubernetes Connector (TKC) 或第三方工具（如 HashiCorp NIA 与 Consul）自动发现服务。

  • 分析和事件监控

    使用 Prometheus/Grafana 进行集中式网络可见性、事件监控和告警 (sysin)，内置 Prometheus 导出器。

vThunder 简介

vThunder 是 A10 Networks 推出的虚拟化应用交付控制器（ADC），旨在为云环境中的应用程序提供高性能、灵活且易于部署的负载均衡和安全服务。

🔧 vThunder 的主要功能

  • 高级负载均衡（L4-L7）：支持多层次的流量分发，确保应用程序的高可用性和性能。

  • 应用加速：通过缓存、HTTP 压缩和 WAN 协议优化，提高内容传输速度。

  • 安全功能：提供 SSL/TLS 卸载、DDoS 防护和 Web 应用防火墙（WAF）功能，增强应用安全性。

  • 多租户支持：支持多租户环境，允许在单一实例中配置多个独立的应用交付分区（ADP）。

  • 全局服务器负载均衡（GSLB）：实现跨地域的流量分发 (sysin)，支持灾难恢复和故障转移。

  • 自动化与可编程性：通过 RESTful API（aXAPI）实现与 DevOps 工具的集成，支持自动化部署和管理。

☁️ 部署选项

vThunder 可在多种虚拟化和云平台上部署，包括：

  • 公有云平台：如 Amazon Web Services（AWS）、Microsoft Azure 和 Google Cloud Platform（GCP）。

  • 私有云和虚拟化平台：如 VMware ESXi、KVM 和 Microsoft Hyper-V。

  • 容器环境：支持在容器化平台中部署，满足现代微服务架构的需求。
