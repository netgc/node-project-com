AlmaLinux 10

由社区提供的免费 Linux 操作系统

一个开源、社区拥有和管理、永远免费的企业 Linux 发行版，专注于长期稳定性，提供强大的生产级平台。AlmaLinux OS 与 RHEL 二进制兼容。

自定义 OVF 属性填写说明：

  • 1、root User Configuration

    • 1.1. User root Password -> 必填项，8-128 个字符，建议使用复杂密码，未强制要求
    • 1.2. Enable root SSH login with password -> 可选启用 root 账号 SSH 密码登录，RHEL 9+ 系列默认禁用

  • 2、New Admin User Configuration -> 新建一个管理员账号，必填项

    • 2.1. New User Name
    • 2.2. New User Password

  • 3、Networking Properties -> 选填项，3.1 - 3.4 要么全部填写，要么全部留空

    • 3.1. Network IP Address
    • 3.2. Network Netmask -> 子网掩码，格式如 255.255.255.0
    • 3.3. Default Gateway
    • 3.4.1 DNS 1
    • 3.4.2 DNS 2
    • 3.5. Hostname -> 主机名可以单独填写（无论是否使用固定 IP），建议填写，系统默认为 localhost
    • 3.6. Domain Name -> 选填，格式如 sysin.org，系统默认为 localdomain

RHEL/CentOS 系列发行版部署完毕后不重启系统，可以通过控制台按回车查看主机名的变化，来确认部署成功。

Linux 系统默认密码规则：

  • 字符长度：8 - 128 个字符
  • 要求通过字典检查（Dictionary Check），即不能使用系统定义的已知词/短语或者规律性的字符序列，防止密码太简单或容易被猜到
    • 例外：root 用户允许不通过字典检查，但是会提示 it is too simplistic/systematic
  • 不强制使用复杂密码，即默认不强制同时使用英文大小写字母、数字和特殊字符组合，只使用一种字符也支持
  • 不能包含用户名
  • 以上规则可能因发行版不同有所差异

建议使用复杂密码，例如长度 12 位以上，四种字符（英文大写字母、英文小写字母、数字和特殊字符）至少 4 取 3。

OVF 特性

1. OVF 版本

  • 默认 VM 硬件版本 20（GuestOS ID 最低要求，可升级至最新版）
  • 兼容 ESXi 8.0、Fusion 13.x、Workstation 17.x 及更新版本
  • 启用 CPU、内存热插拔。

2. 系统账号

root 密码部署时设定，可选启用 SSH 密码登录。部署时创建新的管理员账号并设定密码。

3. 分区

标准分区：

NAME FILESYSTEM SIZE TYPE MOUNTPOINT
sda Linux - 80G disk
├─sda1 BIOS Boot - 1G part
├─sda2 xfs - 2G part /boot
└─sda3 xfs - 78G part /

SWAP：/swap.img - 4G [SWAP]

分区扩容请参看：Linux 分区扩容（根分区扩容，SWAP 分区扩容，挂载新分区为目录）

4. 系统配置

  • 格式化网卡命名为 eth0
  • 禁用 SELinux
  • 禁用 Firewalld
  • 安装 EPEL
  • 更换国内镜像：aliyun（如需更换请查看：AlmaLinux yum/dnf repo/mirrors 国内镜像列表及更换方法）
  • 排除 kernel 和 release 更新 (2024 年 5 月更新已取消此配置)
  • 开发者工具（groupinstall “Development Tools”）
  • 安装一些必备工具 (sysin)
    vim, wget, net-tools, bind-utils, htop, lrzsz, lnav, nc, lsof, tree, ncdu, dstat, fd, rg, screen, tmux, duf, procs, expect
  • NTP：chrony 默认
  • SNMP：仅安装默认配置
  • VMware Tools：open-vm-tools 12.5.0
  • Zsh 作为默认 Shell，配置为当前最新版
    2023-11-25 之后发布的版本默认启用 zsh-autosuggestions
    参看：Linux 全局安装配置 Zsh + oh-my-zsh
  • 重新生成 SSH Host Keys（2023 年 11 月开始成为默认配置）

适用的 VMware 软件下载

建议在以下版本的 VMware 软件中运行（Linux OVF 无需本站定制版可以正常运行，macOS 虚拟化如果不是 Mac 必须使用定制版才能运行，Windows OVF 需要定制版才能启用完整功能）：

  • VMware vSphere：
    • VMware ESXi 9 or with driver & vCenter Server 9 & VCF Operations 9
    • VMware ESXi 8 or with driver & vCenter Server 8
    • VMware ESXi 7 or with driver & vCenter Server 7
  • macOS：VMware Fusion
  • Linux：VMware Workstation for Linux
  • Windows：VMware Workstation for Windows

OVF 版本兼容性和部署方式

默认 VM 硬件版本 20（GuestOS ID 最低要求，可升级至最新版）；兼容 ESXi 8.0、Fusion 13.x、Workstation 17.x 及更新版本。

✅ 支持通过以下客户端部署：

  • VMware Fusion for Mac：13 及更新版本（推荐版本 13）
  • VMware Workstation for Windows & Linux：17 及更新版本（推荐版本 17）
  • VMware vSphere（vSphere Client）：8.0、9.0 及更新版本（推荐 8.0U3 及以上）
  • ESXi Host Client：内置于 ESXi 8.0、9.0 及更新版本（推荐版本 2.12.1 及以上）

已经弃用的客户端如 vSphere Web Cleint (Flash)，以及上述客户端旧版不建议使用。

✅ 客户端系统和软件要求：

  • 支持的客户端操作系统

    • macOS：推荐 macOS Golden Gate、macOS Tahoe、macOS Sequoia
    • Windows 32-bit (x86) and 64-bit (x64)：推荐 Windows 11、Windows Server 2022、Windows Server 2025
    • Linux：兼容主流 Linux 发行版，参看：Linux 产品链接汇总

  • 支持以下浏览器版本【下载】

    • Google Chrome 89 or later
    • Mozilla Firefox 80 or later
    • Apple Safari 9.0 or later (仅限 Host Client)
