由社区提供的免费 Linux 操作系统

一个开源、社区拥有和管理、永远免费的企业 Linux 发行版，专注于长期稳定性，提供强大的生产级平台 (sysin)。AlmaLinux OS 与 RHEL 二进制兼容。

注：既 Redhat “闭源事件” 之后，AlmaLinux OS 基金会董事会决定放弃与 RHEL 1:1 的目标。AlmaLinux 操作系统的目标是与 RHEL 二进制兼容。

AlmaLinux OS 9.8 “Olive Jaguar”

AlmaLinux 9.8（内核 5.14.0-687.5.3.el9_8）引入了新的编译器工具集、更新的模块流以及增强的安全性。本次发布新增 Python 3.14 软件包，带来了新的 MariaDB、PostgreSQL 与 Ruby 模块流，并提供更新后的 Node.js 24 模块流。容器与虚拟化支持方面，更新至最新版本的 Podman、Buildah、libvirt、QEMU-KVM 与 skopeo。安全性方面 (sysin)，则更新了 OpenSSL、OpenSSH、GnuTLS、SELinux 策略以及 crypto-policies。

AlmaLinux 9.8 还提前集成了一个经 ALESCo 批准、尚未进入上游的内核回移修复（kernel backport）：修复 systemd 与 ps 在任务清理期间 CPU 占用异常过高的问题。Alma 最初已将 该修复 提交至 CentOS Stream 9，但其合并被推迟到至少 RHEL 9.9，因此 ALESCo 投票决定直接在 9.8 中加入。如果你此前遇到任务清理期间 CPU 飙升的问题，现在即可修复，而无需再等待一个季度。

AlmaLinux 9 发布公告

AlmaLinux 9 现已推出

你好社区！AlmaLinux OS 基金会自豪地宣布 AlmaLinux OS 9.0 正式发布。AlmaLinux 9 支持以下 4 种架构，与上游完全对等：

  • Intle/AMD (x86_64)
  • ARM64 (aarch64)
  • IBM PowerPC (ppc64le)
  • IBM Z (s390x)

发行说明和更多信息

AlmaLinux OS 9 基于上游内核版本 5.14，包含围绕云和容器开发的增强功能以及对 Web 控制台（驾驶舱）的改进。此版本还增强了安全性和合规性，包括额外的安全配置文件、大大改进的 SELinux 性能和用户身份验证日志。其他各种更新包括 Python 3.9、GCC 11 和最新版本的 LLVM、Rust 和 Go 编译器，以使应用程序的现代化更快、更容易 (sysin)。您可以查看 发行说明 了解更多。

关于 AlmaLinux 操作系统

AlmaLinux OS 是一个开源的、社区驱动的 Linux 操作系统，它填补了 CentOS Linux 稳定版本停产留下的空白 (sysin)。AlmaLinux OS 是 RHEL® 的 1:1 二进制兼容分支。由社区引导和建设。

作为一个独立的、完全免费的操作系统，AlmaLinux OS 享有 CloudLinux Inc 每年 100 万美元的赞助和其他赞助商的支持。正在进行的开发工作由社区成员管理。

AlmaLinux OS 基金会是一个 501©(6) 非营利组织，旨在为 AlmaLinux OS 社区带来利益。
