Xcode 13 新增了强大的团队开发功能，非常适合与 Xcode Cloud 以及 GitHub、Bitbucket 和 GitLab 协作功能搭配使用。直接在 Xcode 中发起、审核、评注和合并拉取请求 (sysin)。直接在代码内查看团队成员的注释。快速比较代码文件的任何两个版本。

发行说明

  • Xcode 13.4 includes SDKs for iOS 15.5, iPadOS 15.5, tvOS 15.4, watchOS 8.5, and macOS Monterey 12.3. The Xcode 13.4 release supports on-device debugging for iOS 15.5, iPadOS 15.5, tvOS 15.4, watchOS 8.5, and later. Xcode 13.4 requires a Mac running macOS Monterey 12.3 or later.

    Released: May 16, 2022, Build 13F17a, Release Notes

  • Xcode 13.3 includes SDKs for iOS 15.4, iPadOS 15.4, tvOS 15.4, watchOS 8.5, and macOS Monterey 12.3. The Xcode 13.3 release supports on-device debugging for iOS 15.4, iPadOS 15.4, tvOS 15.4, watchOS 8.5 and later. Xcode 13.3 requires a Mac running macOS Monterey 12 or later.

    Released: March 14, 2022, Build 13E113, Release Notes

  • Xcode 13.2 includes everything you need to create amazing apps for all Apple platforms. It includes the SDKs for iOS 15, iPadOS 15, watchOS 8, tvOS 15, and macOS Monterey.

    Released: December 13, 2021, Build: 13C90, Release Notes

  • Xcode 13.1 includes SDKs for iOS 15, iPadOS 15, tvOS 15, watchOS 8, and macOS Monterey 12. The Xcode 13.1 release supports on-device debugging for iOS 9 and later, tvOS 9 and later, and watchOS 2 and later. Xcode 13.1 requires a Mac running macOS 11.3 or later. Release Notes

  • Xcode 13 includes Swift 5.5 and SDKs for iOS 15, iPadOS 15, tvOS 15, and watchOS 8.

    Xcode 13 release date: September 20, 2021，Read Xcode 13 Release Notes.

概述

轻松设置

利用完整的工作流程，直接在 Xcode 内管理拉取请求。创建新请求，查看可供审核的拉取请求队列，以及快速查看、构建和测试在本地或由 Xcode Cloud 生成的结果。

内嵌团队注释

团队成员在审核期间为代码添加的注释与审核者的姓名和头像一起内嵌显示在代码编辑器中。

快速比较

在任何编辑器中，跳转到任何两个源代码版本的对比视图，同时保留当前的编辑情境。

云端签名

App 使用 Apple 托管服务进行代码签名，该服务会帮助管理您的所有证书，从而使 App Store 提交流程变得更加方便可靠。只需使用您的 Apple ID 登录 Xcode，系统就会基于您的会员资格职能和权限对您的 Mac 进行开发与部署配置。

底栏

始终显示的底栏中包含实用的信息，例如行与列，让您能够快速比较不同的代码版本。

Vim 模式

代码编辑器中直接支持 Vim 用户所熟悉的许多常用组合键和编辑模式，同时在新的底栏中显示模式指示器。

CarPlay 车载模拟器

通过这个适用于 Mac 的新模拟器，您可以全面控制屏幕尺寸、分辨率和变量输入方法 (sysin)，方便您测试许多不同车载平台上的 CarPlay 车载体验。

即时崩溃报告和反馈

只需几分钟时间，来自 TestFlight 用户的崩溃报告就会出现在 Xcode Organizer 中，同时还有用户反馈，因此您的测试员可以向您描述他们在遭遇崩溃时发生的确切情况。崩溃日志会内嵌显示，您只需点按一下，就能跳转到相关的代码。

自定文档

直接通过源代码的文档注释为您的 Swift 框架和软件包构建文档，然后在 Xcode 快速帮助和专用文档查看器中查看。通过添加扩展文件、文章和教程 (全部以 Markdown 语言编写)，扩充这些注释，并选择将编译的 DocC 归档分享给其他开发者或托管在您的网站上。

Xcode Cloud Beta 版

Xcode Cloud 是专为 Apple 开发者设计的 Xcode 内置持续集成和交付服务。要获取 beta 版，请提交请求，我们会在您的账户可以启用相关功能时给您发送电子邮件。
