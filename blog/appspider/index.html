AppSpider

没有任何应用程序未经测试，没有未知风险

当今的安全团队负责保护数百个应用程序，这些应用程序包含复杂的富客户端和 API，需要遵循行业与政府法规，并持续跟进黑客攻击趋势。对他们来说，构建有效的应用安全计划不仅仅是对 Web 应用界面进行爬取，而是要实现对应用的全面覆盖，并利用更复杂的攻击方法来应对现代应用所使用的技术。

应用安全本身很难，但使用应用安全工具不应该如此复杂 (sysin)。应用安全扫描通常有上千种选项，而 Rapid7 的应用安全产品基于多年的实践经验提供了系统默认配置，让你可以将更多精力放在修复漏洞上。

通过 AppSpider，你可以规划、控制和衡量扫描，并在所有应用扫描数据中查看整体趋势，从而跟踪安全状况的改进。最终，AppSpider 帮助你评估并优先处理最高风险区域，进而构建现代化的企业级应用安全计划。

Rapid7 AppSec Solutions - Rapid7 应用安全解决方案

AppSpider 是一款动态应用安全测试（DAST）解决方案，可用于扫描 Web 与移动应用中的漏洞。

AppSpider 的核心技术是 Universal Translator（通用转换器），它能够解析现代 Web 与移动应用所使用的新技术（如 AJAX、HTML5 和 JSON），同时也能爬取传统应用。

AppSpider 可部署在本地、托管环境或作为托管服务使用 (sysin)，能够帮助你有效管理应用安全计划，提供深入分析、全面覆盖以及复杂的攻击方法。

AppSpider 的优势包括：

  • 广泛覆盖
  • 高级认证
  • 集成能力
  • 交互式报告
  • 分布式与可扩展架构
  • 集中化控制
  • 持续站点监控
  • 对基于 OpenAPI 规范（前称 Swagger）构建的 API 进行端到端测试

新增功能

应用程序安全 AppSpider

AppSpider 版本 7.5.029

软件发布日期：2026 年 9 月 9 日 | 发布说明发布日期：2026 年 9 月 9 日

🆕 新增功能：

  • AI 漏洞验证器：扩展模块支持 - 集成 AWS Bedrock LLM 验证功能，用于验证 LDAP 注入发现结果。在现有盲 SQL、盲 NoSQL、SQL 注入和远程文件包含（RFI）验证模型的基础上，进一步扩展 AI 漏洞验证器套件，以自动评估并过滤误报。
  • AI 验证器误报透明度日志记录 - 启用 AI 漏洞验证器后，自动生成评估日志/报告文件 (sysin)，记录每一项被标记为误报并从扫描结果中排除的发现项。
  • ALF v2.1.1 基础设施升级 - 将应用层框架（ALF）升级至 v2.1.1，新增原生一次性密码（OTP）支持，无需手动设置 Hook；同时扩展 ALF 日志可见性，并优化默认配置参数。
  • 技术检测证据上下文 - 技术检测漏洞发现结果现在会包含详细的“Detection Method”（检测方法）和“Match Details”（匹配详情）遥测信息，这些信息由 R7Crawler 直接转发。

✨ 改进：

  • AppSec 扫描引擎
    • 动态内存管理 - 优化扫描期间的内存缓存机制，解决内存分配问题，并防止因内存不足导致扫描失败。
    • ASP.NET Core 配置泄露检测 - 升级可预测资源位置模块，用于识别位于 Web 根目录中、可能暴露的 ASP.NET Core / .NET Core 配置文件，这些文件可能泄露敏感凭据和环境机密。
    • 会话强度误报 - 修正模块测试逻辑，使其忽略非授权令牌，从而消除会话强度相关的误报发现。
    • FrontPage/SharePoint 清理 - 修复影响非易受攻击 Microsoft SharePoint 环境的误报触发问题。
    • 按 URL 失败跟踪 - 通过引入按 URL 的失败跟踪机制以及可配置控制项 (sysin)，增强连续错误处理能力，使反复失败的 URL 可以被阻止，从而避免其导致引擎运行停滞。
    • 运行时安全升级 - 将已安装的 .NET 8 运行时组件从 8.0.29 更新至 8.0.30。
    • 攻击数据定义 - 更新分析配置文件，以检测近期的 Drupal 版本，并解决元标签评估过程中的边缘情况。
  • R7 Crawler
    • 浏览器与驱动升级 - 将 R7Crawler 升级至 Chromium 151.0.7922.34，并将 Selenium ChromeDriver 升级至 152.0.7977.64。
    • 部分页面加载支持 - 对于等待页面完全加载时发生超时、但已达到 DOMContentLoaded 状态的请求，将其记录并作为有效的部分加载状态进行处理。
    • 链接采集与覆盖范围 - 优化对已发现 href 目标的处理，以提高基于 Chromium 的扫描过程中的整体爬取深度。
    • 机器人检测规避 - 优化 navigator.webdriver 的隐藏控制，以增强在受保护目标上的机器人检测规避能力。
    • 会话检查逻辑 - 对于加载失败的页面，自动抑制 isLoggedIn 检测例程。

🐞 修复：

  • AppSec 扫描引擎
    • 技术检测验证扫描 - 通过为技术检测模块增加完整的验证扫描支持，修复验证扫描期间行为不一致的问题。
