Arista EOS

世界上最先进的网络操作系统

Arista 可扩展操作系统 (EOS®) 是 Arista 用于下一代数据中心和云网络的云网络解决方案的核心。使用 Arista EOS 构建的云架构可扩展到数十万个计算和存储节点，并具有大规模工作的管理和配置功能 (sysin)。通过其可编程性，EOS 支持一系列软件应用程序，可提供工作流程自动化、高可用性、前所未有的网络可视性和分析以及与虚拟化、管理、自动化和编排服务的各种第三方应用程序的快速集成。

Arista EOS 是一个完全可编程且高度模块化的基于 Linux 的网络操作系统，使用熟悉的行业标准 CLI，并在 Arista 交换系列中运行单个二进制软件映像。EOS 专为实现弹性和可编程性而设计，具有独特的多进程状态共享架构，可将状态信息和数据包转发与协议处理和应用逻辑完全分开。

CloudEOS 简介 - 云网络基础设施即代码

CloudEOS™ 是 Arista 的多云和云原生网络解决方案，支持自主作，可为任何云提供企业级、高度安全和可靠的网络体验。作为 Arista EOS® 和 CloudVision® 产品系列的一部分，它为企业边缘、WAN、园区、数据中心以及多个公有云和私有云提供一致的分段、自动化、遥测、配置和故障排除。

为了提供可扩展的自动化网络体验，CloudEOS 与 Arista CloudVision 集成，以简化运营商互连和管理多云、云原生和本地企业网络的体验 (sysin)。CloudEOS 和 CloudVision 利用网络范围的工作负载编排和工作流自动化方法，以及先进的网络遥测和基于标准的可编程性，为多云网络提供了一种无缝且通用的方法。

CloudEOS 与通用云网络设计一起部署，提供了构建多云连接所需的重要缺失元素，并在整个企业环境中实现一致的隔离。它提供一致的高性能虚拟机和基于容器的 EOS 软件实例，通过声明式云配置工具链（如 Terraform、Ansible 和其他用于部署整个应用程序堆栈的常用 CloudOps 和 DevOps 解决方案）简化网络作。

借助 CloudEOS，客户可以充分利用他们的多云和云原生投资，而不会影响他们期望从 Arista 获得的网络可靠性、安全性和可预测性。

Arista CloudEOS 路由器 - 关键功能摘要：

声明式云配置 – 使用流行的 Terraform 应用程序，平台工程团队可以在多个公有云提供商中建立 Virtual Private Cloud 实例，每个 VPC 只需一行额外的代码 (sysin)。Terraform 将自动部署 Arista CloudEOS 叶路由器或高可用性路由器对，并为每个连接的 VPC 建立与 CNPS 的安全连接。

多云可访问性和扩展性 - 任何资源都可以在公有云中弹性扩展/缩减，其实例化和实时寻址在整个 CNPS 细分市场中保持一致地维护，甚至在 Kubernetes 等高速环境中的云提供商之间也是如此。

弹性扩展和使用 ——对于分段控制点、边缘传输路由器和云主干节点等云交付功能，该架构旨在支持在公有云提供商中或通过公有云提供商采购这些节点，并根据即用即付模式中的实际消耗量计费。

增强的可见性和分析 - CNPS 中的每个网络节点都将遥测数据流式传输回 Arista CloudVision，后者可以部署在 VPC 中的公有云中或本地。这使得网络状态的数字副本可用于分析或作为监督式机器学习模型的训练数据。

产品亮点

✅ 云级路由

  • 多云：虚拟机路由——针对公有云和私有云进行了优化，并可在主要公有云市场（包括 Amazon AWS、Google Cloud Platform 和 Microsoft Azure）中使用。
  • 云原生：容器版本——将 CloudEOS 扩展到 Kubernetes 集群，实现自动配置、一致路由、改进的可见性和更好的故障排除。
  • 可传递路由：通过标准化的连接模式将多个虚拟私有云（VPC）互连，并在所有 Arista 网络平台上使用相同的经过验证的 Arista EOS 软件。
  • UCN：通用云网络（Universal Cloud Network, UCN）——在公有云内部和跨云的基于标准的网络设计；通过基于 BGP 的三层 EVPN 或可靠的叶脊（Leaf-and-Spine）路由拓扑 (sysin)，实现叶脊和端到端连接。
  • 站点到站点：使用 IPsec VPN 加密和动态路径选择，实现公有云、数据中心和校园站点之间的高速 WAN 互连。

✅ 关键功能和特性

  • 云网络私有分段（CNPS）：基于 VXLAN 和 IPsec 的虚拟专用网络（VPN），跨越云区域和提供商，实现安全、全球一致的分段模型。
  • 动态路径选择（DPS）：针对云边缘用例，结合带内路径遥测（In-band Path Telemetry），在多种 WAN 分段上提供可靠连接。
  • 网络地址转换（NAT）：在任何 VPC 中提供 IP 地址灵活性。
  • 遥测流：基于开源 gNMI、gRPC 和 OpenConfig 标准，大幅提升网络可见性和故障排除能力。

✅ 自治云操作

  • 弹性：通过公有云市场和服务目录按需付费（PAYG）。
  • 全包：包括 CloudVision 与 Terraform 集成、所有 EOS 路由和遥测功能以及 A-care 软件支持。
  • 一致的运营模式：Arista EOS 和 CloudVision 结合 DevOps 和 CloudOps 工具链集成（如 Terraform）。
  • 开放可编程性：通过 JSON API（eAPI）或 EOS SDK 进行编程，支持 Python、Go、Ansible、NetConf 和 OpenConfig。

✅ 性能和可靠性

  • 云高可用性（HA）：利用双向转发检测（BFD）和多路径路由（ECMP），实现快速恢复和持续运行。
  • 高性能数据平面（DPDK/SR-IOV）：提高吞吐量，同时降低延迟、抖动和 CPU 利用率 (sysin)，在任何云或硬件平台上实现最佳性能。
  • 最新云架构：利用 Microsoft Azure Accelerated Networking 和 Amazon AWS Enhanced Networking，在公有云实例中实现高效的资源利用。
