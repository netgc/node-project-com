Arista EOS

世界上最先进的网络操作系统

Arista 可扩展操作系统 (EOS®) 是 Arista 用于下一代数据中心和云网络的云网络解决方案的核心。使用 Arista EOS 构建的云架构可扩展到数十万个计算和存储节点，并具有大规模工作的管理和配置功能 (sysin)。通过其可编程性，EOS 支持一系列软件应用程序，可提供工作流程自动化、高可用性、前所未有的网络可视性和分析以及与虚拟化、管理、自动化和编排服务的各种第三方应用程序的快速集成。

Arista EOS 是一个完全可编程且高度模块化的基于 Linux 的网络操作系统，使用熟悉的行业标准 CLI，并在 Arista 交换系列中运行单个二进制软件映像。EOS 专为实现弹性和可编程性而设计，具有独特的多进程状态共享架构，可将状态信息和数据包转发与协议处理和应用逻辑完全分开。

Figure: Arista EOS Architecture

Arista vEOS（Virtual EOS）简介

Arista vEOS（Virtual Extensible Operating System） 是 Arista Networks 提供的虚拟化网络操作系统，旨在将 Arista EOS（Extensible Operating System）的所有功能带入虚拟化平台中。它允许用户在虚拟机（VM）环境中运行完整的 EOS 系统，无需物理硬件交换机。

vEOS 核心特点

✅ 1. 完整的 EOS 功能

  • 一致的 CLI：与物理 Arista 交换机相同的命令行界面（CLI），无需重新学习。
  • 高级网络协议：支持 BGP、OSPF、MPLS、EVPN、VXLAN 等网络协议 (sysin)。
  • 灵活的自动化：完全兼容 eAPI（Extensible API）、CloudVision 和 Ansible、Terraform 等自动化工具。

✅ 2. 多虚拟化平台支持

  • VMware vSphere：标准的 vEOS 虚拟机可以运行在 vSphere 环境中，适配 NSX。
  • KVM（Kernel-based Virtual Machine）：兼容开源虚拟化平台（如 Proxmox、OpenStack）。
  • Hyper-V：支持 Windows Server 的虚拟化环境。
  • 其他平台：支持 AWS、Azure 等公有云平台中的虚拟机。

✅ 3. 易于部署

  • 快速启动：基于虚拟机映像（.ova、.qcow2、.vmdk），支持即插即用。
  • 动态配置：通过 eAPI 或 CloudVision 快速推送配置。
  • 映像小巧：可在资源有限的虚拟化平台中运行。

✅ 4. 多用途应用

  • 测试和开发：作为物理 Arista 交换机的模拟器，适合 CLI 和协议测试。
  • 虚拟化数据中心：作为虚拟路由器或虚拟交换机，与物理交换机互联。
  • 混合云和多云互联：在公有云或私有云中实现虚拟路由器 (sysin)。

vEOS 架构解析

✅ 1. 组成结构

  • vEOS 映像文件：以 .ova（VMware）、.qcow2（KVM）或 .vmdk（Hyper-V）格式提供。
  • vEOS-lab：轻量版 vEOS，专为实验和测试环境设计，资源占用更低。
  • SysDB 和 Agent：保持 Arista EOS 模块化设计，每个服务独立运行。
  • eAPI（Extensible API）：提供 JSON-RPC 接口，便于编程集成。

✅ 2. vEOS 网络接口

  • 标准虚拟网卡：支持 VMware VMXNET3、Virtio、Hyper-V 虚拟网卡。
  • 支持 VXLAN/EVPN：可以充当虚拟数据中心的网关或虚拟交换机。
  • 灵活的接口配置：可通过 vSphere 或 KVM 为 vEOS 分配多个虚拟接口。

vEOS 典型部署场景

✅ 1. 虚拟化数据中心

  • 在 VMware vSphere 或 KVM 环境中运行 vEOS 作为虚拟路由器。
  • 结合 Arista 物理交换机，实现数据中心的虚拟化扩展。

✅ 2. DevOps 和测试

  • 在本地虚拟化平台（如 VMware Workstation、Proxmox）中运行 vEOS。
  • 测试和模拟路由协议（如 BGP、OSPF、EVPN），进行自动化配置实验。

✅ 3. 云环境互联

  • 在 AWS、Azure 或 Google Cloud 中运行 vEOS 作为虚拟路由器。
  • 结合 CloudVision 实现跨云互联和集中化管理 (sysin)。
