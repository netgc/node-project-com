Burp Suite 简介

Burp Suite 是一套用于 Web 安全测试的高级工具集 —— 将所有功能集成在一个产品中。从基础的拦截代理到先进的 Burp Scanner，使用 Burp Suite，您所需的工具触手可及。

强大的自动化能力让您可以专注于最擅长的工作，而 Burp Suite 则负责处理那些易于实现的检测任务。先进的手动工具能够帮助您识别目标中更加隐蔽的安全盲点。

Burp Suite 由专业研究团队开发，这意味着在每次发布前，最新的研究成果已经融入产品之中。该 Pentesting 工具不仅能提升您的工作效率，还能帮助您掌握最新的攻击向量。

新增功能

Professional / Community 2026.10

2026 年 10 月 12 日

此版本更新新增了对 HTTP Digest 身份验证的支持，改进了通知机制和 BApp 限制，修复了多个错误，并升级了 Burp 浏览器。

🔐 支持 HTTP Digest 身份验证

重新引入了对 HTTP Digest 身份验证的支持，使用户能够更轻松地测试采用这种身份验证方式的应用程序，而无需依赖旧版本的 Burp 或使用变通方案。

🔔 改进通知机制

现在，通知会固定显示在 Burp 的主窗口中，而不再覆盖在对话框上方。如果某个窗口关闭，与其关联的通知会转移到另一个窗口，以确保通知始终可见且易于访问。

🐞 错误修复

修复了以下问题：

  • 现在，点击事件日志（Event Log）中的文档链接时，可以正确打开对应文档。
  • 在 Linux 上，将鼠标悬停在 Inspector 中较大的 __VIEWSTATE 参数上时，不再导致 Burp 卡死或崩溃。
  • 删除问题后，仪表板（Dashboard）扫描任务中的问题计数现在会正确更新。
  • 如果在所有扩展程序加载完成之前更新 Burp，现在 Burp 会保留扩展程序的设置。此前，重启后可能会有部分扩展程序丢失，需要手动重新加载。
  • 包含服务器发送事件（SSE）响应的 HTTP 消息现在可以正确发送到 Organizer (s)。此后添加的项目也会正确编号。
  • 当 Burp 修复损坏的项目时，WebSocket Repeater 选项卡现在会保留其连接数据，因此恢复后的选项卡仍然可以正常使用。
  • 修复了使用 --config-file 加载项目配置时，SOCKS 代理绕过列表可能被静默丢弃的问题。这可能导致原本应绕过代理的流量反而通过代理进行路由。
  • 现在，即使 Repeater 中的响应仍在持续传输，也可以取消相应请求。

已将 Burp 浏览器升级至以下 Chromium 版本：

  • Linux：Chromium 154.0.8037.97
