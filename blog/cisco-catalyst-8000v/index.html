Cisco Catalyst 8000V 边缘软件

云智能路线

使用专为云构建的虚拟路由平台扩展云和应用 WAN。

Cisco® Catalyst® 8000V 边缘软件 (Catalyst 8000V) 是一款虚拟路由器，可在虚拟和云环境中提供全面的 SD-WAN、广域网网关和网络服务功能。Catalyst 8000V 采用广为人知、行业领先的 Cisco IOS® XE 软件网络功能 (sysin)，让企业能够以透明的方式将其广域网扩展到提供商托管云。同样，云提供商自身也可以使用 Catalyst 8000V 为租户或客户提供企业级网络服务。

Cisco Catalyst 8000V：随心所欲访问位于云、数据中心和边缘的混合型应用和多云应用。

特性和优势

Catalyst 8000 边缘平台是一款基于意图的网络 (IBN) 平台，它将思科在软件定义广域网 (SD-WAN) 和安全领域的成果集于一身，旨在实现卓越的可扩展性、灵活性和安全连接性。Catalyst 8000 边缘平台系列经过优化，可凭借更快的 SD-WAN 和路由服务、多层安全保护和边缘智能功能无缝连通 WAN 边缘和云边缘，确保提供更出色的用户体验。

  • 安全的互联体验

    集业界领先安全和网络技术于一身 (sysin)，跨所有层提供统一的 SD-WAN 和安全访问服务边缘 (SASE) 架构

  • 云原生灵活性

    开放且完全可编程，可实现云级别的自动化并支持丰富多样的微服务

  • 以业务为重的恢复能力

    灵活的服务支持和端到端分析，有助于轻松采用 5G 等演进技术

Cisco Catalyst 8000V

借助自动化、可视性与可控性实现优化，畅享安全可靠的多云连接。

Cisco Catalyst™ 8000V Edge Software（Catalyst 8000V）是一款以虚拟机形态运行的云路由器，可在虚拟化本地基础设施和云环境中提供全面的 SD-WAN、WAN 网关以及传统网络路由服务。基于业界领先且广泛使用的 Cisco IOS® XE 网络能力，Catalyst 8000V 使企业能够将其广域网无缝扩展至由服务提供商托管的云环境。托管服务提供商和公有云提供商可以利用 Catalyst 8000V，为其客户和租户提供企业级网络服务。

除了将企业级网络服务与安全能力引入公有云环境外，Cisco Catalyst 8000V 还可作为构建可扩展网络服务的基础组件。当作为网络功能虚拟化（NFV）组件使用时，它能够承担传统上由专用硬件设备完成的角色。通过将这些复杂功能虚拟化，服务提供商可以将多个实例整合到单一服务器上，并在新增客户或网络扩展时轻松实现横向扩展。

Catalyst 8000V 是 Cisco Catalyst 8000 路由器产品组合的一员，基于与物理设备相同、经过验证的 Cisco IOS XE 软件构建。这种一致性使 Catalyst 8000V 能够提供与物理平台一致的丰富功能，包括传统路由能力、SD-WAN、VPN、下一代防火墙、网络地址转换（NAT）、服务质量（QoS）、应用可视化、故障切换、WAN 优化、虚拟路由反射器（vRR）以及语音服务。这一完整的功能集合使企业和云服务提供商能够构建高度安全、优化、可扩展且一致的混合网络，覆盖分支机构、数据中心、托管数据中心以及公有云。

图 1. Cisco Catalyst 8000V 可将 SD-WAN 架构扩展至托管数据中心和公有云

🌐 使用场景

Cisco Catalyst 8000V 可支持丰富的网络路由应用场景：

  • 传统路由
  • 高安全性的 VPN 网关
    • NAT 网关
    • 多协议标签交换（MPLS）
    • 三层（Layer 3）
    • 二层（虚拟机迁移）和三层（IP 迁移）扩展
  • Cisco Catalyst SD-WAN
    • 下一代防火墙（NGFW）
  • 多云互联
  • WAN 优化
  • 语音服务

系统要求

KVM

  • Cisco NFVIS: 4.4.x or later
  • Redhat Enterprise Linux: 9.x, 8.x, 7.x
  • SUSE Linux Enterprise Server: 15.x
  • Ubuntu: 22.04 LTS,16.04 LTS

OpenStack

  • Cisco Virtualized Infrastructure Manager 4.2 (VIM) based on OpenStack Train
  • Redhat OpenStack Platform 16.1 (RHOSP) based on OpenStack Train

VMware

  • VMware ESXi: 9.x, 8.0, 7.0

Cisco Catalyst 8000V Edge Software 或 Cisco Catalyst 8000V 是一种基于软件的虚拟路由器，它将 Cisco 云服务路由器（Cisco CSR1000V）和 Cisco 集成服务虚拟路由器（Cisco ISRv）的功能组合到一个映像中，用于在云和虚拟数据中心中部署。Cisco Catalyst 8000V 支持 NIM 模块，在任何 x86 平台上运行，并且在 ESXi、KVM、NFVIS 等虚拟机监控程序上受支持。您还可以在公共云提供商（如 Amazon Web Services（AWS）、Microsoft Azure 和 Google 云平台（GCP））上部署此产品。

当您在虚拟机上部署 Cisco Catalyst 8000V 时，Cisco IOS XE 软件的功能就像部署在传统的 Cisco 硬件平台上一样。您可以根据 Cisco IOS XE 软件映像配置不同的功能。
