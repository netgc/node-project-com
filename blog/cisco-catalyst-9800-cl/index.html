面向云的思科 Catalyst 9800-CL 无线控制器，既可以部署在私有云（支持 ESXi, KVM, Hyper-V 和 NFVIS on ENCS hypervisors）, 也可以部署在公有云 IaaS 中，已经在 AWS、Azure 和 GCP marketplace 中提供。

Catalyst 9800 系列无线控制器将最佳射频性能与 IOS XE 的优势集于一身，为您提供可靠性和安全性均达到业内顶级水平的无线控制器 (sysin)。您可以将其部署在任意位置，包括您选择的任何云环境！这样一来，您可以在简化操作的同时，节省更多时间和资金。

产品概述

图 1. 兼容的云平台示例

为基于意图的网络（intent-based network）从零开始构建，Cisco Catalyst 9800 系列无线控制器基于 Cisco IOS XE 操作系统，并融合了 Cisco Aironet 接入点的射频优势，为不断发展和扩展的组织打造一流的无线体验。9800 系列基于开放且可编程的架构构建，内置安全功能、流式遥测以及丰富的分析能力。

Cisco Catalyst 9800 系列无线控制器建立在网络卓越性的三大支柱之上——始终在线、安全可靠、随处部署——通过在不妥协的前提下提供最佳无线体验，同时节省时间与成本，从而增强网络能力。

Cisco Catalyst 9800-CL 是面向云环境的新一代企业级无线控制器，支持无缝软件更新，适用于分支机构、中型园区、大型企业以及服务提供商。

Cisco Catalyst 9800-CL 控制器功能丰富、企业级就绪，可支持关键业务运行并提升最终用户体验：

  • 通过热补丁和冷补丁实现高可用性和无缝软件更新，在计划内和计划外事件中保持客户端和服务始终在线（always on）。
  • 使用 Cisco Catalyst 9800-CL 实现对无线环境、设备和用户的安全保护。借助 Cisco 加密流量分析（ETA）和软件定义接入（SD-Access），无线基础设施成为最强的第一道防线。控制器内置运行时防护、镜像签名与完整性验证等安全机制。
  • 实现随处部署（deploy anywhere），让无线连接无处不在。无论是公有云还是私有云，Cisco Catalyst 9800-CL 都能满足组织需求。
  • 基于模块化操作系统构建，9800-CL 提供开放且可编程的 API，实现从 Day-0 到 Day-N 网络运维的自动化 (sysin)。模型驱动的流式遥测可深入洞察网络与客户端健康状况。
  • Cisco 用户定义网络（User Defined Network）是 Cisco DNA Center 提供的一项功能，允许 IT 为终端用户在共享网络中分配专属无线网络分区。用户可以远程且安全地在该网络中部署设备。非常适用于大学宿舍或长期住院场景，该功能在提供设备安全的同时赋予用户控制权，使其可以决定谁能接入其网络。
  • Wi-Fi 6 就绪仪表板是 Cisco DNA Center Assurance 菜单中的新功能。它会扫描网络中所有设备库存，并验证设备、软件和客户端与 Wi-Fi 6 标准的兼容性。升级后，高级无线分析将展示 Wi-Fi 6 部署带来的性能与容量提升。这是一项强大的工具，可帮助团队确定无线网络的升级位置与方式。同时还提供按协议（802.11ac/n/abg）的接入点分布、无线空口效率以及细粒度性能指标。
  • 借助 Cisco 在线软件升级（ISSU），软件更新或升级期间的网络停机成为过去。ISSU 支持在网络运行过程中完成完整镜像升级与更新。软件镜像或补丁会在不中断流量转发的情况下推送到无线控制器。升级过程中，所有接入点与客户端会话均可保持。只需点击一次，网络即可自动升级到最新软件。

🌐 面向私有云的思科 Catalyst 9800-CL

图 2. 面向私有云的思科 Catalyst 9800-CL

关键特性：

  • 支持 VMware ESXi、KVM、Hyper-V 以及 Cisco NFVIS（运行于 ENCS 上）
  • 支持集中式、Cisco FlexConnect、Mesh 以及 Fabric（SD-Access）部署模式
  • 单一部署包支持多种规模与吞吐配置*，满足不同组织需求
    • 小型（低/高吞吐）： 适用于分支机构和小型园区，最多支持 1000 个接入点（AP）和 10,000 个客户端
    • 中型（低/高吞吐）： 适用于中型园区，最多支持 3000 个 AP 和 32,000 个客户端
    • 大型（低/高吞吐）： 适用于大型企业和服务提供商，最多支持 6000 个 AP 和 64,000 个客户端
  • 所有规模模板使用统一部署包，在创建虚拟机（VM）时选择部署规模和吞吐配置
  • 在集中式无线部署中（未启用 SR-IOV 的低吞吐配置），最高支持 2.1 Gbps 吞吐量
  • 在高（增强）吞吐配置下，配合合适的网卡与资源（支持 SR-IOV 的 NIC），在 ESXi 和 KVM 上最高可达 5 Gbps
  • 在虚拟机初始化过程中提供直观的引导向导 (sysin)，用于以推荐参数启动无线控制器
  • 可将 9800-CL 作为虚拟机部署在运行 Cisco NFVIS 的 Cisco 5000 系列企业网络计算系统（ENCS）上，从而优化分支网络

高吞吐配置仅在 ESXi 和 KVM 虚拟化平台上支持。

🌐 面向公有云的思科 Catalyst 9800-CL

图 3. 面向公有云的思科 Catalyst 9800-CL

关键特性：

  • Cisco Catalyst 9800-CL 以基础设施即服务（IaaS）形式提供，可在 Amazon Web Services（AWS）、Google Cloud Platform（GCP）、Microsoft Azure（Azure）市场中获取
  • 支持托管 VPN 部署模式（截至 17.7）：
    • 9800-CL 需部署在虚拟私有云（VPC）中
    • 需从客户站点到 AWS、GCP 或 Azure 建立 VPN 隧道，以实现 Cisco 接入点与 9800-CL 控制器之间的通信
  • 从 17.8 版本起支持通过公网 IP 进行 AP 注册（onboarding）
  • 支持 Cisco FlexConnect 集中认证与本地交换
  • 支持 AWS GovCloud
  • 最多支持 6000 个接入点和 64,000 个客户端
  • 可通过 Cisco 提供的 CloudFormation 模板（推荐）或使用 EC2 控制台手动部署 AWS 无线控制器实例
  • 可通过市场中的引导式流程在 GCP 和 Azure 上部署无线控制器

系统要求

Supported Host Environments for Public and Private Cloud

☁️ Private Cloud

  • VMware: VMware vSphere 6.7, 7.0, 8.0, and 9.0
  • KVM：
    • Linux KVM-based on Red Hat Enterprise Linux 9.2, or latest version
    • Ubuntu 16.04.5 LTS, Ubuntu 18.04.5 LTS, Ubuntu 20.04.5 LTS, or latest version
  • Microsoft Hyper-V: Windows Server 2019, Windows Server 2022, Windows Server 2025
  • NFVIS: ENCS 3.8.1 and 3.9.1

☁️ Publi Cloud

  • AWS: AWS EC2 platform
  • GCP: GCP marketplace
  • Azure: Microsoft Azure
