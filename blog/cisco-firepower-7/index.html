概述

使用 Secure Firewall 预见威胁、及时行动并简化安全

​

由于员工、数据和办公场所遍布各地，企业防火墙必须做好一切准备。Secure Firewall 帮助企业做好计划、确定事件优先顺序、填补安全缺口，并从灾难中恢复，变得更加强大。

  • 与防火墙交互

    三分之一的防火墙规则已经遭到破坏。使用 Cisco AI Assistant for Security 帮助识别和报告策略、加强故障排除能力并自动执行策略生命周期管理任务。

  • 实现卓越的可视性

    重新获得对加密流量和应用环境的可视性和可控性 (sysin)。在具备安全弹性的基础设施上利用数十亿信号，通过 Cisco Talos 提高可视性和检测能力。

  • 大规模提升效率

    Secure Firewall 支持高级集群、高可用性和多实例功能，让您能够为整个团队和混合网络环境提供可扩展性、可靠性和工作效率。

  • 让零信任成为现实

    Secure Firewall 通过网络、微分段和应用安全集成 (sysin)，经济高效地实现零信任状态。自动控制访问，提前预测威胁。

新增功能

Device Manager Features in Version 7.7.x

下面仅列出新增功能的摘要描述，限于篇幅，详细描述请参看官方文档。

平台功能：

  • 安全防火墙 1210CP IEEE 802.3bt 支持（PoE++ 和 Hi-PoE）。
  • AWS、Azure 和 GCP 的实例。
  • 使用基于 ISO 的 cloud-init 种子为 VMware 提供无人值守的威胁防御虚拟配置。

防火墙和 IPS 功能：

  • 内联集的硬件旁路支持。
  • 已弃用：Snort 2。

管理功能：

  • 自定义登录页面。
  • 使用 Google 远程过程调用 (gRPC) 进行自定义流遥测。

性能：

  • 更快的故障转移，实现高可用性威胁防御。
  • 高带宽加密应用程序流量可绕过不必要的入侵检查。
  • 使用 FlexConfig 配置威胁防御从块耗尽自动恢复。
  • 安全防火墙 1200 出口整形器。Secure Firewall 1200 根据接口速度调整传出流量。

故障排除：

  • CPU 分析器包括应用程序识别统计数据。
  • 新的 IP 流量统计。

安全和强化：

  • Threat Defense CLI Basic 用户的有限用户权限。
  • 要求所有 RADIUS 响应中都包含 Message-Authenticator 属性。
