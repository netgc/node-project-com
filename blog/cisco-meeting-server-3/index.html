思科 Meeting Server

人人畅享轻松会议体验

思科 Meeting Server 将本地视频、音频和网络通信解决方案整合到一个设备中，可满足现代工作场所的协作需求。它还能与第三方设备结合使用，打造亲切、愉悦的用户体验 (sysin)。该软件可实现轻松扩展，您只需购买所需的基于用户的多功能多方许可选项即可。

特性

增强的会议体验

无论与会者以何种方式参加会议，Meeting Server 都能为所有人提供顺畅而愉悦的用户体验。

企业级协作

了解 Meeting Server 软件如何以简单而轻松的购买方式，帮助您简化协作，提高工作效率，并实现投资保护。

全面的设备支持

Meeting Server 支持思科协作终端、Jabber 客户端、 Meeting App（本地客户端或通过兼容 WebRTC 的浏览器）和第三方设备 (sysin)，每个人都能以自己习惯的方式加入会议，并获得毫无差别的高质量体验。

  • 阅读 FINRA 案例研究

强大的可扩展性

可轻松扩展的 Meeting Server 能够同时满足小型和大型部署的需求。通过支持用户使用多种平台在一起开会，您可以优化带宽并降低成本。您可以从小型部署起步，并随时根据需要扩大部署规模。

简化的许可方式

基于用户的多功能多方许可模式便于您轻松购买 Meeting Server。您可以根据当前需求购买所需的服务，日后随着组织规模的增长灵活地增购许可证。请详细了解思科提供的简单而经济的许可选项。

Meeting Server 的部署方式

如需了解更多部署相关信息，请咨询思科销售代表或合作伙伴，在他们的帮助下选择最适合您的方案。

选择平台

Meeting Server 软件经过优化，非常适合在基于 UCS 的思科 Meeting Server 1000 和 Meeting Server 2000 平台上运行。

选择许可方案

思科的多方许可方案支持按每次会议单独购买许可。当然，您也可以选择传统许可模式，按容量购买许可。

挑选追加功能

您可以选择品牌支持和录制功能等追加选项。

下载软件

从思科的网站或 App Store 上下载 Mac 版或 PC 版思科 Meeting App，或者从 App Store 下载 iOS 版思科 Meeting App。
