Cisco Secure Client 5 新增功能

🔐 Cisco Secure Client 5.1.20.333 新特性

2026 年 9 月 11 日

此版本包含以下更新和功能，并修复了 Cisco Secure Client 5.1.20.333 中所述的缺陷。

  • 支持 macOS 27（Golden Gate）
  • 支持并部署 Endpoint Data Loss Prevention（端点数据丢失防护）（仅适用于 Windows 和 macOS 预部署，以及 Apple silicon M 系列）—通过控制传输到外部设备的数据，帮助您保护端点上的敏感数据。该功能扩展了您的数据保护策略，并确保敏感数据保持安全，同时符合您的安全要求。
  • Network Access Manager 回退到机器身份验证（CSCwt18945）— 目前，当智能卡被移除时，根据配置不同，网络连接可能会断开，或者仍然保持与用户级授权的关联。现在，在这些情况下，Network Access Manager 会自动切换到机器身份验证，从而确保即使用户会话不再处于活动状态，设备仍能保持与网络的连接 (sysin)。此更新对于维持可靠、一致的连接至关重要，并能显著提高 IT 部门的工作效率。它允许在无需预先安装单个用户证书的情况下配置通用 PC。通过机器回退建立连接后，系统可以无缝处理证书注册或推送更新，从而显著减少机器配置所需的人工工作量。
  • 5.1.20.333 版本包含以下各模块版本：
    • Zero Trust Access—5.1.20.7023
    • Secure Client UI—5.1.20.2493
    • Cisco AnyConnect VPN core—5.1.20.333
    • DART—5.1.20.333
    • Umbrella—5.1.20.333
    • SBL—5.1.20.333
    • Network Access Manager—5.1.20.333
    • Network Visibility Module—5.1.20.333
    • Secure Firewall Posture—5.1.20.333
    • Endpoint Data Loss Prevention（仅限 Windows）—1.5.0.292
    • ThousandEyes—2.43.2
    • ISE Posture—5.1.20.333
    • Duo Desktop—7.20.0.0
    • Endpoint Visibility Module—1.8.0.5（Windows 和 macOS）
  • 已知问题：CSCww61247—将系统语言更改为受支持的区域设置后，Linux CSC UI 仍显示为英文

文件描述

Cisco Secure Client 可通过以下方式部署给远程用户：

  • 预部署（Predeploy）：新的安装或升级可以由最终用户完成，或通过企业软件管理系统（SMS）进行。
  • Web 部署（Web Deploy）：AnyConnect 软件包会加载到头端设备上，该设备可以是 ASA 或 FTD 防火墙，或者是 ISE 服务器。当用户连接到防火墙或 ISE 时，AnyConnect 会被部署到客户端。

The Cisco Secure Client can be deployed to remote users by the following methods:

  • Predeploy - New installations and upgrades are done either by the end user, or by using an enterprise software management system (SMS).
  • Web Deploy - The AnyConnect package is loaded on the headend, which is either an ASA or FTD firewall, or an ISE server. When the user connects to a firewall or to ISE, AnyConnect is deployed to the client.
