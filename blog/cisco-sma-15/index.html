Cisco Secure Email and Web Manager

Cisco Secure Email 内容安全管理设备（SMA）可将多个 Cisco® Email Security Appliances（ESA）与 Cisco Web Security Appliances（WSA）的管理与报告功能集中化。Cisco SMA 与 Cisco ESA、WSA 的整合简化了电子邮件和网络安全的规划与管理、提升合规性监控、确保一致的可接受使用政策执行，并增强整体威胁防护能力。

对于人员与预算有限、且需在地理分散的团队之间协调管理多个安全设备的组织来说，Cisco SMA 基于强大的平台构建，在优化报告与追踪的同时，提供高性能、可扩展性以及行业领先的安全防护与控制能力，保证长期投资价值。

功能与优势

Features and benefits

下列章节将介绍 Cisco SMA 的功能与优势。

🌐 Simplified administration and planning（简化的管理与规划）

通过 Cisco SMA 的直观、易于使用的界面 (sysin)，网络管理人员可在单一控制台上向多个 Cisco ESA 与 WSA 发布策略设置与配置变更。对于高流量部署，组织也可将特定设备专用于特定应用。

此外，当安全设备超过建议容量时，网络管理人员会收到通知。Cisco SMA 会报告每秒事务数、系统延迟、响应时间及代理缓存内存等信息，使网络管理人员能够判断是否需重新配置系统或添加更多设备。

🌐 Improved compliance monitoring and enforcement（提升合规监控与政策执行）

集中化的报告与追踪功能有助于识别违反可接受使用政策的用户、找出部门或站点中的政策违规行为 (sysin)，并监控对 Facebook、YouTube 等 Web 2.0 应用的使用情况，以及对赌博、体育等 URL 类别的访问行为。

通过集中管理多个设备，管理员能够在整个组织内一致地执行可接受使用政策。

🌐 Enhanced threat protection（增强的威胁防护）

Cisco SMA 提供组织安全运营的全面视图，带来更完善的威胁情报、防护及修复能力 (sysin)。关键功能包括集中管理电子邮件垃圾隔离、跨多个网络安全网关的全面威胁监控、网络信誉评分及僵尸网络（botnet）检测。Cisco SMA 的报告功能还能帮助管理员识别与处理涉及数据泄露防护（DLP）的活动。

🌐 High performance and scalability（高性能与可扩展性）

Cisco SMA 采用两个分别为报告与追踪优化的专用数据库，而非单一通用数据库。每次查询都使用适当的计算方式，以快速生成实时报告。

基于高性能的 Cisco AsyncOS® 操作系统构建 (sysin)，Cisco SMA 具备行业领先的扩展能力，可满足小型、中型、大型组织及服务提供商的需求。

🌐 Flexible deployment with the Cisco Content Security Management Virtual Appliance（灵活的虚拟化部署）

Cisco 内容安全管理虚拟设备（SMAv）特别适用于高度分散的网络 (sysin)，在管理电子邮件与网络安全方面能显著降低成本。网络管理员可在需要的时间与地点创建实例，利用现有网络基础架构快速部署。

Cisco SMAv 是 Cisco SMA 的软件版本，可运行在 VMware ESXi 虚拟化平台及 Cisco UCS® 服务器上。购买任意 Cisco 电子邮件或网络安全软件套件的 SMA 软件许可后，即可获得不限数量的 SMAv 实例。

使用 Cisco SMAv 后，组织可立即因应流量增长，轻松规划容量扩展，无需采购并寄送实体设备，也无需增加数据中心复杂度或额外雇用人员。
