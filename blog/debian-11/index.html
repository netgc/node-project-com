2024 年 6 月 29 日

Debian 项目宣布其老版本 Debian 11 (代号 “bullseye”) 的第十次更新。此版本主要增加了对安全问题的更正，以及对严重问题的一些调整。安全建议已经单独发布，并在可用情况下提供参考。详见：Updated Debian 11: 11.10 released

2022 年 9 月 10 日

Debian 项目宣布了 Debian 11 稳定发行版（代号 "Bullseye "）第五次更新。本次发布主要增加了对安全问题的更正，以及针对严重问题的一些调整。安全建议已经单独发布并在可用的地方引用。详见：Updated Debian 11: 11.5 released。

Debian 11 “bullseye” 发布

2021 年 8 月 14 日

经过 2 年 1 个月 9 天的开发，Debian 项目自豪地推出了新的稳定版本 11（代号 “bullseye”），该版本将在未来 5 年内得到 Debian 安全团队 和 Debian 长期支持团队的共同支持。

Debian 11 “bullseye” 附带多个桌面应用程序和环境。除其他外，它现在包括桌面环境：

  • Gnome 3.38,
  • KDE Plasma 5.20,
  • LXDE 11,
  • LXQt 0.16,
  • MATE 1.24,
  • Xfce 4.16.

此版本包含超过 11294 个新包，总数为 59551 个包，同时显著减少了超过 9519 个标记为 “过时” 并已删除的包。更新了 42821 个包，5434 个包保持不变。

大多数现代打印机都能够使用无驱动程序打印和扫描，而无需供应商特定的（通常是非免费的）驱动程序。“bullseye” 提出了一个新包 ipp-usb，它使用许多现代打印机支持的供应商中立的 IPP-over-USB 协议。这允许将 USB 设备视为网络设备。官方的 SANE 无驱动后端由 libsane1 中的 sane-escl 提供，它使用 eSCL 协议。

默认情况下，“bullseye” 中的 Systemd 激活其持久日志功能，并隐式回退到易失性存储。这允许不依赖特殊功能的用户卸载传统的日志守护程序并切换到仅使用 systemd 日志 (sysin)。Debian Med 团队一直在参与抗击 COVID-19，打包软件用于在序列级别研究病毒并使用流行病学中使用的工具抗击大流行；这项工作将继续专注于这两个领域的机器学习工具。团队在质量保证和持续集成方面的工作对于科学所需的一致可重复结果至关重要。

Debian Med Blend 有一系列性能关键的应用程序，现在可以从 SIMD Everywhere 中受益。要安装由 Debian Med 团队维护的软件包，请安装名为 med-* 的元软件包，其版本为 3.6.x。

中文、日文、韩文等多种语言现在有了新的 Fcitx 5 输入法，它是《霸道》中流行的 Fcitx4 的继承者；这个新版本有更好的 Wayland（默认显示管理器）插件支持。

Debian 11 “bullseye” 包括许多更新的软件包（占前一版本所有软件包的 72% 以上），例如：

  • Apache 2.4.48
  • BIND DNS Server 9.16
  • Calligra 3.2
  • Cryptsetup 2.3
  • Emacs 27.1
  • GIMP 2.10.22
  • GNU Compiler Collection 10.2
  • GnuPG 2.2.20
  • Inkscape 1.0.2
  • LibreOffice 7.0
  • Linux kernel 5.10 series
  • MariaDB 10.5
  • OpenSSH 8.4p1
  • Perl 5.32
  • PHP 7.4
  • PostgreSQL 13
  • Python 3, 3.9.1
  • Rustc 1.48
  • Samba 4.13
  • Vim 8.2
  • 超过 59,000 个其他即用型软件包，由 30,000 多个源包构建而成。

凭借如此广泛的软件包选择及其传统的广泛架构支持，Debian 再次忠于其成为 “通用操作系统” 的目标。它适用于许多不同的用例：从桌面系统到上网本；从开发服务器到集群系统；以及用于数据库、Web 和存储服务器。同时，额外的质量保证工作，如对 Debian 存档中所有软件包的自动安装和升级测试，确保 “bullseye” 满足用户对稳定的 Debian 发行版的高期望。

一共支持九种架构：64 位 PC/Intel EM64T/x86-64（amd64）、32 位 PC/Intel IA-32（i386）、64 位 little-endian Motorola/IBM PowerPC（ppc64el）、 64 位 IBM S/390 (s390x)，用于 ARM、armel 和 armhf 用于较旧和较新的 32 位硬件，加上 arm64 用于 64 位 “AArch64” 架构，以及用于 MIPS、mipsel（小端）架构用于 32 位硬件和用于 64 位小端硬件的 mips64el 架构。

选择 Debian 的理由

用户选择 Debian 作为他们的操作系统的原因有很多。

主要的原因

  • Debian 是自由软件。

    Debian 是由自由和开放源代码的软件组成的，并将始终保持 100%自由。每个人都能自由使用、修改，以及分发。这是我们对 我们的用户 的主要承诺。它也是免费的。

  • Debian 是一个稳定且安全的基于 Linux 的操作系统。

    Debian 是一个广泛用于各种设备的操作系统，其使用范围包括笔记本计算机，台式机和服务器。自 1993 年以来，它的稳定性和可靠性就深受用户的喜爱。我们为每个软件包提供合理的默认配置。Debian 开发人员会尽可能在其生命周期内为所有软件包提供安全更新。

  • Debian 具有广泛的硬件支持。

    大多数硬件已获得 Linux 内核的支持 (sysin)。当自由软件无法提供足够的支持时，也可使用专用的硬件驱动程序。

  • Debian 提供平滑的更新。

    Debian 以在其发行周期内轻松流畅地进行更新而闻名，不仅如此，还包括轻松升级到下一个大版本。

  • Debian 是许多其他发行版的种子和基础。

    许多非常受欢迎的 Linux 发行版，例如 Ubuntu、Knoppix、PureOS、SteamOS 以及 Tails，都选择了 Debian 作为它们的软件基础。Debian 提供了所有工具，因此每个人都可以用能满足自己需求的软件包来扩展 Debian 档案库中的软件包。

  • Debian 项目是一个社区。

    Debian 不只是一个 Linux 操作系统。该软件由来自世界各地的数百名志愿者共同制作。即使您不是一个程序员或系统管理员，也可以成为 Debian 社区的一员。Debian 是由社区和共识驱动的，具有一个 民主的治理架构。由于所有 Debian 开发人员都享有平等的权利，所以它不能被单个公司所控制。我们的开发人员遍布在 60 多个国家 / 地区，并且 Debian Installer 提供了超过 80 种语言的翻译支持。

  • Debian 有多个安装程序选项。

    终端用户会使用我们的 Live CD，其包括易于使用的 Calamares 安装程序，只需很少的输入或前置知识。经验丰富的用户可以使用我们独特的功能齐全的安装程序，而专家可以对安装进行微调，甚至可以使用自动网络安装工具。

企业环境

如果您在专业环境中需要使用 Debian，则可以享受以下额外好处：

  • Debian 是可靠的。

    Debian 在从单个用户的笔记本到超级对撞机、证劵交易所和汽车行业的数以千计的现实日常场景中证明其可靠性。它在学术界、科研机构和公共部门中也很流行。

  • Debian 有很多专家。

    我们的软件包维护者不仅会为 Debian 软件包修正问题，还会将其补丁合并到新的上游版本。他们通常是上游软件的专家，直接为上游开发做出贡献。有时他们也是上游的一部分开发成员。

  • Debian 是安全的。

    Debian 对其稳定版本提供安全支持。许多其它发行版的开发人员和安全研究人员都依赖 Debian 的安全跟踪器。

  • 长期支持。

    Debian 提供了免费的 长期支持 (LTS)。这为您提供了对稳定版本至少 5 年的额外支持。除此以外，还有 扩展的 LTS 计划，该计划将对有限的软件包的支持延长到了 5 年以上。

  • 云映像。

    官方云映像可用于所有的主流云端平台。我们还提供了工具和配置，因此您可以构建自己的自定义云映像。您还可以在桌面或容器里的虚拟机中使用 Debian。

开发者

Debian 被各种软件和硬件开发人员广泛使用。

  • 公开的错误跟踪系统。

    我们的 Debian 错误跟踪系统 (BTS) 向所有人公开，任何人都可通过浏览器访问。我们不会隐藏我们的软件错误，您可以轻松提交新的错误报告。

  • 物联网和嵌入式设备。

    我们支持各种设备，例如 Raspberry Pi、QNAP 的各个变种、移动设备、家庭路由器以及大量单板计算机 (SBC)。

  • 多种硬件架构支持。

    Debian 支持 一长串 的 CPU 架构，包括 AMD64、i386、ARM 和 MIPS 、POWER7、POWER8、IBM System z、RISC-V 的多个版本。Debian 还可以用于较旧的特定架构。

  • 为数众多的可用软件包。

    Debian 拥有最多数量的已安装软件包（当前为 59000）。我们的软件包使用 deb 格式，该格式以其高质量著称。

  • 提供不同版本的选择。

    除了我们的稳定版本外，您还可以通过安装测试版或不稳定版本来获得最新版本的软件。

  • 在开发人员工具和政策的帮助下保证高质量。

    多个开发人员工具帮软件包维持高水平的质量，并且我们的 政策 规定了每个被官方仓库接受的软件包所必须满足的技术需求。我们的持续集成是运行在 autopkgtest 这个软件上的，piuparts 是我们的安装、升级和删除测试工具，lintian 是一个用于 Debian 软件包的全面的软件包检查程序。
