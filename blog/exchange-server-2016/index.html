2025 年 10 月 Exchange Server 安全更新

微软已发布针对以下产品中发现漏洞的安全更新 (SUs)：

  • Exchange Server Subscription Edition (SE)
  • Exchange Server 2019
  • Exchange Server 2016

以下特定版本的 Exchange Server 可获取相应的安全更新：

  • Exchange SE RTM
  • Exchange Server 2019 CU14 和 CU15
  • Exchange Server 2016 CU23

2025 年 10 月的安全更新修复了由安全合作伙伴负责任地向微软报告、以及微软内部流程发现的漏洞。
虽然目前尚未发现有针对这些漏洞的实际利用行为，但我们强烈建议您立即安装这些更新，以保护您的环境。

这些漏洞影响 Exchange Server。Exchange Online 客户已自动受到这些安全更新所修复漏洞的保护，无需采取任何额外措施，只需确保环境中的 Exchange 服务器或 Exchange 管理工具工作站保持最新即可。
