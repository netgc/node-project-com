集中式网络管理

FortiManager 和 FortiManager Cloud 跨混合环境简化和自动化 Fortinet Security Fabric 的网络和安全管理

FortiManager 概述

FortiManager 通过自动化日常任务并根据智能洞察采取行动，彻底改变网络管理和安全运营。它通过最佳实践模板加速零接触配置，用于部署混合式部署防火墙、SD-WAN 和 SD-Branch。与 Fortinet 解决方案和 500 多种生态系统工具的广泛集成进一步增强了端到端工作流程编排。

优化网络管理体验

FortiAI 驱动的 FortiManager 提供简化单一管理平台体验，以及无与伦比的网络洞察。助您随时掌握连接状态、资源利用率、设备配置、策略状态和告警信息。FortiManager 可轻松编排各种外形规格的 FortiGates，包括 VM、CNF 以及标准或加固硬件 (sysin)。同时，还将强大的管理功能无缝扩展至在 FortiOS 统一操作系统之上运行的整个网络生态系统，包括 FortiSwitch、FortiAP 和 FortiExtender。这种集成可确保整个组织网络始终一致地执行统一的安全策略，显著增强安全性并简化管理，实现最佳性能。

FortiAI-Assist：FortiManager 中的生成式 AI 工具

FortiManager 中的 FortiAI-Assist 利用生成式 AI 的强大功能，彻底改变网络运营。它使网络管理员能够自动执行日常任务、优化网络配置、加速诊断并简化策略管理。此外，FortiAI-Assist 与 FortiAIOps 无缝集成，促进预测网络分析和自动故障排除，使管理员能够在潜在问题影响网络性能之前主动识别并解决这些问题。通过结合 AI 驱动的自动化和预测分析，FortiManager 中的 FortiAI-Assist 可简化网络管理，减少人为错误和缩短停机时间，并提高整体运营效率。

混合式部署防火墙管理

Fortinet 是目前业内唯一一家可提供集中式统一管理的安全厂商，可帮助企业跨复杂的混合环境实施一致的安全策略。集中统一的管理涵盖在本地和云中部署 FortiGate 下一代防火墙（混合式部署防火墙），以及安全 SD-WAN、安全 WLAN/LAN、Universal ZTNA 和 FortiSASE (sysin)。

Fortinet Security Fabric 的集中管理

FortiManager 集中管理 Fortinet Security Fabric，无缝统一网络和安全运营，从而简化网络和安全融合。借助 FortiManager，您可以执行一致的安全策略、自动化工作流程，并在整个基础设施中获得实时可见性，无论是本地、云还是混合。了解 FortiManager 如何降低复杂性，同时加强防御不断演变的威胁。

通过 FortiManager Cloud 进行基于云的管理

FortiManager Cloud 提供快速部署、更高的灵活性和轻松的可扩展性，实现无缝管理，同时减少维护和中断。无论您的基础设施是在本地、云中，还是两者兼而有之，FortiManager Cloud 都能确保在整个生态系统中实现一致的安全策略、简化的运营和实时可见性 (sysin)。借助 FortiManager Cloud，您可以轻松管理和监控混合环境，降低复杂性，同时保持强大的防护，抵御不断演变的威胁。

FortiManager 功能与优势

✅ 集中式管理

支持管理 100,000 台 Fortinet 设备：FortiGate、FortiSwitch、FortiAP、SD-WAN 和 FortiSASE

✅ SD-WAN 叠加网络编排

零接触配置功能，简化部署工作流，大幅缩短所有分支机构和企业园区 SD-WAN 的部署时间

✅ 内置生成式 AI

采用 FortiAI 实现 AI 辅助并提升运营效率

✅ 安全自动化

通过 REST API、脚本、连接器、自动化工作流实现自动化，降低复杂性

✅ 即用型企业级集成

与 Splunk、IBM QRadar、ServiceNow 和 Tufin 等技术联盟合作伙伴产品实现一站式集成

✅ 基于云的管理

通过集中、弹性的基于云的控制简化混合环境管理

FortiManager 应用场景

✅ 提升运营效率

轻松管理和监控大规模防火墙配置和安全策略，同时借助单一管理平台实现全面可视化和自动化编排。

✅ 加速零接触配置

基于最佳实践模板和设备蓝图部署 SD-WAN 等安全组网技术，实现大规模快速部署。

✅ 降低网络安全风险

跨本地和云中部署的 NGFW 、SD-WAN、ZTNA 和集成安全访问服务边缘（SASE）的防火墙即服务解决方案，实施一致的安全策略。
