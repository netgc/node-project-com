FreeBSD 14.5-RELEASE 发布公告

日期：2026 年 9 月 8 日

FreeBSD Release Engineering Team 宣布 FreeBSD 14.5-RELEASE 正式发布。这是 stable/14 分支的第 6 个版本。

FreeBSD 14.5 更新 LLVM 21.1.8、OpenSSL 3.0.21、OpenZFS 相关组件及 Unbound 1.26.0，新增 Linux inotify API 兼容支持，改进 smartpqi 存储驱动、FAT32 Unicode 文件名、UEFI 启动及 IPv6-only DNS 配置，并加入内核 kenv 访问控制。

若需查看完整的新功能列表、受支持的硬件以及已知问题，请访问官网查阅在线发布说明、硬件兼容性说明和勘误列表。

FreeBSD 14 新功能

🆓 一般更新

FreeBSD 14 将 root 用户的 默认 shell 提升为 sh，拥有一系列专为交互式使用而定制的新功能。此次升级带来了清新高效的 shell 体验，增强了用户与系统的交互。

FreeBSD 14 进行了重大转变，采用 Dragonfly Mail Agent 作为 默认邮件传输 代理 (MTA)，取代了 sendmail。此更改通过 mailer.conf 简化了 MTA 配置，为用户提供了更现代、更高效的电子邮件处理体验。

以及对文件名通配的支持而得到了提升 引入 .include 指令 Jail 通过在 jam.conf 文件中 。此增强功能简化了监狱配置，为用户提供了对虚拟环境的更大灵活性和控制力。

一次性密码工具 OPIE 已从 删除 基本系统中 (sysin)，鼓励用户在希望继续使用时安装安全 / opie 端口。FreeBSD 14 通过在 etcupdate 期间从 PAM 策略中删除或注释 pam_opie 和 pam_opieaccess 来确保平稳过渡。

区域设置处理 在 FreeBSD 14 中得到了重大升级，现在与 CLDR 41.0 和 Unicode 14.0 保持一致。这确保用户能够获得最新的国际化标准，从而培育更具包容性和全球意识的计算环境。

此版本还引入了 base64 实用程序，为系统的功能添加了一个有价值的工具。此外，bhyve 虚拟机管理程序现在支持可选的 TPM 直通，为虚拟化环境提供增强的安全功能。

FreeBSD 14 还 带来了显着改进 为 AMD 和 Intel GPU 的 bhyve 中的 GPU 直通 。虽然这仍然是一项正在进行的工作，但增强的配置为更高效、更强大的虚拟化设置铺平了道路。

有影响力的更改 之一是 pw 和 bsdinstall 现在 在 /home 而不是 /usr/home 中创建主目录 。不会创建 /usr/home 中 /home 的符号链接。因此，如果从 FreeBSD 13 升级到 FreeBSD 14，请确保正确迁移它。

此外，一些以用户为中心的增强功能包括 。 在日期实用程序中添加用于时区转换的 -z 选项、在 diff 中使用 -color 选项支持彩色输出，以及删除已弃用的 fmtree 实用程序


FreeBSD 14


FreeBSD 14 与 Xfce 桌面

🆓 存储和文件系统

FreeBSD 14 引入了 gconcat 实用程序的改进，允许将设备添加到串联设备中 即使在创建后也。这为存储配置提供了更大的灵活性，从而增强了整体用户体验 (sysin)。此外，gunion 的引入有助于跟踪只读磁盘上的更改，这对于文件系统修复或软件升级等尝试性更改非常有价值。

为了增强可见性和调试，与 vnode 相关的统计信息现在 分组 在 vfs.vnode 下，提供更全面的视图。此更改来自解决和解决通用文件系统代码中与 vnode 回收相关的问题。

用户现在可以 执行后台文件系统检查，从而提高系统维护效率。 使用运行日志软更新的 UFS 文件系统上的快照来

通过升级到 OpenZFS 版本 2.2，ZFS 子系统得到了显着的提升。新功能包括块克隆、BLAKE3 校验和以及性能改进（例如完全自适应 ARC 和 I/O 预取增强）。

NFS 变化：

FreeBSD 14 现在支持在 VNET 监狱中运行 NFS 服务器，从而扩展了网络配置的范围。用户可以通过隔离其文件系统上的 Jail、设置 allow.nfsd 参数并确保正确配置 enforce_statfs 来从此功能中受益。

NFSv4 挂载得到显着 改进，客户端默认为服务器支持的最高次要版本。用户可以使用次要版本安装选项覆盖此行为。此外，FreeBSD NFS 客户端现在支持 1 MB I/O 大小，与 Linux 客户端保持一致。

引入了新的 syskrb5 挂载选项 (sysin)，允许 Kerberized NFSv4.1/4.2 挂载，而无需在挂载时提供 Kerberos 凭据。这简化了身份验证过程并增强了安全性。

🆓 网络、启动和硬件更新

lua 风格的加载器现在解释 loader_conf_files 中的 .lua 文件，并在沙箱中执行它们。这带来了更大的可配置性并扩展了加载器环境变量的实用性。

EC2 实例现在使用 UEFI（如果可用）启动，从而大幅缩短启动过程持续时间。此增强功能对于寻求 EC2 实例更快启动时间的用户来说是一个福音。

IPv6 over IPv4 的 6to4 接口 if_stf 现在支持按照 RFC5969 的 IPv6 快速部署（第 6 版），扩展了 FreeBSD 14 上的 IPv6 功能。

if_bridge 上的第 3 层过滤受到关注，并调整了默认设置以确保更安全的操作 (sysin)。此更改增强了某些虚拟配置的安全性和稳定性。

FreeBSD 14 告别了对 MIPS 架构的支持，以适应不断变化的硬件和架构偏好。

在此版本中，FreeBSD 不再提供 armv6 工件，而是专注于更现代的架构和优化资源。

FreeBSD 14 作为一个主要版本带来了巨大的改进，使其成为您正在运行的 BSD 机器的完美升级，以提高整体系统性能。一如既往，我鼓励您探索全面的 发行说明，以深入了解更改和优化。

FreeBSD 是什么?

FreeBSD 是一个注重功能、速度和稳定性的操作系统，支持许多平台。它源于 BSD ── 美国加州大学伯克利分校开发的 UNIX® 版本。它由一个很大的志愿者社区开发和维护。

为什么选择 FreeBSD?

🆓 先进特性

FreeBSD 提供了网络、性能、安全以及兼容性等多方面的特性，这些特性即使是在当今最优秀的商业操作系统中亦有所欠缺。

🆓 强大的互联网解决方案

FreeBSD 是理想的 Internet 或 Intranet 服务器。即使是在超重负载下，它仍然能够有效地使用内存 (sysin)，为同时运行的数以千计的用户进程提供良好的响应时间。

🆓 嵌入式平台支持

FreeBSD 为嵌入式平台和设备带来了先进的网络操作系统特性，无论是高端的基于 Intel 的设备，还是 ARM、PowerPC 或 MIPS 硬件平台。从邮件和网络设备到路由器、校时服务器和无线接入点 (sysin)，世界各地的供应商依赖 FreeBSD 的整合编译和交叉编译环境以及其它先进特性，以此作为他们嵌入式产品的基础。而伯克利开放源代码许可证让他们得以自主决定要贡献哪些改动。

🆓 能够运行大量可供选择的应用

经由 ports 中超过 33,000 个库和应用程序，FreeBSD 支持桌面系统、服务器和嵌入式平台的各种应用。

🆓 易于安装

FreeBSD 能通过多种介质进行安装，包括普通光盘、 DVD 光盘，或直接通过 FTP 或 NFS 服务器安装。您只需按照安装指导操作。

🆓 FreeBSD 是 free 的

您或许认为如此优秀的操作系统需要花费大笔金钱来购买，而 FreeBSD 是免费提供的，并且包含了源代码。
