FreeBSD 15.1-RELEASE 发布公告

发布日期：2026 年 6 月 16 日

FreeBSD 发布工程团队（Release Engineering Team）很高兴地宣布 FreeBSD 15.1-RELEASE 正式发布。这是 stable/15 分支的第二个正式版本。

✨ 主要更新亮点

  • 基于 LinuxKPI 的无线网络驱动程序（包括 iwlwifi(4)）现已升级并基于 Linux v7.0 实现。
  • 使用打包基础系统（packaged base system）的 FreeBSD 云镜像现在默认包含 pkg(8)，并支持在首次启动时自动更新基础系统软件包。
  • 新增 kern.sched.name 可调参数（tunable），允许在系统启动时选择内核调度器。
  • 对 C23 版本 C 语言标准的支持取得了显著进展，距离完整支持又迈进了一大步。
  • Unicode 支持已更新至 Unicode 17.0.0 和 CLDR 48，新增 4,803 个字符。

📋 更多信息

有关新功能、支持的硬件以及已知问题的完整列表，请参阅以下在线文档：

  • 发布说明（Release Notes）：https://www.FreeBSD.org/releases/15.1R/relnotes/
  • 硬件兼容性说明（Hardware Notes）：https://www.FreeBSD.org/releases/15.1R/hardware/
  • 勘误列表（Errata）：https://www.FreeBSD.org/releases/15.1R/errata/

有关 FreeBSD 发布工程活动的更多信息，请参阅：https://www.FreeBSD.org/releng/

FreeBSD 15.0-RELEASE 发布公告

日期：2025 年 12 月 2 日

FreeBSD 发布工程团队很高兴宣布 FreeBSD 15.0-RELEASE 的正式发布。这是 stable/15 分支的首个版本。

一些亮点如下：

  • FreeBSD 的 “base” 基础系统现在可以通过 pkg(8) 包管理器进行安装和管理（见下方 “Packaged base system” 部分）。
  • FreeBSD 15.0 的发布制品（安装镜像、VM 镜像等）全部在不需要 root 权限的情况下生成。
  • FreeBSD 现在提供原生 inotify 实现 (sysin)，简化了目录监控和软件移植。
  • OpenZFS 已升级至 2.4.0-rc4。
  • OpenSSL 已升级到最新的长期支持（LTS）版本 3.5.4，包含对 QUIC 的支持，并提供已标准化的抗量子算法：ML-KEM、ML-DSA 和 SLH-DSA。
  • OpenSSH 已升级至 10.0p2，并默认支持抗量子密钥协商。

若需查看完整的新功能列表、受支持的硬件以及已知问题，请访问官网查阅在线发布说明、硬件兼容性说明和勘误列表。

✅ Packaged base system

FreeBSD 15.0 的一项重大变化是引入了一种使用 pkg(8) 包管理器来安装和管理基础系统的新方法。在开发期间，此方法常被称为“pkgbase”。

在安装过程中，bsdinstall(8) 会提示用户从两种安装方式中进行选择：

  1. Distribution Sets（传统方式）：这是之前 FreeBSD 版本使用的方法。以此方式安装的系统仍使用 freebsd-update(8) 工具进行更新。Distribution sets 的支持计划在 FreeBSD 16 中移除，但在 FreeBSD 15 的整个稳定分支生命周期内仍会保留（包括 freebsd-update 的支持）。
  2. Packages（pkgbase / 新方式）：基础系统作为一组来自 “FreeBSD-base” 仓库的包进行安装 (sysin)。以此方式安装的系统完全由 pkg(8) 工具管理。所有 VM 镜像以及发布到公共云的镜像均默认使用此方法。在 FreeBSD 15.0 中，pkgbase 作为技术预览提供，但预计在未来将成为管理基础系统安装和升级的标准方法。

✅ 可用性

FreeBSD 15.0-RELEASE 现已支持以下架构：amd64、aarch64、armv7、powerpc64、powerpc64le 和 riscv64。

FreeBSD 是什么?

FreeBSD 是一个注重功能、速度和稳定性的操作系统，支持许多平台。它源于 BSD ── 美国加州大学伯克利分校开发的 UNIX® 版本。它由一个很大的志愿者社区开发和维护。

💾 原生 ZFS

OpenZFS 将文件系统和卷管理器的功能整合为一个统一且可靠的存储平台。在 FreeBSD 中，它已完全集成到操作系统之中。

🖥️ 虚拟化

bhyve 是 FreeBSD 的现代化虚拟机监控程序（Hypervisor），支持 virtio、PCI 直通以及高性能 NVMe 模拟。

🔒 Jail 容器

FreeBSD Jail 为服务和应用程序提供隔离运行环境。每个 Jail 都可以拥有独立的文件系统、网络配置以及运行参数。

🌐 网络

FreeBSD 以卓越的网络性能和稳定性而广受认可。全球众多关键基础设施都依赖其处理高负载、严苛要求的网络工作负载。

📚 文档

FreeBSD 提供内容丰富且维护完善的文档体系。从《Handbook》到各类手册页（man pages），文档始终被视为系统的重要组成部分。

🤝 社区

FreeBSD 拥有充满活力且协作紧密的社区，成员既包括个人贡献者，也包括大型企业组织。社区活跃于各种交流渠道，从实时通信平台到邮件列表和新闻组，均有广泛参与。

为什么选择 FreeBSD?

🆓 先进特性

FreeBSD 提供了网络、性能、安全以及兼容性等多方面的特性，这些特性即使是在当今最优秀的商业操作系统中亦有所欠缺。

🆓 强大的互联网解决方案

FreeBSD 是理想的 Internet 或 Intranet 服务器。即使是在超重负载下，它仍然能够有效地使用内存 (sysin)，为同时运行的数以千计的用户进程提供良好的响应时间。

🆓 嵌入式平台支持

FreeBSD 为嵌入式平台和设备带来了先进的网络操作系统特性，无论是高端的基于 Intel 的设备，还是 ARM、PowerPC 或 MIPS 硬件平台。从邮件和网络设备到路由器、校时服务器和无线接入点 (sysin)，世界各地的供应商依赖 FreeBSD 的整合编译和交叉编译环境以及其它先进特性，以此作为他们嵌入式产品的基础。而伯克利开放源代码许可证让他们得以自主决定要贡献哪些改动。

🆓 能够运行大量可供选择的应用

经由 ports 中超过 33,000 个库和应用程序，FreeBSD 支持桌面系统、服务器和嵌入式平台的各种应用。

🆓 易于安装

FreeBSD 能通过多种介质进行安装，包括普通光盘、 DVD 光盘，或直接通过 FTP 或 NFS 服务器安装。您只需按照安装指导操作。

🆓 FreeBSD 是 free 的

您或许认为如此优秀的操作系统需要花费大笔金钱来购买，而 FreeBSD 是免费提供的，并且包含了源代码。
