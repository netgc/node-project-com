Gartner 魔力象限：主存储 2023

Published 18 September 2023

魔力象限

主要存储用户正在接受基于基础设施消耗的混合、多域、关键任务应用程序的服务，并使成本与业务需求保持一致。I&O 领导者应利用这项研究来实现运营自动化、降低复杂性和流失率，并实现 IT 运营转型。

战略规划假设
到 2026 年，基于存储消耗的平台 SLA 保证将取代 50% 以上的传统本地 IT 容量管理、预算、评估、采购和履行活动，而 2023 年这一比例还不到 10%。

到 2027 年，不到 30% 的 IT 存储基础设施预算将用于硬件管理和支持 IT 技能，低于 2023 年的 85%。

到 2028 年，基于消费的存储即服务 (STaaS) 将取代超过 35% 的企业存储资本支出 (capex)，而 2023 年这一比例还不到 10%。

市场定义 / 描述
Gartner 对主存储市场的看法主要集中在创新存储技术和混合平台计划、IT 云运营模式以及将塑造最终用户未来需求的即服务部署和实现方法。它不像今天那样专注于市场。正如《利用存储即服务平台 SLA 和功能来转变 IT 成果》中所述，主存储市场正在进入一个加速创新的时期 (sysin)。最终用户正在从传统的资本支出融资和预算转向采用混合平台策略，该策略包含本地云运营模式和新的供应商存储资产融资和管理方法。供应商在平台功能、数据和网络弹性以及新存储操作系统架构方面的进步为本地 I&O 领导者提供了针对 IT 运营模型结果的 SLA。I&O 领导者面临的最基本问题是如何获得类似云的优势，同时保持高水平的弹性和控制力 基于中央服务的 IT 运营基础设施。

Gartner 将主存储市场定义为提供专用产品或服务的供应商，这些产品或服务跨存储介质设备汇集容量，通过块接口协议（如光纤通道或 Internet 小型计算机系统接口（iSCSI））向业务应用程序提供逻辑单元号（LUN）。同时，供应商提供高可用性和数据保护。主存储产品可以以固态阵列 (SSA)、软件定义存储 (SDS) 或混合存储阵列的形式提供。SDS 软件将存储资源从对底层供应商硬件设备的依赖中抽象出来，以提高灵活性、经济高效且高效的可扩展性 (sysin)，以及跨混合平台扩展到数十个计算节点时的 存储线性性能。SDS 软件设计为在本地、通过混合云或公共云上的行业标准硬件上运行。混合存储阵列包括固态驱动器 (SSD) 和硬盘驱动器 (HDD) 配置。SSA 产品是 100% 基于固态技术的系统，无法与 HDD 组合或扩展。SSA 和混合存储阵列必须具有专用的产品名称和关联的型号。

主存储产品的首要目的是支持响应时间和每秒输入 / 输出 (IOPS) 敏感的结构化数据工作负载。此外，主存储功能将与集中控制平面集成并支持独立使用，以实现自动化基础设施管理、数据服务和数据移动，以及存储即服务混合基础设施平台产品。典型用例包括：

  • 任务和业务关键型数据库工作负载
  • 应用整合
  • 支持虚拟化和虚拟桌面基础架构环境
  • 容器环境的持久存储和数据保护
  • 跨越本地、托管、边缘和公共云基础设施的混合云 IT 运营

核心能力：

主存储市场的核心能力包括：

  • 基于块的主机接口协议，例如光纤通道、iSCSI、串行连接 SCSI (SAS)；基于文件的，例如网络文件系统和服务器消息块；或块和文件协议的组合。
  • 数据服务可跨存储介质设备（HDD 或闪存）汇集容量并向业务应用程序提供 LUN。
  • 数据服务可节省容量利用率、提供高水平的效率和弹性、防止数据丢失和勒索软件，并通过本地和远程复制实现恢复。
  • 基于块的 STaaS 产品，可作为服务提供商提供 (sysin)，并作为IT管理产品与最终用户客户端合作管理。
  • AIOps 软件包括对规定运行状况的操作监控、客户支持以及对主动容量管理、无中断工作负载模拟、数据放置和迁移、存储资产利用率成本优化、性能优化以及全堆栈和跨堆栈以及车队范围遥测可观测性的支持、警报和报告。
  • 一种 SDS 产品架构，将供应商的存储硬件与存储操作软件分开。SDS 产品支持本地存储和/或可通过市场访问的一个或多个公共云平台。它与云提供商的服务器、存储和网络硬件集成，并部署与其本地设备解决方案相同的存储操作系统。它还与供应商 AIOps 功能集成。
  • 将数据从当前阵列无中断迁移到未来阵列，并保证 100% 的数据可用性。
  • 网络存储保护和恢复能力，包括对勒索软件检测、数据保护和恢复功能的支持。

可选功能：

其他主存储功能包括：

  • 具有非易失性内存的 SSA 通过结构 (NVMe-oF) 作为主机接口，为光纤通道和以太网连接提供支持。
  • 先进的 AIOps 实时事件流功能支持受监控的 SLA 阈值条件，这些条件需要对关键 IT 运营情况（例如存储资产管理、网络责任弹性和生产力）采取自动化的系统级（例如：非人工干预）操作。
  • 多基础设施域和混合平台范围的中央控制平面，具有多租户、多供应商 AIOps，可实现 ITOps 即服务功能，支持先进的 IT 运营模型 SLA 结果。
  • 多协议、分解存储计算体系结构 (sysin)，支持容量和计算的无中断、不对称弹性扩展，相互独立，通过将存储节点从少量计算和存储节点增加到数十个来保持性能。
  • 混合基础设施平台产品，用于集成、管理和支持集中式 IT 数据服务基础设施解决方案，包括但不限于备份即服务、灾难恢复即服务、勒索软件恢复或保护即服务以及数据库即服务。
  • 至少在两个主要地区测量的满载系统的公布碳排放量，以每年每兆字节的二氧化碳总量来衡量。
  • 专用 SSD 或专属 NVMe SSD 驱动器，可增强性能、耐用性、管理和数据服务。
  • 可以横向扩展并基于 SSD 或 HDD 或两者组合的阵列外形规格。

如何选择

在特定市场内定位技术参与者。

主要技术市场上有哪些竞争参与者？他们如何为您提供长期帮助？Gartner 魔力象限是对特定市场的巅峰研究，可帮您广泛了解市场竞争对手的相对位置 (sysin)。利用图示法和一系列统一的评估标准，魔力象限可帮助您快速确定技术提供商执行其既定愿景的情况，并参照 Gartner 的市场观点了解其表现。

如何使用 Gartner 魔力象限？

面对特定投资机会考虑技术提供商时，请借助 Gartner 魔力象限迈出第一步。

请记住，专注于领导者象限不一定是最好的行动方案。有充分的理由考虑市场挑战者。特定领域者可能比市场领导者更能满足您的需求。这完全取决于提供商如何与您的业务目标保持一致。

Gartner 魔力象限如何发挥作用？

面对快速增长和提供商差异化明显的众多市场，Gartner 魔力象限用图形化方法划分出四类提供商：

  • 领导者很好地执行了当前愿景 (sysin)，并为未来做好了充分准备
  • 有远见者了解市场发展方向，或者有改变市场规则的设想，但执行效果不尽如人意。
  • 特定领域者成功专注于一个小的细分市场，或者目标不明确，创新和表现未能超越竞争对手。
  • 挑战者当前表现很好，或者可能在大部分细分市场占据主导地位，但未表现出对市场方向的了解。
