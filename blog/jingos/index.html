全球首个专为平板打造的 Linux

JingOS 是一款基于 Linux 的 “融合” 开源操作系统，用于平板和移动设备，

它可以运行 Linux 和 Android 应用程序，

它能让你用手、用笔、用键盘，还有触控板来互动，

当你连接键盘和触控板时可以变成桌面模式。

移动或桌面二合一 All in one

JingOS 适配平板和桌面系统的不同体验，接上键盘和触控板秒变桌面模式，提高生产力，您可以用它来办公处理文档，制作 ppt，开发，创作和解决特定场景需求 (sysin)。去掉键盘它会是一款阅读和娱乐设备，您可以用它观看电影，阅读喜欢的书籍，以及玩喜爱的游戏和听喜欢的音乐。

专为移动打造的触控体验

支持多点触摸手势，精心设计的图标及动画效果，和全屏的应用使用体验。让你在操作系统更专注。

支持触控板手势和外接键盘

JingOS 在触控板手势上也做了优化，支持与触摸屏幕类似的手势，让你可以更加方便在桌面模式下使用 JingOS。专属光标得心应手地进行电子表格编辑、文本选取这类特别需要光标的工作。

Linux 和 Android 应用支持，丰富的应用商店

我们将 Linux 和 Android 的应用通过独有的专利技术进行的连接，使 JingOS 成为了一款 “融合” 操作系统。您可以通过 Linux 的桌面应用解决生产力的难题，通过下载 Android 应用来完善娱乐生态。但是你无需关心它是什么系统的应用，在 JingOS 中保持一致的体验，这些你都可以通过我们的应用商店来获取。

**Android 应用只适配于 ARM 架构的设备，X86 架构的设备只能运行 Linux 应用 *

JingOS, 为高效办公、提高生产力而生

JingOS 默认安装 Chrome 浏览器阅读和浏览网页, WPS Office 办公软件可以帮您创建文档，电子表格和演示文稿，VS Code 开发应用程序。

安全，稳定，快速

JingOS 基于 Linux 和 Unix, 拥有其特性和安全优势，以及高质量的代码和安全策略，为操作系统减少间谍软件和病毒的困扰。

精美的内置应用，获得更佳的日常使用体验

为了让用户获得更好的体验 (sysin)，我们专门为 JingOS 设计了包括计算器、时钟、文件、媒体播放器，图片浏览器，录音机等应用。这些应用都是与 iPad 应用一样，专为触摸和平板体验打造。
