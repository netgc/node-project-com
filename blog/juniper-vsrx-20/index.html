Juniver vSRX 虚拟防火墙

用于保护私有云、公共云和混合云的高性能下一代防火墙

魔力象限挑战者。了解 Gartner 授予瞻博网络“2020 年网络防火墙魔力象限挑战者”称号的原因。

Gartner Magic Quadrant for Network Firewalls 2020

vSRX 概述

组织正逐渐将工作负载迁移到云中，以充分利用虚拟化优势 — 但迁移到云带来了新的安全需求。进入 vSRX 虚拟防火墙，可为私有云、公共云和混合云提供可扩展的安全保护。

vSRX 以虚拟化外形提供了与物理 SRX 系列防火墙完全相同的功能 — 安全服务，可以灵活扩展以满足网络需求。它提供与 SRX 设备相同的功能，包括核心防火墙、稳定的网络、全面的新一代功能以及自动化生命周期管理。vSRX 处理速度高达 100 Gbps，堪称业界最快的虚拟防火墙。

它支持瞻博网络 Contrail、OpenContrail 和第三方软件定义网络 (SDN) 解决方案 (sysin)，并且与 OpenStack 等云编排工具进行了集成。带策略实施器的 Junos Space Security Director 支持自动化安全实施，在一个通用界面中为物理和虚拟资产提供统一管理和可见性。

vSRX 功能

高级威胁防御

包括使用瞻博网络 ATP 云的动态恶意软件保护和自适应威胁分析、阻止已知威胁的 SecIntel 威胁情报，以及针对隐藏在 SSL 加密流量中威胁的加密流量洞察。

下一代防火墙

高级安全服务包括 IPS、应用安全 (AppSecure)、基于用户角色的防火墙控制，﻿以及统一威胁管理 (UTM)（防病毒、防垃圾邮件、Web 过滤）。

瞻博网络安全连接

为远程办公的员工提供可访问公司资源和云资源的动态、自适应型安全 SSL-VPN。

公共云工作负载保护

为 AWS、Microsoft Azure 和 Google Cloud Platform Marketplace 公共云上的工作负载提供无与伦比的保护。

网络灵活性

通过与 Contrail、OpenContrail 及第三方 SDN 解决方案集成，支持软件定义网络 (SDN) 和网络功能虚拟化 (NFV)

出色的性能和可扩展性

最高可扩展至 100 Gbps，实现跨公共云和私有云的超高性能保护。

关键功能的自动化

借助 Junos OS 中强大且多用途的 API，可使用 REST API、NETCONF、Ansible 和 Vagrant 等工具实现管理和编排自动化。

灵活的许可模式

提供简单、灵活和可扩展的许可模式 (sysin)，以满足不同业务需求，包括公共云的即用即付制 (PAYG) 和自带许可证 (BYOL)。
