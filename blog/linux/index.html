世界主宰

其实，Apple、Cisco、F5，VMware 以及各类网络操作系统产品，都是 Unix-Like 系统，或基于 Linux kernel，或基于（BSD）Unix。

ESXi 的 VMkernel 当然也符合 POSIX 规范。

  • macOS 下载汇总 (系统、应用和教程) --> Unix
  • Cisco 产品下载链接汇总 --> Linux
  • F5 产品下载汇总 - 多云安全和应用交付 --> Linux
  • Firewall 产品链接汇总 --> Linux, BSD
  • VMware 产品下载汇总 --> VMkernel, Linux

当然还有手机上的 iOS（Unix）和 Andriod（Linux）以及灿若繁星的 IoT，Unix-Like 是地球信息世界的绝对主宰！
