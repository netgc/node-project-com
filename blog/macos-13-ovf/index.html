macOS 13 Blank OVF - 在 ESXi 8.0 中运行 macOS Ventura 的简单方式

作者主页：sysin.org

近期一些读者朋友反馈，在 ESXi 8.0 中无法运行 macOS Ventura。通过测试发现，ESXi 8.0 中运行 macOS Ventura 确实比之前的版本稍微麻烦一点，究其原因还是 Apple 转型 ARM 架构致使 VMware 目前无法支持在 Apple silicon 上运行 ESXi，VMware ESXi 8.0 已经不再官方支持 Mac 硬件和新版 macOS Guest OS。在此前 Mac 上 ESXi 7.0 虚拟化 macOS 是官方支持的 (sysin)。笔者在网站上的一些文章中已描述虚拟化 macOS Ventura 的注意事项，实现也很简单，不过还是直接上 OVF 来的省事一些。

系统 (软件) 要求

macOS 12/13 blank OVF for VMware ESXi

  1. OVF 版本兼容性

    vm hardware version 20，兼容 ESXi 8.0 / Fusion 13 / Workstation 17 及以上版本

  2. VMware 软件支持

    要求已经 macOS Unlocker 的 ESXi 8.0 或者 ESXi 9.0。旧版本理论上也支持，只是新的客户机操作系统通常在对应的新版主机操作系统中测试。

    • VMware ESXi 8.0U3k macOS Unlocker & OEM BIOS 2.7 标准版和厂商定制版
    • VMware ESXi 8.0U3k macOS Unlocker & OEM BIOS 2.7 集成网卡驱动和 NVMe 驱动 (集成驱动版)
    • VMware ESXi 9.1.1 macOS Unlocker & OEM BIOS 2.7 标准版和厂商定制版
    • VMware ESXi 9.1.1 macOS Unlocker & OEM BIOS 2.7 集成网卡驱动和 NVMe 驱动 (集成驱动版)

    当然也支持 Unlocker 的 VMware Workstation。

    • VMware Workstation 17.6.4 Pro Unlocker & OEM BIOS 2.7 for Windows & Linux
    • VMware Workstation Pro 26H1u1 macOS Unlocker & OEM BIOS 2.7 定制版

  3. macOS 映像要求

    要求可引导的 macOS 映像：

    • macOS Ventura 13.7.8 (22H730) Boot ISO 原版可引导映像下载
    • macOS Monterey 12.7.6 (21H1320) Boot ISO 原版可引导映像下载

  4. VMware Tools

    macOS 成功运行后，需要安装 VMware Tools 12.1.x 版本
    当前版本：VMware-Tools-darwin-12.1.1-22484250.iso (与 v12.3.5 同时发布)
    下载地址：https://sysin.org/blog/vmware-tools-12/

硬件 (CPU) 要求

要求 Intel 第四代酷睿或者同代志强处理器（Haswell 架构）及更新的硬件。现已收到反馈可以支持 Intel 13 代酷睿处理器。
具体来讲是要支持 “Instruction Set Extensions: Intel® AVX2” 的 CPU。

建议使用 Intel 第 7 代酷睿或者同代志强处理器（Kaby Lake 架构）及更新的硬件。

  • Intel® Core™ Processor (Kaby Lake or later)
  • Intel® Xeon® Processor (Kaby Lake or later)

不支持 Intel 赛扬（Celeron®）处理器和奔腾（Pentium®）处理器。

不支持 AMD 处理器。

注意事项

请阅读以下注意事项：

  1. 这只是一个空白的 OVF，没有包含 macOS 系统。导入 OVF 后挂载本站的 macOS iso 文件即可正常安装。

  2. 默认支持 ESXi 8.0，关于是否适用 Fusion 13 和 Workstation 17，参看下面两条。

  3. VMware Fusion 13 无需使用该模板。在 Fusion 中的 macOS 支持 3D 加速，通过其他方式实现。

  4. VMware Workstation 17 Unlocker for Windows or Linux 导入后无法识别 GuestOS ID，需要手动修改。

  5. VMware Workstation 17 中通过手动修改 GuestOS 也能运行，已验证支持 13 代 CPU（方法已经包含在下载中）。

  6. 如果硬件已经成功运行过上一个版本的 macOS，那么理论上也能成功运行 macOS Ventura。

  7. 如何调整屏幕分辨率？参看：如何安装 VMware Tools (macOS, Linux, Windows)。

  8. 能运行 macOS Ventura 不代表能用来替代 Mac，macOS 开启卓越性能的（唯一）平台是搭载 M 芯片的 Mac。

  9. macOS 虚拟机与 Mac 上的 macOS 体验有天壤之别。尽早加入 Apple 阵营，开启卓越体验吧。

  10. 不支持虚拟的 Metal CPU 加速或称 3D 加速，此功能仅限在 Fusion 中启用。这是虚拟化 macOS 卡顿的主要原因。

  11. 当前 vGPU RAM Size 最大限制为 256MB（实际只能使用 128MB），OVF 已默认配置。
