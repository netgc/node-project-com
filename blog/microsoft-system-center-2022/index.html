产品简介

简化数据中心管理

System Center - 让您的 IT 完全掌控不同的环境和平台。在提高灵活度和性能的同时，简化基础结构以及软件定义的虚拟化数据中心的部署、配置、管理和监控 (sysin)。

您会爱上 System Center 的 4 个原因

  • 加速时间价值

利用简便安装、就地升级和自动化工作流快速实现价值。

  • 高效运营

利用一键式功能和简单的控制台快速完成任务。

  • 支持异构环境

管理和监控 Windows Server、Linux、Unix、Hyper-V 和 VMware。

  • 云集成

利用 Azure 安全和管理集成获得对数据和应用程序的可见性和控制力 (sysin)。

System Center 解决方案

  • 基础结构预配

利用网络技术、存储、计算和安全等一整套综合性方案部署并管理您的软件定义数据中心。

  • 自动化和自助服务

利用自动化工作流进程和自助服务减轻组织负担并提高效率。

探索 System Center 解决方案

  • 基础结构和工作负载监控

诊断并检修基础结构、工作负载或应用程序问题以确保可靠性和高性能。

解决方案组件

System Center 2022 includes:

  • System Center Operations Manager：监控应用程序、工作负载和 Infrastructure 的运行状况、容量和使用情况。

  • System Center Orchestrator：自动化数据中心任务，使用原生 PowerShell 脚本高效创建和执行 Runbook。

  • System Center Virtual Machine Manager：通过全面的网络、存储、计算和安全解决方案 (sysin)，部署并管理虚拟化的、软件定义的数据中心。

  • System Center Service Manager：用于事件响应、变更控制和资产生命周期管理的自动化服务交付工具。

  • System Center Data Protection Manager：为私有云部署、物理计算机、客户端和服务器应用程序提供备份、存储与恢复，保护数据安全。
