新增功能

2025 年 12 月 11 日

微软宣布 System Center 2025 Update Rollup 1（UR1） 现已正式发布！本次更新为整个 System Center 产品套件带来了多项重要增强和修复，重点聚焦于安全性、兼容性和可靠性的提升。

✨ System Center 2025 UR1 有哪些新内容？

✅ 增强的安全性与兼容性

  • 支持 TLS v1.3

    System Center 2025 现已支持 TLS v1.3，在所有组件中提升安全性，并符合最新的加密与合规标准。

  • 支持 Microsoft SQL Server 2025

    所有 System Center 组件现已支持 SQL Server 2025，为数据中心运营提供更好的性能与可扩展性 (sysin)。当前运行在 SQL Server 2022 上的部署可无缝升级至 SQL Server 2025。

✅ 扩展的 Linux / Unix 平台支持

Operations Manager 2025 UR1 将监控能力扩展到最新的企业级 Linux 发行版：

  • Oracle Linux 10
  • Rocky Linux 10
  • Alma Linux 10
  • Red Hat Enterprise Linux（RHEL）Server 10
  • Debian 13

Operations Manager Linux Agent 现已支持 OpenSSL 3.x 发行版，确保符合现代安全要求。

✅ System Center Operations Manager（SCOM）

  • 已修复的问题

    已解决控制台内容阻塞、监视器创作失败、Web 控制台仪表板改进、S2D 工作流 WMI 错误、拓扑小组件问题，以及中文字符集 GB18030-2022 合规性问题。

✅ System Center Data Protection Manager（SCDPM）

  • 新增功能

    • Hyper-V 选择性磁盘排除：DPM 2025 UR1 新增在 Hyper-V 虚拟机备份中排除特定磁盘的能力。管理员可以选择性地将某些磁盘内容从还原点中排除，确保在 VM 恢复过程中不会覆盖被排除的磁盘 (sysin)，为备份存储与恢复场景提供更高的灵活性。
    • 支持 Exchange Subscription Edition：DPM 2025 UR1 现已支持 Exchange Subscription Edition 的应用感知备份，扩展了使用 Microsoft 365 混合部署组织的保护选项。
    • 增强的安全性与运行时环境：DPM 2025 UR1 要求安装最新的 Visual C++ Redistributable（2013、2015–2022 x64），确保运行环境符合最新的安全更新要求。

  • 已修复的问题

    • 已解决 SQL Server 强制加密保护、VMware 备份传输模式（NBDSSL）以及恢复页面本地化问题。
    • 包含所有 SCDPM 2022 UR3 与 DPM 2025 RTM 的修复内容。
    • 在适用场景中加入对中文字符集 GB18030-2022 的合规支持。

✅ System Center Service Manager（SCSM）

  • Update Rollup 1 新增内容

    • 支持最新的 MSOLEDBSQL19 提供程序
    • 增强的 Orchestrator 集成：支持连接 Orchestrator Web API 2022/2025，同时向后兼容 SCO 2019 Web Service

  • 已修复的问题

    • 所有输入字段支持中文字符集 GB18030-2022 合规性
    • 自助服务门户修复：知识文章图片显示正常，非英文字符的分享按钮不再被裁剪 (sysin)，修复包含 HTML 标签时的审批决策错误
    • 提升 MonitoringHost 与 GroupCalc 的稳定性

✅ System Center Orchestrator（SCO）

  • 已修复的问题

    已解决 Read Line 活动对特殊字符的处理问题、Monitor Event Log 崩溃、Invoke-Runbook 凭据持久化问题，以及 Runbook 测试器显示中的 GB18030-2022 中文字符集合规问题。
