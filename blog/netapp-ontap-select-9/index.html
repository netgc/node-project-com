NetApp® ONTAP® Select 软件定义的存储虚拟设备将云的敏捷性和精细容量扩展优势与内部部署存储的灵活性、故障恢复能力和数据定位融为一体。

强大的企业级软件定义存储 (SDS)

NetApp ONTAP Select 提供了一些强大的企业级存储服务，可以从您的自有数据中心轻松部署到自选的商用硬件上。它将云在灵活性和细粒度容量扩展方面的优势与内部存储的灵活性、故障恢复能力和本地性优势完美地结合在一起。

ONTAP Select 可将服务器的内部磁盘驱动器、NVMe、SSD 或 HDD 以及 HCI 和外部阵列存储转变为一个兼具灵活性和敏捷性的存储系统，该系统具有基于 NetApp® ONTAP® 数据管理软件的专用存储系统的许多优势。

ONTAP® Select 9 评估版部署说明

评估版 - ONTAP Select

产品概述

ONTAP Select 是 ONTAP 9 的纯软件版本，以虚拟设备（Virtual Appliance）的形式实现。它可在通用硬件平台上提供企业级存储管理解决方案。得益于虚拟化技术固有的灵活性，ONTAP Select 提供多种部署模式，以满足不同的业务需求和使用场景。

ONTAP Select 由两个主要软件组件构成：

  • ONTAP Select 节点镜像

    集群中的每个节点均以虚拟机形式部署，并运行专门设计的 ONTAP 9 软件衍生版本。

  • ONTAP Select Deploy 管理工具

    Deploy 管理工具作为独立的 Linux 虚拟机安装，用于部署 ONTAP Select 集群。

评估版部署支持的安装选项

部署带有评估许可证的 ONTAP Select 集群时，可选择以下两种方式：

  • 无需 Deploy，通过 OVF 模板安装到 VMware ESXi

    ONTAP Select 单节点集群以 OVA 文件形式提供。您无需使用 Deploy 管理工具，即可直接将 OVA 部署到 VMware ESXi 主机。此部署方式仅支持运行于 ESXi 上的单节点集群。

  • ONTAP Select Deploy 管理工具

    您必须先安装 Deploy 工具，然后使用它部署 ONTAP Select 集群。使用 Deploy 工具可以在所有受支持的虚拟化平台（ESXi 和 KVM）上创建由一个或多个 HA 对组成的多节点集群。

重要说明：

  • 本站提供的软件资源仅允许您部署带有评估许可证的 ONTAP Select 集群。
  • 您只能以 NODAR 方式部署 ONTAP Select 集群。
  • 不得在生产环境中使用评估集群。
  • 如果使用 Deploy 管理工具创建评估集群，后续可以升级为容量分层（Capacity Tiers）许可证，以用于生产环境。
  • 如果通过直接安装 OVF 模板创建评估集群，则不支持升级为用于生产环境的正式许可证。
  • 使用 Deploy 工具的安装和部署流程与直接安装 OVF 模板的流程不同。

以 OVF 模板打包的单节点集群概述

ONTAP Select OVF 模板提供了一种替代的 ONTAP Select 部署方式。您无需 ONTAP Select Deploy 工具即可快速部署单节点集群。相反，您可以通过 vSphere 将 ONTAP Select 节点镜像直接安装到 ESXi 虚拟化主机。

通过使用以单个 OVA 文件形式提供的 OVF 模板，您无需满足常规生产环境部署要求即可安装并评估 ONTAP Select。

ONTAP Select OVF 模板部署具有以下特性和限制：

  • 以单个 OVA 文件形式提供，便于下载和部署
  • 仅支持单节点集群（不支持多节点集群）
  • 包含 90 天评估许可证
  • 无需向 NetApp 申请序列号和容量许可证
  • 仅允许用于评估部署

OVF 模板安装的系统要求

OVF 模板安装的基本系统要求包括：

  • ESXi 版本：8.0 GA（Build 20513097 或更高版本）
  • 任意 VMware vSphere 许可证
  • 预留 16 GB 虚拟内存（vMemory）
  • 预留 4 个 vCPU 核心
