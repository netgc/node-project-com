大规模应用程序交付可能很复杂。

使用 NetScaler 让一切变得更简单。

一个平台，一致的应用程序交付和安全体验

因为没有人有时间学习多个系统来管理 ADC 部署

NetScaler 构建在具有基于软件架构的单一操作系统之上，因此无论您选择哪种 ADC 外形（硬件、虚拟机、裸机或容器），其行为都是相同的。

坚定地本地部署。一切都在云上。混合环境也很好。
无论您选择哪一个 (sysin)，NetScaler 在所有这些平台上的工作方式都是相同的。

为什么选择 NetScaler 进行应用程序交付？

无论您是向数亿消费者、数十万员工还是向两者交付应用程序，NetScaler 都可以帮助您可靠、安全地完成任务。

高性能

闪电般快速的应用程序交付，提供最佳的最终用户体验：

  • 一次性架构可实现最低延迟和最佳 CPU 利用率
  • 互联网盲点检测和动态路径选择，提供最佳应用体验
  • 动态扩展混合和多云工作负载的互联网流量，以实现高达 6.4 Tbps 的 L7 吞吐量的集群

全面安全

跨环境对应用程序和 API 进行统一保护，且不影响性能：

  • 大规模 Web 应用程序防火墙 (WAF) 和容量机器人防护
  • 对内部和外部应用程序的零信任网络访问 (ZTNA) 访问
  • 本机集成身份验证和单点登录体验 (sysin)

深度可观察性

实时洞察和丰富的分析可实现最佳应用程序性能和更快的故障排除：

  • 根据应用程序最终用户位置和实时互联网条件推荐最佳数据中心、云和 CDN
  • 使用全局服务图更快地排除单体和微服务应用程序的故障
  • 与 Splunk、Prometheus 等集成

外形尺寸

软件

  • 虚拟机 (VPX)
  • 容器（CPX）
  • 裸机 (BLX)

硬件

  • 单租户 (MPX)
  • 多租户 (SDX)

NetScaler VPX Express 许可证

适用于本地部署和云部署的 VPX Express 不需要许可证文件，它提供以下功能：

  • 20 Mbps 带宽
  • 所有 ADC 标准许可证功能，NetScaler Gateway 以及 L4 和 L7 防御除外
  • 最多 250 个 SSL 会话
  • 20 Mbps SSL 吞吐量

您可以将 VPX Express 许可证升级到以下两个选项：

  • 独立的 NetScaler VPX 许可证。
  • 适用于 VPX 实例的 NetScaler 池容量许可证。

重要

  • 群集功能在 VPX 公有云的 Standard Edition 和 VPX Express 许可证中可用。

NetScaler Build 13.1- 58.21

2025 年 4 月 22 日

提示：该版本说明文档不包含与安全相关的修复内容。有关安全修复和公告的详细信息，请参阅 Citrix 安全公告。

Build 58.21 | NSCONFIG-3188：如果满足以下一系列条件，用户可能无法登录降级后的 NetScaler 设备：

  • 执行了以下任一操作：
    • 升级至当前构建后，添加系统用户或更改现有系统用户的密码，并保存配置。
    • 使用当前构建部署新的 VPX、BLX 或 CPX 实例 (sysin)。
  • 将设备降级至以下任一版本：
    • 13.0-47.x 或更早版本
    • 12.1-56.x 或更早版本
    • 11.1-64.x 或更早版本

要查看降级后受影响的用户列表，请在命令行中执行：query ns config -changedpassword [-config <full path of the configuration file (ns.conf)>]

解决方法：重置受影响用户的密码。

注意：如果是对已升级的构建进行降级，建议在降级时使用之前构建的配置文件（ns.conf）备份以避免此问题。User Interface

Build 58.21 | NSCONFIG-8068：与上一个问题类似，但影响的构建版本不同：

  • 执行以下任一操作：
    • 升级至当前构建后，添加系统用户或更改现有系统用户的密码，并保存配置。
    • 使用当前构建部署新的 NetScaler VPX、BLX 或 CPX 实例。
  • 将设备降级至以下任一版本：
    • 13.1-4.x
    • 13.0-82.x 或更早版本
    • 12.1-62.x 或更早版本

看受影响用户的命令及解决方法与上条一致。User Interface

Build 58.21 | NSHELP-36166：无法通过 NetScaler GUI 中的 Security > SSL Forward Proxy > SSL Interception Policies 添加 SSL 拦截策略。User Interface

Build 58.21 | NSHELP-36271, NSCONFIG-8406：在执行 showrun 命令时若中断，NetScaler 会终止会话，影响任务继续进行。User Interface

Build 58.21 | NSHELP-36747, NSCXLCM-3290：在启用速率限制功能的配置文件中编辑 “Rate Limit Condition” 字段时，可能会出现如下错误：An entity with the name is already bound, No such bind resource。User Interface

Build 58.21 | NSHELP-37188：在 NetScaler GUI 中，通过 System -> Diagnostics -> Pre v/s Post Upgrade -> Export diff report 导出差异报告的功能无法正常工作。User Interface

Build 58.21 | NSHELP-37268：在 BLX Web UI 中，点击 System > Diagnostics 页面的 Generate support bundle 后，支持包生成失败，并显示以下弹窗信息：Operation not permitted [Partition is not supported in CPX/BLX]。User Interface

Build 58.21 | NSHELP-37454：在 NetScaler GUI 中为虚拟服务器持久性组配置基于规则的持久性时，可能无法配置备份持久性。但可通过 NetScaler CLI 完成该配置。User Interface

Build 58.21 | NSHELP-37597, NSCXLCM-6662, …（多编号省略）：当 NetScaler 上配置的服务数量超过 500 时，NetScaler 进程可能无法将数据写入磁盘，导致 newnslog 文件中数据缺失。User Interface

Build 58.21 | NSHELP-38323：启用了 enablelocal 选项后，如果在启用强密码功能时排除了 Probe vserver 命令，功能不会按预期工作。User Interface
