产品优势

数字工作空间的身份解决方案

  • 通过条件访问保护您的环境

    通过基于设备状态、用户行为和位置的条件访问来保护公司资产。

  • 平衡用户体验和安全性

    在最终用户需要时为他们提供所需的内容，同时实时定制访问权限和管理风险。

  • 与身份和安全生态系统集成

    轻松与领先的 IDP 集成，实现交钥匙配置和管理。将安全信号纳入访问决策中。

功能特性

为什么选择 Access？

  • 访问代理

    与领先的身份提供商集成，以减少部署时间并支持更安全地访问任何应用程序。

  • 自适应多因素身份验证 (MFA)

    提供本机 MFA 或与现有 MFA 提供商集成，以更好地保护对应用程序和数据的访问，并为最终用户提供低摩擦体验。

  • 单点登录 (SSO)

    通过与 Omnissa Workspace ONE® Intelligence Hub 集成，提供对 Web、SaaS、移动和旧版应用程序的单点登录。

  • 基于风险的条件访问

    创建和实施利用设备注册、网络、用户行为、位置以及第三方安全信号和信息的访问策略。

使用案例

解决您最棘手的挑战

在不影响安全性的情况下提供对应用程序和数据的一致访问具有挑战性。 Omnissa Access 可以提供帮助。

  • 启用零信任

    平衡风险并持续验证设备、用户和应用程序上下文，以提供对公司资源的最低权限访问。

  • 加速应用程序部署

    提供对任何设备上任何应用程序的本质安全、有条件的访问。通过基于复杂身份、设备和应用程序组合的代理访问来加快部署时间。

  • 单点登录

    持续验证用户、设备和登录上下文，以提供高度安全的单点登录并提高员工工作效率，同时保护公司资产。

新增功能

Omnissa Access 26.07

Omnissa Access 26.07 是版本 24.12.x 的后继版本，基于全新的架构进行构建。在以前的版本中，Omnissa Access 作为单个独立的虚拟设备来交付。从 26.07 开始，Omnissa Access 作为一组容器化微服务来交付，这些微服务在控制平面上运行，该控制平面是一个自动化平台，可安装、运行、扩展和监控构成 Omnissa Access 的服务。

重要信息：由于 Omnissa Access 26.07 基于新的部署架构，而不是对现有设备的更新，因此该版本仅可进行全新安装。不支持从任何以前的 Omnissa Access 虚拟设备版本进行升级。

尽管底层架构是新的，但 Omnissa Access 的日常管理方式与以前的版本类似。

  • 与以前的版本相比，管理控制台基本保持不变。
  • Omnissa Access Connector (s) 的激活过程和体验保持不变。

Omnissa Access 26.07 继续包含 Hub Services；Hub Services 是一项与 Omnissa Access 位于同一位置的服务，您可以通过该服务设计并设置员工如何使用 Workspace ONE® Intelligent Hub 应用程序来访问、发现和连接到公司内的企业资源、团队和工作流。用户可使用其设备上的 Workspace ONE Intelligent Hub 应用程序或 Web 浏览器中的 Hub 门户来访问员工参与功能。

新增功能

✅ 新增，2026 年 8 月 10 日 - Access 部署向导

现在提供了新的 Access 部署向导，可帮助简化 Omnissa Access 26.07 内部部署版本的部分部署过程。该向导将许多手动配置步骤整合到一个引导式自动化工作流中。您可以使用该向导作为手动执行这些步骤的替代方法。该向导会收集所需的信息、生成配置文件、验证输入，并按正确的顺序执行部署任务，从而有助于降低复杂性并最大限度地减少错误。

✅ 微服务

以前版本的 Omnissa Access 作为在虚拟设备内运行的单项服务来交付，但 Omnissa Access 26.07 已重新构建为一组独立的服务，每项服务都作为由控制平面编排的单独工作负载运行。由于各项服务已分离，因此可以单独更新、重新启动、扩展和恢复这些服务。

新模型还使内部部署产品与 Omnissa Access 云部署版本保持一致，从而将以前仅限云部署版本的功能引入到内部部署。

✅ 新的控制平面架构

Omnissa Access 26.07 引入了基于控制平面框架的新部署模型，从而取代了以前基于 OVA 的虚拟设备。该控制平面使用 Nomad、Consul 和 Vault 跨专用虚拟机集群编排所有平台服务、基础架构服务和 Access 应用程序服务。

版本 26.07 包含以下组件：

  • 平台服务：
    • Nomad：用于编排工作负载
    • Consul：用于发现服务和进行内部通信
    • Vault：用于管理密钥、证书、令牌
  • 基础架构服务：
    • PostgreSQL：数据库
    • Redis：缓存和队列
    • Kafka：事件流式传输和消息传递
    • OpenSearch：分析
  • Omnissa Access 应用程序服务：构成 Omnissa Access 26.07 的一组微服务。

您可以从单个位置（即引导节点）来管理部署。

✅ 命令行界面

新的命令行界面 WSO CLI 是部署和管理 Omnissa Access 26.07 的主界面。

✅ 新增功能

Omnissa Access 26.07 包含以下新功能，这些功能以前仅在 Omnissa Access 云部署版本中提供。借助新的微服务和控制平面架构，这些功能现在首次可在内部部署中使用。

  • 身份验证方法和功能
    • Pass 应用程序“基本”（不支持推送通知）
    • FIDO2
    • 移动 SSO（适用于 Apple）
    • 平台 SSO（适用于 macOS）
    • Verify (Intelligent Hub)
    • DUO 安全
    • 令牌身份验证适配器
    • 身份验证访问策略规则选项
  • OAuth 2.0 和 OpenID Connect
    • 对 OpenID Connect 应用程序的用于代码交换的证明密钥 (PKCE) 支持
    • 公共和机密 OAuth 2.0 用户访问客户端
    • 对 OAuth 2.0 和 OpenID Connect 端点的跨来源资源共享 (CORS) 支持
    • 使用第三方身份提供程序的密码验证
  • 特定于自定义应用程序的访问策略
  • 基于 IP 地址的会话令牌绑定
  • 与 SIEM 系统集成 - Syslog、Splunk 和 CrowdStrike
  • Omnissa Identity Service 内部部署版本

✅ Omnissa Identity Service

Omnissa Identity Service 现在与 Omnissa Access 26.07 捆绑在一起，用于内部部署。Omnissa Identity Service 可将 Omnissa 产品和服务与第三方基于云的身份提供程序（如 Microsoft Entra ID 和 Okta）集成，以进行用户置备和身份联合，从而实现跨 Omnissa 平台的集中式用户管理。

✅ 已弃用的功能

Omnissa Access 26.07 不包含用于移动 SSO（适用于 iOS）身份验证方法的内置密钥分发中心 (KDC)。Omnissa 建议改用移动 SSO（适用于 Apple）身份验证方法。
