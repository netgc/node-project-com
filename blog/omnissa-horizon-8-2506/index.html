Horizon 8

formerly VMware Horizon

通过从本地到云端高效、安全地交付虚拟桌面和应用程序，提升数字工作空间体验。

随时随地访问虚拟桌面和应用程序

  • 从云端管理

    使用基于云的控制台和 SaaS 管理服务跨私有云、混合云和多云基础设施高效管理桌面和应用程序。

  • 提供端到端安全性

    利用 Horizon 基础设施内置的内在安全性来获得对企业资源的高度安全的远程访问 - 提供从设备到数据中心再到云的保护。

  • 提高投资回报率

    借助行业领先的 VDI、DaaS 和应用程序平台实现跨私有云和公共云的灵活部署选项，从而节省成本并实现业务价值。

新增功能

Horizon 8 2506 | 2025 年 7 月 31 日

借助 Horizon 8，IT 部门可在数据中心内运行远程桌面和应用程序，并将这些桌面和应用程序交付给员工。最终用户可以获得熟悉的个性化环境，并可以在企业或家庭中的任何地方通过任意数量的设备访问此环境。通过将数据集中到数据中心，管理员可以进行控制并提高效率和安全性。

✅ Nutanix AHV 支持 – 有限可用性

作为 Horizon 8 2506 版本的一部分，Horizon 8 对 Nutanix AHV 的支持现在处于“有限可用性” (LA) 状态。有限可用性 (LA) 是我们软件发布周期的一个阶段，这意味着 Horizon 8 对 Nutanix AHV 的支持是一项可用于生产的功能，受 Omnissa 的完全支持，并可供选定的合格客户使用。这是通向正式发布的一步，由于受到 Omnissa 的完全支持，因此可以将其用于生产环境。

管理员可以在 Nutanix AHV 上部署 Horizon 8 基础架构，并将 Horizon 8 配置为与 Nutanix Prism Central 集成，以便置备自动池。内部部署和 NC2 (Nutanix Cloud Clusters) 部署均支持此功能。

✅ 许可证激活

  • 在此版本中，为了遵守 Broadcom 剥离协议，将从 Horizon Connection Server 中移除所有 VMware (Broadcom) 许可证模块。系统将完全过渡到 Omnissa 许可证模块支持，从而简化许可过程并确保合规性。更新范围将涵盖 LDAP、服务器代码、许可证文件和 cart 模块。
  • 2412 版本中为短期许可证和永久许可证引入了一个新许可模块。虽然现有许可证密钥仍受支持，但如果您使用的是短期许可证或永久许可证，我们强烈建议您使用新的 Omnissa 许可证激活 Horizon 8。
  • 可通过 Customer Connect 门户获取新的 Omnissa Horizon 许可证密钥。横幅通知将提示您升级到新的 Omnissa 许可证，您将有 60 天的时间来完成此转换 (sysin)。如果未能在此期限内更新许可证密钥，将导致 Horizon Console 进入受限模式。请参阅《Horizon 8 安装和升级》指南中的 “为 Horizon 8 启用订阅许可证和 Horizon Control Plane 服务” 。
  • 已取消订阅许可证的 15 天宽限期。如果在未使用 Horizon Edge 的情况下在 Horizon 8 中激活订阅许可证，则必须每 90 天重新激活一次，以保持完整功能。但是，如果您正在使用 Horizon Edge，则将自动激活许可证。
  • Horizon Console 中的许可和使用情况屏幕包含一个订阅结束日期字段。当可从 Horizon 控制平面获得数据时，此字段将显示订阅许可证的结束日期。否则，此字段将显示“不适用”。

✅ Horizon Connection Server

  • 要提高连接服务器集群的适应性和性能，必须在所有服务器中使用一组通用的加密证书和签名证书。为保持安全性，加密证书应每 24 小时轮换一次。这种方法可以防止在某些服务器脱机时服务中断，并减少由多个 POD 产生的过多元数据文件导致的 WS1 数据库负载。通过利用现有集群证书进行签名并创建匹配的加密证书，可以最大限度地减少各个服务器的元数据调用，从而确保在整个集群中运行更顺畅、更高效。
  • Horizon 8 版本 2503 仅在绿地部署中引入了对 Windows 2025 的支持。由于 Microsoft 对 AD LDS 功能级别支持的限制，Pod 或联合中的混合操作系统版本将受到限制。但是，知识库文章 6000960 中提供的脚本可以验证环境就绪情况并配置 Windows 2025 所需的功能级别，从而使客户能够将支持扩展到棕地部署。
  • 作为 Universal Brokering 的一部分，连接服务器通过使用 Horizon Cloud JWT 身份验证器，支持从 Horizon Cloud 重定向的会话启动请求。这些身份验证器可以由 Horizon Cloud 自动管理，也可以由管理员手动管理。借助此项更新，管理员可以通过连接服务器身份验证部分中的新 UI 工作流来管理 Horizon Cloud 身份验证器 (sysin)，这类似于 SAML 支持。
  • 我们最近更新了订阅比较表，以反映 Helpdesk 功能授权的扩展。它现在包含在以下 SKU 中：Horizon for Linux、Horizon Standard、Horizon Advanced、Horizon Apps Standard 和 Horizon Apps Enterprise。以前，此功能仅限于 Horizon Enterprise SKU 和 Horizon Apps Enterprise SKU。根据此更新，我们进行了必要的更改，从 2506 和 2503.1 ESB 版本开始，将为与上述 SKU 关联的所有短期许可证启用 Helpdesk 功能。对于 2503 及更低版本，Helpdesk 功能仍然只适用于 Horizon Enterprise 和 Horizon Apps Advanced 短期许可证，而不适用于其他 SKU。
  • 现在，您可以在 LDAP 中将“helpdesk-privacy-setting”设置为“打开”，这将“隐藏”“Helpdesk 应用程序”选项卡上显示的“应用程序名称”。默认情况下，该设置的值为“关闭”。
  • 当 Horizon 环境中存在多个 Active Directory 域时，管理员现在可以配置 Horizon Client 中显示的域列表排序顺序。

✅ Horizon Console

  • 在此版本之前，CPA 全局授权只能通过 API 进行管理，这限制了首选使用 GUI 的管理员的可访问性。我们在 GUI 中增加了一个用户友好的界面，可以直接启用或禁用 CPA 全局授权。该界面包括带确认提示的选项开关控件、清晰的授权状态可见性以及强大的错误处理功能，可确保与现有 API 功能无缝集成。

  • 用于数据网格的高级筛选器组件：现在，以下屏幕中提供了增强的筛选和排序选项：

  • 清单 > 桌面 > 计算机 网格

  • 清单 > 桌面 > 会话 网格

  • 清单 > 场 > 会话 网格

  • 监控 > 会话 网格

  • 清单 > 计算机（“vCenter”、“RDS 主机”、“其他”、“容量提供程序”选项卡） 网格

✅ Horizon Agent for Linux

  • 在此版本中，Linux 代理支持用于增强渲染（渲染加速）的 A 配置文件 vGPU。当前不支持视频编码卸载功能，因为此功能将由软件执行。现在，Horizon 支持对在 Linux 端点上访问的桌面会话和远程应用程序进行浏览器内容重定向 (BCR)，方法是从远程桌面（而不是客户端端点）提取 Google Chrome 中的 Web 内容，同时继续在客户端上呈现这些内容。
  • 除了已受支持的 RHEL 8.x 外，数字签名的 .rpm 安装程序软件包现在还支持安装到 RHEL 9.x 上。

✅ Horizon Agent for Windows

  • 使用反向连接时，Blast 协议现在会创建第二个反向连接，该反向连接将保持空闲状态。在客户端和 Blast 安全网关之间的网络中断期间，这个空闲的反向连接随时可以启动 (sysin)，并能更快地重新连接用户。
  • 自动续订 Blast 自签名证书：Blast Agent 现在支持在自签名 TLS 证书过期之前自动更换该证书。
  • 适用于 Windows 的 Horizon Client 现在可以连接到 Horizon Cloud next-gen Universal Broker。

✅ Horizon 8 和 Amazon WorkSpaces Core

  • Amazon WorkSpaces Core 上的 Horizon 8 现在支持使用多会话 Windows Server 2019 和 2022 主机的自动远程桌面会话 (RDS) 场。这样，客户就可以通过远程桌面会话主机 (RDSH) 来交付已发布的桌面和应用程序。客户可以利用 AWS 公有自带协议 (BYOP) 服务器包来创建自定义的 RDSH 最佳配置映像。此外，还支持 App Volumes Apps on Demand，从而允许向用户实时地动态交付应用程序，而无需在场主机上预安装应用程序。

✅ 远程桌面功能

  • 添加了用于配置 IpPrefix 注册表项的组策略支持：从 Horizon Agent 2506 开始，管理员可以使用 GPO 指定由多网卡虚拟机上的 Horizon Agent 使用的子网，从而简化了部署和管理。
  • Mac 上适用于 VDI/会话的单个应用程序共享：在 Horizon VDI/会话模式下，Mac 端点上的最终用户现在可以在 Teams 屏幕共享会话期间共享单个应用程序或窗口。
  • 自动续订 Blast 自签名证书：Blast Agent 现在支持在自签名 TLS 证书过期之前自动更换该证书。
  • Linux 和 Mac 支持自定义背景图像：在 Horizon VDI/会话模式下，Linux 和 Mac 端点上的最终用户现在可以在 Microsoft Teams 中使用自定义背景图像 (sysin)，从而增强了个性化和隐私性。
  • 已将 URL 扩展更新为 Manifest V3：升级了该扩展以使用 Chrome 的 Manifest V3。
  • Linux 客户端上已发布的 Chrome 和 Edge 应用程序现在支持浏览器内容重定向 (BRC)：作为已发布的应用程序交付时，此增强功能可在 Chrome 和 Edge 中启用完整的 BCR 功能。
  • 客户端上的屏幕截图：此功能允许跨多个显示器进行定制屏幕截图，这增强了用户控制能力，提高了多显示器工作流的灵活性。
  • 多个具有扫描仪重定向功能的设备：弹出窗口将显示已重定向到 VDI/RDSH 会话的所有已连接扫描仪，从而允许您直接在该应用程序中选择或切换扫描仪。
  • 支持拖放已发布的浏览器：此增强功能支持涉及基于浏览器的拖放文件导入操作的常见工作流，并且适用于 Windows 和 Mac 客户端。
  • 支持对 Blast MKS/音频使用 Vvc 原始通道：使用专用传输通道和可配置的协议模式提高了实时音频性能和可扩展性。

✅ 虚拟桌面和应用程序

  • 间接显卡驱动程序 (IDD) 现在是 Horizon 的默认显卡驱动程序。通过利用虚拟机底层硬件 GPU 的渲染和编码功能，Horizon 间接显卡驱动程序支持按照较高的帧速率，以最佳方式呈现应用程序。在使用多会话池和高工作负载 3D 应用程序（如设计和建模软件）时，此功能可提供性能方面的优势。

✅ 适用于 Omnissa Horizon 的 Windows 操作系统优化工具

  • 预检查：此功能会在执行“通用化”操作之前，先运行检查表以确保虚拟机稳定性。
  • 新版本包含修复了此前所报告问题的更新。有关此版本中已修复问题的列表，请参阅已解决的问题。
