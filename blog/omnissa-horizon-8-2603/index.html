Horizon 8

formerly VMware Horizon

通过从本地到云端高效、安全地交付虚拟桌面和应用程序，提升数字工作空间体验。

随时随地访问虚拟桌面和应用程序

  • 从云端管理

    使用基于云的控制台和 SaaS 管理服务跨私有云、混合云和多云基础设施高效管理桌面和应用程序。

  • 提供端到端安全性

    利用 Horizon 基础设施内置的内在安全性来获得对企业资源的高度安全的远程访问 - 提供从设备到数据中心再到云的保护。

  • 提高投资回报率

    借助行业领先的 VDI、DaaS 和应用程序平台实现跨私有云和公共云的灵活部署选项，从而节省成本并实现业务价值。

新增功能

Horizon 8 2603 | 2026 年 4 月 14 日 | 内部版本：8.18.0-24169897839

借助 Horizon 8，IT 部门可在数据中心内运行远程桌面和应用程序，并将这些桌面和应用程序交付给员工。最终用户可以获得熟悉的个性化环境，并可以在企业或家庭中的任何地方通过任意数量的设备访问此环境。通过将数据集中到数据中心，管理员可以进行控制并提高效率和安全性。

重要说明

  • 对于运行使用 Nutanix 的 Horizon 8 2512 自动池或场的客户：2603 中的一项配对机制更改要求连接服务器和代理都必须更新到 2603，这样正在进行的置备操作才能正常执行。如果已升级到 2512.1，则不适用。

  • vSphere 6.5 或 vSphere 6.7 不支持 Horizon 8，这两个版本都已超过一般支持期限。Horizon 8 Instant Clones 与这两个 vSphere 版本不兼容，您必须先升级到 vSphere 7.0 或更高版本 (sysin)，然后再升级到 Horizon 8，才能使用即时克隆。

  • 重要的生命周期里程碑：

    • Horizon 2512 是支持 vSphere 7.x 的最后一个版本。

    • Horizon 2603 ESB 将不支持 vSphere 7.x。

      必需操作：您必须通过 2603 ESB 升级到 vSphere 8.x 或 9.x 才能保持完全受支持状态。

新增功能

Horizon Connection Server

  • 此版本在 CPA 中引入了下一个首选站点逻辑，可在站点已满时改进路由。现在，管理员可以定义首选站点顺序，而不是随机回退。CPA 将按照此顺序选择下一个可用站点，从而提供更可预测的路由、更出色的性能以及改进的负载均衡。
  • 管理员可以创建由未受管手动池提供的已发布应用程序。
  • 现在，Horizon 可跨未联合的 Pod 收集授权。这样，用户便可通过 Horizon Client 获得内部部署环境和托管环境中桌面和应用程序的单一视图。
  • 借助 SAML 元数据功能，管理员可以在 Cloud Pod 架构 (CPA) 级别配置安全断言标记语言 (SAML) 身份验证设置。通过此功能，可以集中控制 Omnissa 环境中多个 Pod 部署之间的 SAML 元数据分发、证书管理和实体标识 (sysin)。
  • 现在，连接服务器在配置了兼容密码套件的情况下，支持上载“vdm”证书的椭圆曲线 (EC) 证书。

Horizon Console

  • 在 Horizon 8 中为 MS SQL 事件数据库添加了对 Windows 集成身份验证 (IWA) 的支持，从而无需存储或轮换数据库凭据。管理员可以直接在 Horizon Console 中选择 SQL 身份验证或 IWA。选择 IWA 时，用户名/密码字段处于隐藏状态。此版本还支持用于事件数据库的 PostgreSQL 17。

此版本在 Horizon Console 中添加了一个用于管理全局 SAML 身份验证器的界面。这样，管理员便可在一处查看、创建、更改和管理身份验证器及其连接的连接服务器。

  • 现在，提供了一个从最佳配置映像复制选项，以便在 Nutanix 池和场工作流期间选择网络。
  • 可以在 Nutanix 池和场工作流期间指定同步后脚本和关机脚本。
  • 此版本通过增强的键盘导航、屏幕阅读器支持、焦点处理、对比度和表单标记功能，改进了整个 Horizon Console 的可访问性，以更好地与 WCAG 2.2 AA 准则保持一致。
  • 现在，Horizon Console 可显示向连接服务器注册的 UAG 的基本运行状况信息，包括服务状态和网关证书运行状况，从而提供必要的基础架构可见性。
  • 通过防止在 Recording Server UI 和 API 响应中公开数据库密码 (sysin)，增强了安全性。在配置工作流中添加了遮罩显示并改进了密码处理。
  • 在高级筛选器模式中添加了搜索未分配的虚拟机和支持自定义筛选器的功能。
  • 现在，管理员可以在创建非永久桌面池时直接从 Horizon Console 中启用 Workspace ONE UEM 管理，因为对永久桌面池的支持现已提供。此增强功能将 Workspace ONE UEM 扩展到物理设备、移动端点和 Horizon VDI，可通过单个控制台提供统一的实施后管理体验。该集成可确保从第一天起就应用一致的策略，简化操作，增强合规性和安全性，并降低总体拥有成本。

Horizon Agent for Linux

  • 现在，Horizon 支持将超过 15 个字符的虚拟机名称用于 Linux VDI 桌面池，从而消除以前的命名模式限制。Windows VDI 继续支持使用最多 15 个字符。
  • 为 Horizon Linux 虚拟桌面添加了对 Red Hat Enterprise Linux (RHEL) 8.x 和 9.x 上 MATE 桌面环境的支持。
  • 现在，Horizon Linux Agent 使用特定于代理的独立智能卡服务 (pcscd-horizon)，而不是覆盖系统 /usr/sbin/pcscd，从而确保与操作系统智能卡服务安全共存并提高系统稳定性。
  • 添加了对 Debian 12.13、Debian 13.3 和 Rocky 9.7 的支持。
  • 更新了 NVIDIA vGPU 支持：Horizon Agent 2603 添加了对 NVIDIA vGPU 版本 16.13、18.6、19.4 和 20.0 的支持。

Horizon Agent for Windows

  • 现在，Horizon Windows Agent 包含用于桌面会话的 Blast 系统托盘图标。通过该图标，可以一目了然地查看会话体验（包括网络连接质量），并可方便地访问与 Blast 相关的会话信息。如果需要，可以使用管理策略（Blast 系统托盘）来禁用该图标。
  • 添加了相应支持，使最终用户能够通过按 Ctrl+Alt+F12 键盘快捷键，立即断开与远程桌面或应用程序会话的连接。默认情况下将禁用此功能。管理员可以通过 viewClient.enableSessionDisconnectHotKey 设置来启用此功能。
  • 改进了 Horizon Windows Agent 中的 IP 地址选择逻辑，可优先将可路由的 IPv4/IPv6 对用于 Blast 连接，从而消除了由不可路由的接口（例如，内部 Hyper-V 网卡）导致的故障，而无需进行其他配置。
  • 更新了 NVIDIA vGPU 支持：Horizon Agent 2603 添加了对 NVIDIA vGPU 版本 16.13、18.6、19.4 和 20.0 的支持。

远程桌面功能

  • 现在，Horizon 引入了强制身份一致性功能，这是一项安全增强功能，可确保只有启动桌面或已发布应用程序的授权用户才能登录到该会话，即使在单点登录 (SSO) 不可用的情况下也是如此。
  • 以前版本中的一些性能增强现已扩展为支持 BSG。
  • 此版本允许您直接从 Horizon Cloud Universal Console 创建包含 Horizon 8 RDSH 场桌面的池组，从而改进了 Universal Broker。通过同步 RDSH 场并增强与控制平面的集成 (sysin)，您可以更无缝地整合多会话资源、优化资源利用率，以及从一个中心位置管理混合环境。
  • 添加了对在 Workspace ONE 模式下进行 URL 内容重定向的支持。

Windows OS Optimization Tool

适用于 Omnissa Horizon 的 Windows 操作系统优化工具

  • 添加了对使用 OSOT SCCM 插件的支持，以简化与 SCCM 的集成，并简化任务序列创建和部署工作流。Windows 11 24H2 和 Windows 11 25H2 支持该插件。
  • 添加了对在 SCCM 任务序列中执行 sysprep 期间使用自定义 unattend.xml 的支持，从而允许配置语言、区域设置、时区、用户账户和其他 Windows 设置参数。这取代了默认的“应用 Windows 设置”步骤。
  • 添加了对使用任务序列导入脚本的支持，以简化 OSOT 部署并自动执行任务序列配置。
