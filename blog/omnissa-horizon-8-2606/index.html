Horizon 8

formerly VMware Horizon

通过从本地到云端高效、安全地交付虚拟桌面和应用程序，提升数字工作空间体验。

随时随地访问虚拟桌面和应用程序

  • 从云端管理

    使用基于云的控制台和 SaaS 管理服务跨私有云、混合云和多云基础设施高效管理桌面和应用程序。

  • 提供端到端安全性

    利用 Horizon 基础设施内置的内在安全性来获得对企业资源的高度安全的远程访问 - 提供从设备到数据中心再到云的保护。

  • 提高投资回报率

    借助行业领先的 VDI、DaaS 和应用程序平台实现跨私有云和公共云的灵活部署选项，从而节省成本并实现业务价值。

新增功能

Horizon 8 2606 | 2026 年 8 月 24 日 | 内部版本：8.19.0-32260804026

借助 Horizon 8，IT 部门可在数据中心内运行远程桌面和应用程序，并将这些桌面和应用程序交付给员工。最终用户可以获得熟悉的个性化环境，并可以在企业或家庭中的任何地方通过任意数量的设备访问此环境。通过将数据集中到数据中心，管理员可以进行控制并提高效率和安全性。

重要说明

  • Horizon 2606 Agent 同时支持 2603 ESB Server 和 2606 Server 版本。
  • 对于运行 Horizon 8 2512 和 Nutanix 自动化池或场的客户：2603 中的配对机制发生了变化，因此 Connection Servers 和 Agents 必须同时更新到 2603 或更高版本，后续置备操作才能正常运行。要为环境准备有限的向后兼容性，请参阅 KB 文章 6001315。如果您已经升级到 2512.1 或更高版本，则不适用。
  • Horizon 8 不支持 vSphere 6.5 或 vSphere 6.7，这两个版本均已结束一般支持。Horizon 8 Instant Clones 与这些 vSphere 版本不兼容，因此在升级到 Horizon 8 以使用 Instant Clones 之前，必须先升级到 vSphere 7.0 或更高版本。

新增功能

Horizon Connection Server

  • Connection Server 安装程序现在会在安装期间自动停止并禁用 Active Directory Web Services (ADWS)，从而减少默认的安全暴露面。ADWS 并非 Connection Server 正常运行所必需，并且可以在临时需要时通过 Horizon Advisor 的 AD LDS Operations 菜单启用。
  • 此版本在 Cloud Pod Architecture (CPA) 中引入了下一个首选站点逻辑。管理员可以定义明确的首选站点顺序，这样当初始站点达到容量上限时，会将会话路由到下一个配置的站点，而不是随机回退。
  • 新的 AD LDS 迁移脚本允许大型 CPA 部署的客户在较长的迁移周期内从旧版 AD LDS 分区迁移到新的 Horizon 分区。它支持分阶段迁移，因此可以在不同的维护窗口中分别迁移独立的 Pod，同时保持 CPA 正常运行 (sysin)。管理员可以在迁移期间从全局授权中添加或移除本地池、创建或删除全局授权以及执行站点操作，从而降低大型多 Pod 部署中的风险和停机时间。此脚本现已作为 Horizon Advisor 的一部分提供，不再作为独立脚本提供。
  • PSG (PCoIP Secure Gateway) 现在可以在 Horizon Connection Server 安装过程中作为可选组件进行选择。
  • 管理员现在可以在 Nutanix Golden Image 上升级、修改、修复或重新安装 Horizon Agent，而无需更改其 Windows 主机名（计算机名称）。现有注册信息会得到保留，池操作不受影响，同时安装程序工作流经过优化，可避免不必要的重新注册和配对操作。
  • Microsoft 引入了使用 Microsoft Entra Kerberos 的 Microsoft Entra Hybrid Join，可显著改善 Entra ID Hybrid Managed 模式下的同步等待时间。
  • Horizon Agent Auto-Upgrade (AAU) 现在支持 Nutanix AHV 环境。管理员可以将自动化 Agent 生命周期管理扩展到由 Nutanix AHV 托管的桌面池，同时继续支持现有的 vSphere 环境。
  • Connection Server LCM API 安装和升级现在引入了新的密码要求，具体要求根据安装类型和托管方式而有所不同。
  • True SSO 解锁现在支持任何第三方 SAML Identity Provider，此外还支持 Workspace ONE Access。Identity Provider 必须支持使用 HTTP POST 绑定针对 AuthnRequests 的 SP 发起式 SSO。
  • 管理员现在可以使用手动 RDSH Farms 按需创建 App Volumes 已发布应用程序 (sysin)，除了现有的对 Instant Clone 自动化 RDSH Farms 的支持之外。
  • Horizon 8 现在使用与 Horizon Cloud 相同的逻辑计算 Concurrent Connection User (CCU) 许可证消耗量，使管理员和许可证团队能够在两个平台上获得准确且一致的使用量统计。新的 REST API 还允许 UI 和 Edge Gateway 获取历史峰值和每日 CCU 数据，减少对手动或不可靠跟踪方式的依赖，并为许可证团队提供用于合规和容量规划的数据。
  • Horizon 组件已更新为使用 OpenSSL 3.5，替代此前即将结束生命周期的 OpenSSL 3.0.x 库。这包括 Connection Server 和 Unified Access Gateway (UAG) 使用的 Blast Secure Gateway (BSG)。

Horizon Console

  • 管理员现在可以直接从 Horizon Console 以 Pod 为级别监控 Unified Access Gateway (UAG) 的运行状况和使用情况，显示每个 UAG 设备的实时可用性状态、服务运行状况、错误详细信息以及证书到期状态。
  • 已发布应用程序新增 Isolated App Launch 设置。启用后，每次启动应用程序都会在新的独立 RDSH 会话中运行，而不是复用现有会话。
  • JWT authenticator 配置现已移至 Horizon Console 中的 Global Settings > Authenticators，为管理所有身份验证方法提供统一位置。
  • 管理员现在可以从 Horizon Console 通过单次操作，将 Allowed User Access Location 应用于多个桌面池或应用程序池。
  • Horizon Console UI 行为：Rows Per Page 首选项现在会在 Horizon Console 中自动保存。
  • SAML 证书管理现已在 Horizon Console 中提供 (sysin)，使管理员无需离开控制台即可查看、更新和管理 SAML 证书生命周期。
  • Horizon Console 表格，包括会话网格，现在支持“Select All Pages”选项，恢复了跨多页表格选择所有行的能力，而不再只能选择当前可见页面中的行。这样一来，向所有会话发送消息等批量操作可以针对完整结果集执行，而无需逐页选择。

Horizon Agent for Linux

  • Horizon 现在支持 Linux Agent 的基于应用程序的 URL 重定向，使在 Slack 和电子邮件客户端等应用程序中点击的 URL 可以重定向到 Mac、Linux 和 Windows 上的 Horizon Client。
  • Horizon Agent for Linux 2606 增加了对 Agent TLS 端点 ECDSA 证书类型的支持。现在可以通过安装程序标志同时支持 RSA（默认）和 ECDSA 密钥类型。
  • Horizon Agent for Linux 2606 将捆绑的 OpenSSL 库从 3.0.x 系列升级到最新可用的 3.5.x 版本，以支持持续满足加密库要求。
  • 管理员现在可以配置 Horizon Agent for Linux VDI 桌面上重定向（虚拟）麦克风音频所使用的采样率。
  • FIPS 140-3 模式现在支持 RHEL 9.x（9.6 及更高版本）。
  • 此版本新增对 Debian 13.4、RHEL 9.8 和 Rocky Linux 9.8 的支持，并取消对 Debian 13.3 的支持。Horizon 8 在 vSphere 上的 RHEL 10.0 现以 Beta 形式增加 Wayland 支持。

Horizon Agent for Windows

  • “Horizon Agent for Windows”安装程序中的“Instant Clone Agent”功能已重命名为“Provisioning and Customization Agent”，以反映该功能是置备 vSphere 之外其他类型池和场所必需的功能。现有部署不受此更改影响。
  • Horizon Agent for Windows 2606 将捆绑的 OpenSSL 库从 3.0.x 系列升级到最新可用的 3.5.x 版本，以支持持续满足加密库要求。

Horizon Agent for Mac - LIMITED AVAILABILITY

  • Horizon Agent for macOS 在 2606 版本中进入生产环境有限可用性 (LA) 阶段。管理员可以在物理 macOS 设备上安装 macOS Agent，并将其注册到 Workspace ONE UEM，通过 MDM 策略集中管理所需的 macOS 隐私权限，包括屏幕录制和辅助功能权限。这样可以避免最终用户在 Horizon 登录或远程会话工作流期间手动批准权限提示。

Horizon 8 on Amazon WorkSpaces Core

  • 改进了 WorkSpaces 配额验证：在创建或编辑池之前，系统会根据当前使用量验证请求的 WorkSpaces 数量是否符合 AWS 区域配额。如果由于临时 AWS API 问题而无法获取配额或当前使用量，验证将允许操作继续执行，从而提高池创建的可靠性，同时保留 AWS 端的配额强制机制。
  • Horizon 8 on Amazon WorkSpaces Core 现在支持在自动化池工作流中对 WorkSpaces 实例进行加密。管理员可以选择 AWS 托管的 KMS 密钥或客户托管的 KMS 密钥。选择加密 WorkSpace 实例后 (sysin)，根卷和用户卷都会进行加密。这样可以确保静态存储的数据、对卷执行的磁盘 I/O 以及从这些卷创建的快照均经过加密。加密的 WorkSpaces 实例相比未加密实例需要更长的置备时间。
  • 管理员现在可以直接从 Horizon Console 执行池 Bundle 维护操作，从而提高运维效率并减少对外部工作流的依赖。池维护计划允许更新与池关联的 Bundle 或 Image，Horizon 中的更改会自动同步到 AWS。对于非持久性池，刷新操作现在可以灵活选择强制用户注销，或等待用户自然注销。此外，池机器选项卡经过增强，可显示 WorkSpace ID、Bundle ID 和 Image ID，从而清晰了解当前配置和维护状态。

Nutanix

  • 改进了 Nutanix 虚拟机发生自定义失败时的置备重试和恢复逻辑。

远程桌面功能

  • Linux 客户端重定向功能的缓存大小强制限制：现在支持为 Linux 客户端上的 Browser Content Redirection (BCR) 和 HTML5 Multimedia Redirection (HTML5MMR) 设置缓存大小限制。管理员可以配置最大缓存大小，以防止客户端浏览器进程过度占用磁盘空间。
  • Blast 协议现在支持 ECDSA 证书。
  • Storage Drive Redirection (SDR) 已从 Horizon Agent 安装程序中移除，并且不再在 Horizon Client 中提供。若要与远程桌面和已发布应用程序共享本地驱动器和文件夹，请改用 Global Sharing (Client Drive Redirection)。

Windows OS Optimization Tool for Omnissa Horizon

  • 新增 Security 选项卡选项：Turn Off Device Encryption 和 Disable BitLocker

    Common Options 的 Security 选项卡新增两个选项，用于支持 VDI 环境中的 Golden Image 准备工作。

    • Turn Off Device Encryption 会解密 VM 上所有已加密的卷。该工具会等待解密完成后再继续执行下一步。根据卷大小的不同，解密过程可能需要一些时间才能完成。
    • Disable BitLocker 可阻止 Windows 在映像上自动启用设备加密。

  • Windows OS Optimization Tool 已针对 Golden Image 创建工作流进行了增强，从而简化端到端的准备流程。

  • OSOT SCCM 集成现在支持在 SCCM 任务序列中管理 VMware Tools。管理员可以在基于 SCCM 的 Golden Image 创建工作流中加入 VMware Tools 安装和配置步骤。
