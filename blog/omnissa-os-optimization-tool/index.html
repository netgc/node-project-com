概述

您可以优化现有基础 VM，也可以使用指定的操作系统和任务序列创建优化的基础 VM。此优化适用于 Horizon 8 和 Horizon Cloud Service。

✅ 优化现有基础 VM

使用 Omnissa Horizon OS Optimization Tool，您可以优化用于创建即时克隆桌面池或完整克隆桌面池的基础虚拟机上的客户机操作系统。优化将建议和最佳实践应用于基础虚拟机上的 Microsoft Windows 操作系统 (sysin)。此优化包括调整默认操作系统服务功能以满足最佳实践，例如：

  • 停用与虚拟环境中无关的物理桌面功能，以提供更高效的 VM 性能。
  • 停用某些 Windows 系统服务（如 Windows Update），以便将该服务的控制权隔离给管理员，而不是最终用户。

优化为虚拟桌面提供了以下优势：

  • 提高性能
  • 通过增加每个 vSphere 服务器可托管的虚拟桌面数量来提高密度，从而降低基础架构成本
  • 改善最终用户体验
  • 减少最终用户支持事件

优化为 RDS 主机提供了以下好处：

  • 提高托管桌面和应用程序性能
  • 减少每个 RDS 主机所需的系统资源量
  • 增加可托管的 RDS 主机的密度和数量
  • 增加每个 RDS 主机可支持的用户数
  • 改善最终用户托管的桌面和应用程序体验
  • 减少系统支持事件

在 VM 上安装所需的应用程序后 (sysin)，您可以在 VM 上运行 OS Optimization Tool。OS Optimization Tool 会分析基础映像，并根据所选模板显示属性的当前值。您可以选择在优化期间要应用于图像的属性。然后，您可以通过使用无人参与应答文件运行 sysprep 工具来通用化映像。最后一步是通过清理图像来完成图像。

您可以使用 OS Optimization Tool UI 来优化映像，也可以从命令行运行该工具。

注意：对于 Horizon Cloud Service，您只需优化映像，无需对其进行通用化或定型。

✅ 创建优化的基础 VM

借助 MDT 环境自动化工具，您可以使用自动化创建具有指定任务序列的优化基础 VM。

✅ 支持的 Windows 版本

您可以针对以下 Windows 版本优化操作系统：

  • Windows 11
  • Windows 10
  • Windows Server 2022
  • Windows Server 2019
  • Windows Server 2025

✅ 关于其他版本

适用于 Horizon 可执行文件的 Windows OS Optimization Tool 目前与 Windows 7、Windows 8.1、Server 2012、Server 2012 R2、Server 2016 和 Server 2025 不兼容。

适用于 Horizon MDT 插件的 Windows OS Optimization Tool 目前与 Windows 7、Windows 8.1、Windows 11 24H2 及更高版本、Server 2012、Server 2012 R2、Server 2016 和 Server 2025 不兼容。
