Oracle Database 23c Free - Developer 版以 Docker 镜像、VirtualBox 虚拟机和 Linux RPM 安装文件的形式提供，包括以下突破性的新功能:

  • JSON 关系二元性: 开发人员可以使用单一数据源使用关系或 JSON 范式构建应用程序，并从关系模型和文档模型的优势中受益。数据只保存一次，但可以通过任何一种方式访问、写入和修改。开发人员可以同时从 JSON 和关系模型的优点中受益，包括符合 ACID 的事务和并发控制，这意味着他们不再需要在复杂的对象 - 关系映射或数据不一致问题之间进行权衡。

    随着 Oracle Database 23c 免费开发者版的发布，开发者可以尽早使用突破性的 JSON 关系二元来开发新的软件功能。这个版本最终让开发人员有机会使用在开发过程中将关系型数据与文档型数据进行统一。它使开发人员和数据工程师能够访问每种用例的格式，而无需担心数据结构、数据映射、数据一致性或性能调优的问题。它们现在还可以在关系数据和 JSON 数据之上运行图分析。Oracle 的 JSON 关系二元性是一个真正革命性的解决方案，可能是近 20 年来信息科学领域最重要的创新之一。”——IDC 数据管理软件研究副总裁 Carl Olofson。*

  • JavaScript 存储过程: 通过编写 JavaScript 存储过程或将现有的 JavaScript 库加载到 Oracle 数据库中，JavaScript 代码现在可以比以往任何时候更贴近数据库中的数据。通过允许直接在数据层中重用现有业务逻辑和重用 JavaScript 开发人员的技能来提高开发人员的生产力。JavaScript 代码调用可以与 SQL 和 PL/SQL 混合使用，提供多语言编程的支持。

  • JSON 模式: 开发人员现在可以通过行业标准的 JSON 模式来确保和验证 JSON 文档结构，从而能够自信并可靠地使用 JSON 数据格式。

  • 操作性属性图: 开发人员现在可以使用 Oracle 数据库构建事务性和分析性属性图应用程序，使用业界领先的新 SQL 标准属性图查询功能，可以在关系数据和 JSON 数据上运行图分析。

  • Oracle Kafka API: Kafka 应用程序现在可以运行在 Oracle 数据库事务事件队列上，只需进行最小的代码更改，就可以支持使用事务事件构建更健壮的微服务，这些微服务在单个原子事务中执行事件操作和数据库更改。

  • SQL 域: 新的域结构可以作为轻量级类型修饰符，这扩展并极大地改进了 SQL 标准域。这使得开发人员可以更好地理解数据是如何使用的，并改善整体数据质量，而不需要考虑特定的数据类型或用户定义的数据类型的复杂性和不兼容性。

  • 注释: 使用新的注释机制，数据库元数据现在可以直接与数据一起存储在 Oracle 数据库中。开发人员可以对表、列、视图、索引等的公共数据模型属性进行注释，从而提供一个集中的、轻量级的、声明性的方案来跨应用程序注册和交换属性。将元数据与数据一起存储，可以保证一致性，并保证任何使用数据的用户或应用程序都能顺畅访问这些数据。

常见问题解答

获得帮助

  • 我怎样才能得到支持？

    转至 Oracle 数据库免费论坛 并搜索现有问题和答案或输入您自己的问题。

  • 我可以针对 Oracle Database Free 记录服务请求 (SR) 吗？

    不可以，您只能通过 Oracle 支持记录针对完全受支持的产品的服务请求，例如 Oracle 数据库企业版、Oracle 数据库标准版 2 和所有 Oracle 数据库云服务。

  • 是否会为 Oracle Database Free 提供补丁？

    不，不会为 Oracle Database Free 发布补丁。要获得补丁，您必须使用完全受支持的版本，例如 Oracle 数据库企业版或 Oracle 数据库标准版 2。

安装

  • 我可以将 Oracle Database Free 安装到 Docker 中吗？

    是的，可以通过以下方式提取基于 Oracle Linux 的 Docker 镜像 docker pull container-registry.oracle.com/database/free

  • 我可以将 Oracle Database Free 安装到 VirtualBox 中吗？

    是的，您可以下载 Oracle Virtual Box 映像 Oracle Database AppDev VM，其中包含 Oracle Database Free。

  • Oracle Database Free 的资源限制是什么

    Oracle Database Free 最多支持：

    • 2 个 CPU 用于前台进程
    • 2GB RAM（SGA 和 PGA 组合）
    • 磁盘上 12GB 的用户数据（不考虑压缩因子）

常规

  • 我可以在生产中使用 Oracle Database Free 吗？

    Oracle Database Free 不限制其部署环境。但是，Oracle Database Free 不受支持，也不会收到任何补丁，包括安全补丁。Oracle 建议在完全支持的 Oracle 数据库版本或云服务上运行生产部署。

  • Oracle 数据库免费版不包括哪些特性？

    中查看 Oracle 数据库免费版中包括和不包括的完整功能列表 可以在 Oracle 数据库许可指南。

升级 / 迁移

  • 我可以从旧的 XE 版本迁移吗？

    您可以使用 Oracle Data Pump 导出 / 导入将 XE 环境从旧的 XE 环境迁移到新的 Oracle Database Free 环境。

    有关详细信息，请查看 第 8 章 “从以前版本的 Oracle 数据库 XE 迁移到 Oracle 数据库免费版” 。 安装指南中的

  • 我可以将 Oracle 数据库免费 PDB 拔出 / 插入到 EE/SE2 CDB 中吗？

    目前不支持将 Oracle 数据库免费 PDB 插入 EE/SE2 容器数据库 (CDB)。

  • 我可以将 EE/SE2 PDB 拔出 / 插入到 Oracle 数据库免费 CDB 中吗？

    目前不支持将 EE/SE2 PDB 插入 Oracle 数据库免费 CDB。

  • 如何转换我的字符集？

    您可以通过使用数据泵导出 / 导入来转换您的字符集以导出数据，使用您想要的字符集创建一个新数据库，然后再次导入数据。有关详细信息，请参阅 数据库实用程序文档。

相关产品

  • Oracle APEX 在哪里？

    Oracle APEX 不包含在发行版中。相反，您可以 在此处下载最新版本。中的说明 按照 Oracle APEX 文档 安装最新版本的 Oracle APEX。

  • SQL Developer 和 SQLcl 在哪里？

    SQL Developer 和 SQLcl 不是 Oracle Database Free 的一部分。相反，您可以单独下载最新版本的 SQL Developer 或 SQLcl 。

  • 发行版中是否包含 Oracle REST 数据服务 (ORDS)？

    不，单击 此处 了解如何使用 ORDS 和 Oracle Database Free 进行 RESTful 应用程序开发并支持 Oracle APEX。

系统要求

官方要求 OL8 或者 RHEL8，当然也可以运行在其他 RHEL8 兼容发行版上。

  • Red Hat Enterprise Linux (RHEL) 8.10 (x86_64, aarch64) - 红帽企业 Linux
  • Oracle Linux 8.10 - Oracle 提供支持 RHEL 兼容发行版
  • AlmaLinux 8.10 - RHEL 下游免费发行版（CentOS 稳定版的替代品）
  • Rocky Linux 8.10 - CentOS 的权威替代
