Oracle Linux 10 发布公告

Oracle Linux 10 现已正式发布

2025 年 6 月 26 日

Oracle Linux 10 现已正式发布，支持 64 位 Intel 和 AMD（x86_64）以及 64 位 Arm（aarch64）平台。Oracle Linux 10 为业务敏捷性和云规模高负载场景提供稳健的安全性和卓越的性能。其关键特性包括现代化的加密功能、改进的开发者工具，以及面向高可靠基础设施的创新 (sysin)。这些增强功能使组织能够在分布式与多云环境中更快速、更安全地构建和运行应用。

在近期发布的 Unbreakable Enterprise Kernel 8（UEK 8）之后，Oracle Linux 10 包含了 UEK 8.1。这凸显了 Oracle 持续致力于为企业提供行业领先的性能与稳定性。此外，Oracle Linux 10 还包含更新的 Red Hat 兼容内核。Oracle Linux 10 保持与 Red Hat Enterprise Linux 10 的 100% 应用二进制兼容性，并兑现 Oracle 一直以来保持 Linux 开放与自由的承诺。作为 Open Enterprise Linux Association（OpenELA）的创始成员之一，Oracle 持续贡献、维护并支持自由提供的企业级 Linux 源代码。

✅ Oracle Linux 10 核心中的高性能内核

最新的 Oracle Linux 内核——Unbreakable Enterprise Kernel 8（UEK 8）专为数据密集和计算密集型工作负载而构建。作为 Oracle Linux 10 默认内核，UEK 8 在内存管理、文件系统和网络方面带来了最先进的创新。这些由 Oracle 与上游 Linux 社区共同贡献的增强功能，为现代企业所需的性能与可靠性提供了保障 (sysin)。全球客户依赖搭载 UEK 的 Oracle Linux 来驱动关键任务和分布式部署，涵盖 Oracle Database、Oracle Exadata 和 Oracle Cloud Infrastructure。Oracle Linux 为金融、政府、教育等行业提供支撑，是从 OLTP 到大规模数据分析再到 AI/ML 工作负载等广泛应用的基础平台。

✅ 领先防护：无停机打补丁，自信运行

Oracle Ksplice 零停机补丁（在 Oracle Linux Premier Support 中提供）现已支持 Oracle Linux 10。它可在无需系统重启的情况下，为内核和用户空间（包括 glibc 与 OpenSSL）应用关键更新。这项自动化的实时补丁技术能够在几秒钟内交付关键更新，帮助系统持续保持安全和最新，同时不干扰正在运行的应用。借助 Oracle Ksplice，可避免补丁期间因重启而导致的业务中断，从而实现成本节约和运营效率提升。

✅ 面向当今基础设施与未来挑战的企业级安全

在企业环境中，强身份验证和零信任原则至关重要。Oracle Linux 10 为 OpenSSH 带来了重大升级，包含一系列安全性与可用性增强。其中包括按键模糊处理以防止侧信道攻击、扩展的密钥转发与使用限制以强化凭据安全、以及自动关闭非活跃 SSH 通道 (sysin)。此外，SSH 守护进程经过重新架构，将连接处理与会话管理分离，从而减少攻击面。使用基于 FIDO 的身份验证的系统也能从改进的硬件密钥处理和增强的凭据覆盖防护中受益。

为进一步帮助组织保护数据并与新的加密标准保持一致，Oracle Linux 10 作为技术预览引入了后量子密码学（PQC）。它提供了一组旨在抵御量子攻击的新一代算法。在扩展的加密工具集中，pkeyutl 工具现在支持封装与解封操作，包括新的 PQC 算法 ML-KEM。

注意：后量子密码学（PQC）技术预览不适用于生产环境，仅用于测试与开发目的。

✅ 增强的开发者工具：卓越性能与可扩展创新

从现代化的编译器工具链到强化的可观测性，Oracle Linux 10 为开发者日常依赖的工具带来了改进。GCC 更新带来了多项 C、C++ 和 OpenMP 功能，同时提供更严格的安全选项、改进的诊断能力以及性能优化。Oracle Linux 10 引入了 Valkey——一种高性能、内存型键值存储，用于替代 Redis，同时保持完全兼容性并提供更高可扩展性 (sysin)。迁移对大多数应用透明，现有 Redis 配置和数据无需修改即可继续使用。此外，Grafana 引入了焕新的界面与更严格的用户访问控制。对于使用 .NET 的开发者，新版本添加了网络和数据访问等新 API，并在多种平台和架构上提供更广泛支持。

✅ 优化的编程能力，助力新一代应用

Oracle Linux 10 在关键编程语言与数据库技术方面带来了多项改进，从而提升性能并简化日常开发。Python 更新通过优化编译器设置、内联推导式显著提升执行速度，并带来更可读的类型语法。其他升级组件包括 Perl、Node.js 和 MySQL，它们均带来了性能、操作安全性与开发效率方面的提升。

如需查看此版本引入的所有功能、增强和变更，请参考 Oracle Linux 10 发行说明。

✅ 升级到最新 Oracle Linux 版本

使用 Leapp 工具，运行 Oracle Linux 8 的系统可升级至 Oracle Linux 9，运行 Oracle Linux 9 的系统可升级至 Oracle Linux 10。有关升级系统的分步指导，请查看 Oracle Linux 9 和 Oracle Linux 10 的相关文档。
