Oracle Linux 9 发布公告

2022 年 7 月 1 日

Oracle 很高兴地宣布 Oracle Linux 面向 Intel-64/AMD-64 (x86_64) 和 Arm (aarch64) 的版本正式发布。此版本包括 Unbreakable Enterprise Kernel Release 7 (UEK R7)，以及 Red Hat Compatible Kernel (RHCK)，现在也普遍可用。

Oracle Linux 是 操作环境 用于 应用程序开发和 部署。带有 UEK R7 的 Oracle Linux 9 提供了内核、性能和安全性增强功能，包括：

  • UEK R7 基于主线长期支持 (LTS) 5.15 版本，提供最新的硬件支持，并与 Linux 内核社区保持一致，以便更及时地交付关键修复和安全更新。此版本 包括核心调度，这是一种有助于避免侧信道攻击的安全功能；添加 CTF（C 类型格式）调试信息数据作为核心内核安装的一部分，允许开发人员调试他们的系统而无需安装额外的包；并将 64 位 Arm (aarch64) 平台的默认页面大小提高到 4 KB。UEK R7 也可用于 Oracle Linux 8。
  • OpenSSL 3.0 包括许多面向应用程序开发人员和用户的新概念和结构增强功能。OpenSSL 3.0 的新 FIPS 模块可防止使用非 FIPS 算法，同时可以在内核中设置 FIPS 标志，而无需将 OpenSSL 切换到 FIPS 模式。
  • 文件系统增强功能 包括 Btrfs、新的异步 SSD 修整、并行文件系统同步功能和更少的校验和树查找。XFS 支持直接访问 (DAX) 操作，允许直接访问字节可寻址的持久内存，有助于避免使用传统块 I/O 约定的延迟。NFS 引入了 “eager write” 挂载选项来帮助减少延迟。
  • VirtualBox 共享文件夹 UEK R7 原生支持 这有助于 在 Oracle Linux 来宾和主机操作系统之间 Oracle VM VirtualBox。
