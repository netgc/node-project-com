Proxmox Backup Server 简介

开源企业级备份解决方案

Proxmox Backup Server 是一款企业级备份解决方案，专用于虚拟机（VM）、容器以及物理主机的备份与恢复。通过支持增量式、完全去重的备份，Proxmox Backup Server 显著减少了网络负载并节省宝贵的存储空间 (sysin)。结合强大的加密机制和数据完整性校验，即使将数据备份到不完全可信的目标设备，也能确保其安全性。

在现代数据中心中，最重要的是尽可能减少停机时间并确保数据安全。因此，可靠的备份软件是最值得投资的基础设施之一。Proxmox Backup Server 操作简便，不仅能够高效节省空间地备份数据、快速恢复，还能通过基于 Web 的管理界面显著提升管理效率、减少工作时间。

Proxmox Backup Server 4.1 更新亮点

2025 年 11 月 26 日

奥地利维也纳 – 2025 年 11 月 26 日 —— 领先的开源服务器解决方案提供商 Proxmox Server Solutions GmbH（以下简称 “Proxmox”）今日宣布发布 Proxmox Backup Server 4.1。本次更新基于 Debian 13.2 “Trixie”，带来了最新的 Debian 版本，包括更新的软件包、更好的硬件支持以及增强的安全性 (sysin)。Proxmox Backup Server 4.1 采用 Linux 内核 6.17 作为新的稳定默认版本，并包含 ZFS 2.3，以提供可靠的企业级存储。本次发布还在流量控制、验证性能以及基于 S3 的备份操作方面带来了重大改进。

Proxmox Backup Server 4.1 的亮点

✅ 基于用户的流量限制以优化带宽控制

Proxmox Backup Server 4.1 扩展了现有的流量控制能力，该能力已允许管理员为特定客户端网络限制备份和还原流量。在此次发布中，流量控制还可以基于经过身份验证的 Proxmox Backup Server 用户进行控制。这使管理员能够更方便且更精细地对备份和还原工作负载进行优先级管理，例如为业务关键型服务分配更高的备份带宽，或在用户级别区分生产环境和测试环境。

✅ 验证任务的可配置并行度

备份快照验证同时对 I/O 和 CPU 要求较高，因为其需从磁盘读取备份数据块并验证其校验和。在 4.1 版本中，管理员可以为验证任务配置用于磁盘读取和校验和验证的线程数量 (sysin)。根据硬件和工作负载情况，这项改进可显著缩短验证运行时间，并有助于在验证任务与其他资源密集型操作之间取得平衡。

✅ S3 端点的带宽速率限制

基于 Proxmox Backup Server 4.0 中引入的对 S3 兼容对象存储的原生支持，4.1 版本新增对 S3 端点的带宽速率限制。管理员现在可以限制备份和还原操作与 S3 对象存储之间使用的带宽。这有助于防止 Proxmox Backup Server 实例与对象存储基础设施之间的网络拥塞，特别是在共享或带宽受限的环境中。

Proxmox Backup Server 4 发布公告

2025 年 8 月 6 日

Proxmox Backup Server 4.0 发布

Proxmox 很高兴地宣布，Proxmox Backup Server 4.0 的首个稳定版本现已正式发布，可立即下载！

该新版本基于出色的 Debian 13 “Trixie”，但在 Proxmox Backup Server 中使用了更新的 Linux 6.14.8-2 内核作为默认稳定版本，并集成了 ZFS 2.3.3。

Proxmox 为本次版本所付出的努力感到无比自豪，迫不及待地希望您能尽快体验！

Proxmox Backup Server 4.0 中包含的一些令人兴奋的新功能：

  • 支持使用兼容 S3 的对象存储作为备份存储后端（技术预览）。
  • 支持 ZFS 2.3 的 RAID-Z 扩展功能。
  • 在挂载可移动数据存储时自动触发同步作业。
  • 以及更多功能……

除了这些主要更新 (sysin)，还实施了众多性能增强和错误修复，使您的使用体验更加流畅。完整的更改列表请参阅发布说明。

常见问题解答（FAQ）

问：我可以使用 apt 将 Proxmox Backup Server 3 升级到 4 吗？

答：可以，请按照以下升级说明操作：https://pbs.proxmox.com/wiki/Upgrade_from_3_to_4

问：我可以通过 apt 将 4.0 的测试版升级到稳定版吗？

答：可以，测试版可以通过 apt 升级为稳定版本。建议升级时切换到 pbs-enterprise 仓库，以获得最稳定的体验。

问：Proxmox Backup Server 3.4 将支持到什么时候？

答：Proxmox Backup Server 3.4 将获得安全更新和关键性错误修复支持，直到 2026 年 8 月。此支持周期将在 Proxmox Backup Server 4 发布后提供大约一年的重叠期，以便用户有充足时间规划升级。

问：Proxmox Backup Server 4.0 为什么会在 Debian 13 稳定版发布前就推出？

答：Debian 13 稳定版计划在 8 月 9 日（星期六）发布，其核心组件自 5 月 15 日进入“硬冻结”阶段以来已经非常稳定。在进行充分集成测试并收到大量 beta 用户反馈后，对 Proxmox Backup Server 4.0 的稳定性充满信心。由于核心软件包要么由 Proxmox 团队直接维护，要么已经受到 Debian 冻结策略的约束，因此没有推迟发布的技术理由。

问：这个版本如何与 Proxmox Virtual Environment 集成？

答：只需在您的 Proxmox VE 中添加一个 Proxmox Backup Server 数据存储作为新的存储目标。请确保运行的是 Proxmox VE 8.4 或 9.0 的最新版。

问：Proxmox Backup Server 是否仍兼容旧版客户端或旧版 Proxmox VE？

答：我们正在积极测试所有当前支持的主要版本之间的兼容性，包括上一代版本。这意味着您可以安全地从 Proxmox VE 8 备份到 Proxmox Backup Server 4，或从 Proxmox VE 9 备份到 Backup Server 3。不过，若客户端和服务器版本相差两个以上主版本（例如基于 Debian 11 Bullseye 的 Proxmox VE 7 与基于 Debian 13 Trixie 的 PBS 4），则只能提供“尽力支持”。

问：如何在 Debian 或 Ubuntu 上安装 proxmox-backup-client？

答：提供了一个“仅 Proxmox Backup 客户端仓库”，请参见：https://pbs.proxmox.com/docs/installation.html#client-installation

对于 Debian 衍生版本，建议安装 proxmox-backup-client-static 软件包，以避免系统库版本不同引发的问题。

问：Proxmox Backup Server 推荐使用什么服务器硬件？

答：推荐使用企业级服务器硬件，具备高速本地 SSD/NVMe 存储。使用机械硬盘会显著降低备份服务器的访问与响应速度。

问：我可以在 Debian 系统上、虚拟机中、LXC 容器中或与 Proxmox VE 共存地安装 Proxmox Backup Server 吗？

答：可以，但这不是推荐的方式，仅供高级用户使用。
