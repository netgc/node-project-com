Proxmox Datacenter Manager

Proxmox Datacenter Manager 是一套集中式管理解决方案，用于监督和管理多个节点及基于 Proxmox 的虚拟化环境集群。专为大型企业环境而设计，为 IT 团队提供其分布式 Proxmox 虚拟化基础设施的完整概览。

集中化。简化。扩展。

  • 通过统一界面消除分布式虚拟化的复杂性。
  • 提供清晰且可扩展的方式在多个数据中心监控、运行和扩展基础架构。
  • 支持更好的决策，让日常操作更简单，并能在集群间高效管理工作负载。

更棒的是：拥有 Proxmox 远端有效企业支持的客户还可以获得 Proxmox Datacenter Manager 的更新与支持。

核心优势

你会爱上它的理由

  • 洞察力，更好的决策

    获取对环境的单一、清晰视图。基于可靠数据而非猜测来识别趋势、发现机会，并构建新的服务。

  • 为 Proxmox 生态系统而生

    与 Proxmox VE 和 Proxmox Backup Server 的原生兼容性，共同构建一致的管理环境，从而简化日常工作并支持长期扩展。

  • 降低基础设施成本

    了解集群和数据中心的真实利用率。避免过度分配、减少闲置容量 (sysin)，只在真正需要的地方投资。

  • 高可用性与强 SLA

    通过复制与跨数据中心迁移在事件或维护期间保持工作负载在线。避免停机风险、处罚和声誉损失。

  • 扩展而无需扩编

    从一个控制平面管理更多集群、地点与客户，以更少的运营开销支持更大的基础设施规模。

  • 更轻松达成合规

    基于角色的访问控制与集中式身份集成可帮助分离职责、执行最小权限原则，并简化审计与认证。

关键功能

在企业规模上简化 IT 运维

Proxmox Datacenter Manager 专为管理复杂及分布式基础设施的组织打造，从本地部署到全球规模的数据中心均适用。

随着您的基础设施增长，Proxmox Datacenter Manager 将随之扩展 (sysin)。可添加新的集群、扩展至新区域，并使环境的每个部分保持有序、合规且可控。

  • 中央驾驶舱

    Proxmox Datacenter Manager 将所有您的 Proxmox VE 集群、节点及 Proxmox Backup Server 实例链接并呈现在单一界面中。您能获得结构化、统一的概览，涵盖各位置与数据中心的主机、虚拟机、容器和数据存储；而强大的搜索功能可让您在大型环境中快速找到所需资源。

  • 多集群管理与实时迁移

    大规模管理虚拟工作负载：可在无需逐个登录节点的情况下启动、停止、重启或迁移数千个虚拟客体。独立集群间的实时迁移可实现负载均衡、计划维护与高可用性——全程无停机。

  • 深度整合 Proxmox Backup Server

    Proxmox Backup Server 远端可像 Proxmox VE 一样进行管理。统一视图可显示不同数据存储的内容，并提供利用率与性能的 RRD 图表 (sysin)。中央仪表盘的组件也会直接包含来自 Proxmox Backup Server 远端的度量指标。

  • 自定义视图与委派控制

    自定义视图（Custom Views）可让您根据自己的布局和筛选器构建定制化的总览。数据可按远端、资源、资源类型或标签进行筛选。通过基于角色与权限的系统，可为团队授予特定视图的访问权限，而无需允许其直接访问底层主机或存储，从而安全地委派管理权限。

  • 更深入的度量数据与可视化分析

    改进的度量收集与可视化功能为您提供更深入的使用率、性能及增长趋势洞察。仪表盘与 RRD 图能够帮助您及早识别趋势、优化资源分配与更有效地规划未来容量。

  • 企业级认证与 API

    支持 LDAP、Active Directory 与 OpenID Connect，可轻松整合至现有身份体系与 SSO 环境。API 令牌支持对外部应用程序及自动化流程进行细粒度访问控制。

  • 集中式 SDN 能力（EVPN）

    从单一界面配置跨多个远端的 EVPN 区域与虚拟网络（VNet），使大型环境中的复杂网络覆盖与日常网络管理更加简单。

  • 更新管理

    中央更新管理面板可让管理员即时查看整个 Proxmox VE 与 Proxmox Backup Server 基础设施的所有可用更新，并可直接从 Datacenter Manager 界面部署补丁。
