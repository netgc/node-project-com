Proxmox Mail Gateway 简介

全面的开源邮件安全平台

Proxmox Mail Gateway 是领先的开源电子邮件安全解决方案，可帮助您从威胁初现之时起就保护邮件服务器免受所有邮件安全威胁的侵害。它采用灵活的架构，并配备用户友好的基于 Web 的管理界面 (sysin)，使 IT 专业人员和企业能够轻松掌控所有收发邮件流量，有效防御垃圾邮件、病毒、钓鱼和木马等威胁。

任何规模的组织都可以在几分钟内轻松部署和实施这套反垃圾邮件和防病毒平台。该功能完备的邮件代理部署于防火墙与内部邮件服务器之间，使您可以通过单一平台控制所有邮件流量。Proxmox 可帮助您轻松维护安全、专业的邮件通信环境，确保业务连续性，并提升企业声誉与客户满意度。

功能亮点

Proxmox Mail Gateway 集成了 ClamAV 杀毒引擎、多种过滤机制、创新的 Proxmox 消息追踪中心、HA 集群等功能，用于检测木马、病毒、恶意软件及其他安全威胁。

高性价比且可扩展

单个 Proxmox Mail Gateway 服务器即可支持多个内部邮件服务器和无限数量的邮件域，每天可处理数百万封电子邮件。灵活的订阅模式让您在业务增长的同时也能轻松扩展容量 (sysin)，兼顾成本效益。

易于集成到现有 IT 架构

作为一款软件设备，Proxmox Mail Gateway 的优势在于其灵活性。它可以轻松集成至您现有的邮件架构中，并兼容各类邮件传输代理（如 MS Exchange、Lotus Domino 或 Postfix）。您也可以将其作为虚拟设备运行。

Proxmox Mail Gateway 9 新功能

2026 年 6 月 11 日

宣布 Proxmox Mail Gateway 9.1 正式发布！

此版本基于 Debian 13.5 “Trixie”，并采用 Linux 内核 7.0 作为新的稳定默认版本。同时集成了最新版本的 ZFS 2.4、PostgreSQL 17、SpamAssassin 4.0.2（包含更新后的规则集）以及 ClamAV 1.4.4。

Proxmox Mail Gateway 9.1 的部分亮点：

  • 垃圾邮件隔离区（Spam Quarantine）多项易用性改进，桌面端和移动端友好界面均可使用：
    • 支持为共享邮箱标记邮件为已读 (sysin)。
    • 可一目了然查看汇总后的正向和负向垃圾邮件评分。
    • HTML 邮件中的外部图片现在可设置为仅按需加载。
    • 除现有通过邮件发送隔离区登录链接的方式外，现在还可以直接复制某个收件人的隔离区登录链接。
  • 改进 Proxmox Backup Server 集成：
    • 支持客户端备份加密，并提供密钥管理以及可选的主密钥（Master Key）用于恢复。
    • 可触发备份验证，并查看每个快照的加密状态和验证状态。
  • 支持显示可配置的同意提示横幅（Consent Banner）
    • 用户登录前必须确认该提示，例如用于显示法律声明或使用须知。
  • 可选记录邮件信封信息以及解码后的 From、To 和 Subject 标头
    • 用于审计目的。
    • 默认关闭，因为这些邮件头信息可能包含个人数据。

除上述新增功能外，还实现了大量性能优化和错误修复，以进一步提升使用体验。完整变更列表请查看官方发布说明。

常见问题 (FAQ)：

问：我可以通过 apt 将最新的 Proxmox Mail Gateway 8 升级到 9 吗？

答：可以，请参照升级指南：https://pmg.proxmox.com/wiki/index.php/Upgrade_from_8_to_9

问：我可以通过 apt 将 9.0 测试版升级为 9.0 稳定版吗？

答：可以，从 Beta 升级到稳定版完全支持。建议在升级时切换到 pmg-enterprise 仓库，以获得最稳定的体验。

问：Proxmox Mail Gateway 8.2 会获得多长时间的安全和 Bug 修复支持？

答：直到 2026 年 8 月。这一支持周期提供了约一年的缓冲期，方便用户从 8.2 平滑迁移至 9.0。详情请见支持生命周期说明：https://pmg.proxmox.com/pmg-docs/pmg-admin-guide.html#_frequently_asked_questions

问：我能否在 Debian Trixie 上安装 Proxmox Mail Gateway？

答：可以，安装指南见：https://pmg.proxmox.com/pmg-docs/pmg-admin-guide.html#pmg_install_on_debian

问：我能否在 Proxmox VE、VMware 或 Hyper-V 中作为虚拟机安装 Proxmox Mail Gateway？

答：可以，直接使用 ISO 安装即可 (sysin)。若在 Hyper-V 的第二代虚拟机上安装，请将安全启动（Secure Boot）配置为 Microsoft UEFI Certificate Authority。

问：我能否在 Proxmox VE 的 LXC 容器中安装 Proxmox Mail Gateway？

答：可以。你可以在 Debian 容器上安装，或直接通过内置的模板下载器获取安装模板。
