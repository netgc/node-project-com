Proxmox VE 简介

Proxmox Virtual Environment，简称 Proxmox VE，是一款功能强大的开源服务器虚拟化平台，尽管它常被 VMware ESXi 和 KVM 等主流虚拟化方案所掩盖，凭借其免费和开源的特性，它非常适合家庭实验室爱好者和中小企业，这类用户的需求通常不同于大型企业。

Proxmox VE 7.4 更新亮点

奥地利维也纳 - 2023 年 3 月 23 日 - 企业软件开发商 Proxmox Server Solutions GmbH（以下简称“Proxmox”）今天发布了其服务器虚拟化管理平台 Proxmox Virtual Environment 的 7.4 版。新版本着重于提高可用性，为 Web 界面带来更多管理任务。

  • Proxmox VE 7.4 基于 Debian 11.6（“Bullseye”），但使用更新的、长期支持的 Linux 内核 5.15，并包括对 Virtual Environment 领先开源技术最新版本的更新，例如 QEMU 7.2、LXC 5.0 .2 和 ZFS 2.1.9。该平台支持 Ceph Quincy 17.2.5 作为新安装的默认值或可选的 Ceph Pacific 16.2.11。

  • 默认情况下，Proxmox VE 使用更新的、长期支持的 Linux 内核 5.15。可选择安装 Linux 内核 6.2，为最新硬件的当前功能提供支持 (sysin)。可以通过选择 pve-kernel-6.2 元包通过 shell 安装内核。重启后，新内核将被激活。

  • 黑暗主题：完全集成的“Proxmox Dark”主题变体现在可用于网络界面和黑暗爱好者。该主题基于 Crisp light 主题。为了检测用户是否请求了浅色或深色主题 (sysin)，使用了 CSS 媒体特性 prefers-color-scheme。通过操作系统或浏览器中的设置，用户可以表明他们的偏好。但是，用户也可以在 Web 界面中手动切换配色方案。

  • Ceph OSD：Web 界面和 API 现在显示详细的 OSD 信息。这减少了管理员的工作，因为他们不再需要从各个地方收集必要的信息。

  • 任务日志可以在 GUI 中下载为文本文件，这有助于更轻松地进行进一步检查。

  • 资源树排序：现在可以通过选择适当的排序顺序，按名称或 VMID 对 VM 或容器进行排序。特别是在大型集群中，按名称对所有来宾进行排序可以为依赖它们的用户提供更好的概览。

  • HA Manager：通过添加CRM命令，可以手动将在线节点切换到维护状态（无需重启）。此外，还扩展了对 HA 集群资源调度程序 (CRS) 堆栈的支持，现在可以在启动时自动重新平衡 VM 和容器，而不仅仅是在恢复时。

Proxmox VE 7 重磅更新来了

Proxmox Server Solutions GmbH，或简称 Proxmox，宣布了其服务器虚拟化管理平台 Proxmox Virtual Environment 7.0 的主要版本。小数点前的数字总是表示大事。Proxmox 在此宣布新版本基于 Debian 11 “Bullseye”，但使用 Linux 内核 5.11，包括 QEMU 6.0、LXC 4.0 和 OpenZFS 2.0.4。

但你已经知道什么是新的？ Proxmox 发布了大量新的显着增强功能列表，包括：

  • Ceph Pacific 16.2：Proxmox Virtual Environment 完全集成了 Ceph，使用户能够直接从任何集群节点运行和管理 Ceph 存储。这使用户能够设置和管理超融合基础架构。Ceph Pacific 16.2 现在是 Proxmox VE 的默认版本，而 Ceph Octopus 15.2 在持续支持下仍然可用。

    • 从 Ceph Pacific 16.2 开始，默认情况下为新集群启用平衡器模块。这将导致在 OSD 之间更好地分配归置组，并有助于在 OSD 之间更均衡地平衡数据，减少单个 OSD 不成比例地充满的可能性，从而导致集群中的可用空间少于预期。
    • 如果用户有多个配置的链接，可以使用 CLI 创建具有多个公共网络的 Ceph 监视器。

  • Btrfs 存储技术：Linux 内核原生支持的写时复制 (COW) 文件系统，实现了快照、内置 RAID 和通过数据和元数据校验和自愈等功能。它允许拍摄子卷快照并支持离线存储迁移，同时保留快照。对于企业存储系统用户，Btrfs 提供意外断电后的文件系统完整性，帮助防止比特腐，专为大容量和高性能存储服务器而设计。

  • 据说新面板可以通过 GUI 轻松管理 APT 存储库：Proxmox 开发人员在 Web 界面中添加了一个新的“存储库”面板，允许检查节点配置的 APT 存储库。新面板提供了一个查看所有包存储库配置的单一位置，这些配置通常分散在多个文件中，并警告潜在的错误配置。用户可以根据需要启用和禁用存储库，并添加 Proxmox 提供的标准存储库。该公司表示，可以测试主存储库中尚未提供的新 Ceph 版本。Proxmox 提供的 Ceph 测试存储库可以简单地启用（或添加），测试新版本，然后在不再需要时再次禁用。

  • 访问控制：新的开放协议标准 OpenID Connect 提供单点登录 (SSO)，从而带来无缝的用户体验。管理员可以通过使用现有的公共服务或他们自己的身份和访问管理解决方案来集成外部授权服务器。此外，新添加的权限“Pool.Audit”允许用户查看池，但不能更改它们。

  • 基于 Web 的用户界面 (GUI) 的增强功能：

    • “Notes”中的 Markdown -Guest 和 Node 的“Notes”面板现在可以解释 Markdown 并将其呈现为 HTML。这使管理员可以更好地可视化他们的笔记。
    • 修剪手动触发的备份：用户可以在开始手动备份时使用其备份保留参数修剪目标存储。
    • 在创建容器或准备 cloud-init 映像时，支持将安全密钥（如 YubiKey）作为 SSH 密钥。

  • QEMU 6.0：具有新功能的最新 QEMU 版本包含在 Proxmox VE 7 中 (sysin)。这包括对 Linux IO 接口“io_uring”的支持。默认情况下，虚拟驱动器的异步 I/O 引擎将应用于所有新启动或迁移的客户系统。此外，还提供了未引用 VM 磁盘的清理选项。配置中不存在的磁盘不再自动销毁。它现在在 API 和 CLI 工具中选择加入（在 GUI 中，它从 Proxmox VE 6.4 开始出现）。如果启用此清理选项，则只会扫描内容类型为 VM 或 CT 磁盘映像或 rootdir 的存储以查找未使用的磁盘卷，从而有助于防止意外丢失数据。

  • 容器：LXC 4.0 完全支持 cgroups2，这是一种分层组织进程和分配系统资源的机制。Promox VE 7.0 的默认布局是纯 cgroupv2 布局。

  • Proxmox VE 安装程序：安装程序环境已经过重新设计，现在在从 initrd 转换到实际安装程序时使用 switch_root 而不是 chroot。这改进了模块和固件加载，并在安装过程中略微减少了内存使用。安装程序现在会自动检测 HiDPI 屏幕并相应地增加控制台字体和 GUI 缩放。这改进了带有 Proxmox VE 的工作站的 UX（例如，用于直通）。ISO 检测也得到了改进，以便在存储速度较慢的情况下更可靠地工作。新安装程序对 initrd 映像和 squashfs 映像使用 zstd 压缩。

  • 证书管理：ACME 独立插件现在改进了对双栈（IPv4 和 IPv6）环境的支持，不再依赖配置的地址来确定其侦听接口。

  • 网络：现代 ifupdown2 是使用 Proxmox VE 官方 ISO 的新安装的默认网络管理工具。Proxmox VE 7 仍然支持旧的 ifupdown。

  • 时间同步：新安装将 chrony 安装为默认的 NTP 守护进程，因为 systemd-timesync 的设计限制使其在服务器使用中存在问题。使用 systemd-timesyncd 从系统升级的用户应该手动安装 chrony、ntp 或 openntpd。

关于 Proxmox

概况

开源项目 Proxmox VE 拥有庞大的全球用户群，拥有超过 600,000 台主机。该虚拟化平台已被翻译成超过 26 种语言。支持论坛中有超过 88,000 名活跃的社区成员参与并互相帮助 (sysin)。通过使用 Proxmox VE 作为专有虚拟化管理解决方案的替代方案，企业能够集中化和现代化其 IT 基础架构，并将其转变为基于最新开源技术的经济高效且灵活的软件定义数据中心。数以万计的客户依赖 Proxmox Server Solutions GmbH 的企业支持订阅。

关于 Proxmox Virtual Environment

Proxmox Virtual Environment (Proxmox VE) 是用于全包式企业虚拟化的领先开源平台。借助中央 Web 界面，您可以轻松运行虚拟机和容器、管理软件定义的存储和网络功能、高可用性集群以及多个集成的开箱即用工具，例如备份/恢复、实时迁移、复制和防火墙。企业使用功能强大且易于管理的一体化解决方案来满足当今现代数据中心的核心需求 (sysin)。Proxmox VE 凭借其灵活、模块化和开放的架构，使他们能够适应未来的增长。

关于 Proxmox 服务器解决方案

Proxmox 是功能强大且易于使用的开源服务器软件提供商。企业，无论规模、部门或行业，都使用稳定、安全和可扩展的 Proxmox 解决方案来部署高效、敏捷和简化的 IT 基础架构，最大限度地降低总拥有成本，并避免供应商锁定 (sysin)。Proxmox 还提供商业支持和培训服务，以确保其客户的业务连续性。Proxmox Server Solutions GmbH 成立于 2005 年，总部位于奥地利维也纳。
