Proxmox Virtual Environment 现已支持 64 位 ARM（arm64）！

宣布 Proxmox Virtual Environment 首个正式支持第二种 CPU 架构的版本现已发布：64 位 ARM（arm64/aarch64）。此前，Proxmox VE 仅支持 x86-64（amd64）架构。

面向 arm64 的 Proxmox VE 9.2 与 x86-64 版本共享相同的代码库、软件包仓库以及发布生命周期。该版本基于 Debian 13.5 “Trixie” 构建，默认采用稳定版 Linux 内核 7.0，并搭载相同版本的底层核心技术 (sysin)，包括 QEMU 11.0、LXC 7.0 和 ZFS 2.4。除下方列出的少量架构相关差异外，配置方式、工具链和文档均与 x86-64 版本完全一致。

平台支持：

  • 在 NVIDIA Grace Hopper 和 NVIDIA Vera 平台上提供完整支持
  • 在其他基于 UEFI 的 ARMv9-A 或更新版本硬件上提供尽力支持（ARMv8-A 通常也可以运行，同样属于尽力支持范围）
  • 主机必须通过 UEFI 启动，并通过 ACPI 描述硬件信息
  • 仅支持设备树（Device Tree）的单板计算机（例如 Raspberry Pi）不受支持

架构相关差异：

  • 虚拟机始终通过 UEFI 启动，由 ARM 版本的 OVMF（AAVMF）提供支持。arm64 不提供 SeaBIOS。
  • AMD SEV 内存加密和 Intel GVT-g 虚拟 GPU 直通技术仅支持 x86 架构。
  • 与 x86 上的 intel-microcode 和 amd64-microcode 不同，arm64 没有操作系统级别的 CPU 微码软件包。
  • 虚拟机只能运行在与其架构匹配的节点上，实时迁移仅支持相同架构节点之间进行。

特别感谢 NVIDIA 对此次移植工作的信任与紧密合作，这使 Proxmox 能够在 arm64 平台上开发、测试并强化 Proxmox VE。目前，该版本已经在受支持的平台上投入生产环境使用。

Proxmox 正在与更多企业服务器厂商合作推进其 ARM 相关工作，并希望未来能够进一步扩大官方支持硬件平台列表。

Proxmox VE 正式推出 arm64 支持

Proxmox Virtual Environment 正式推出 arm64 支持

2026 年 8 月 5 日

  • 首个官方 arm64 版本，将 Proxmox VE 扩展至 x86-64 之外的架构。
  • 首发即完成对 NVIDIA Grace™ 和 NVIDIA Vera™ CPU 架构的官方验证。
  • 在 KVM、LXC、ZFS 和 Ceph 存储栈上实现完整的功能一致性。

奥地利维也纳 – 2026 年 8 月 5 日 —— 企业软件开发商 Proxmox Server Solutions GmbH 今日宣布，其旗舰平台 Proxmox Virtual Environment 首个官方支持的 arm64 版本正式发布。此次发布将这一开源虚拟化平台扩展至基于 Arm 的服务器系统，以满足企业对高密度、高能效数据中心架构不断增长的需求。

arm64 版 Proxmox VE 提供了统一的平台，用于管理 arm64 虚拟机和 Linux 容器（LXC）。用户可在受支持的 arm64 硬件上使用 Proxmox VE 成熟的 Web 管理界面、软件定义网络、存储、高可用集群以及备份等功能 (sysin)。

首个官方 arm64 版本即支持基于 NVIDIA Grace 和 NVIDIA Vera CPU 架构的系统。这些平台面向高要求的数据中心、云计算、加速计算以及 AI 训练和推理环境，为构建现代化、高能效数据中心的企业提供了更多基础设施选择。

🔧 在 NVIDIA Grace Hopper™ 系统上完成技术验证

Proxmox 与 NVIDIA 和 Supermicro 展开技术合作，工程团队在 NVIDIA Grace Hopper™ Superchip 服务器系统上进行了联合验证。这项工作使平台能够快速完成移植，并对整个软件栈进行了全面测试。目前，该平台已在部分企业生产环境中投入运行。

💾 ZFS 与 Ceph 实现完整功能一致性

arm64 版本基于 Proxmox VE 成熟的 Linux 和 KVM 基础构建，并完成了覆盖整个架构的全面验证。包括 ZFS 和 Ceph 在内的企业级核心存储技术均已完成优化 (sysin)，在性能、可靠性和功能方面与现有 x86 部署实现完全一致。

“随着数据中心不断向高密度、高能效架构演进，Proxmox 的客户希望在 arm64 平台上获得与 x86 一样值得信赖的关键业务稳定性，”Proxmox Server Solutions 首席运营官（COO）Tim Marx 表示。“通过与 NVIDIA 和 Supermicro 的紧密工程合作，Proxmox 确保企业能够充满信心地扩展其下一代 AI 和云工作负载，并依托可靠的底层虚拟机管理程序运行。”

“Proxmox 的目标不仅仅是让 Proxmox VE 能够运行在新的架构上，更重要的是实现完整的功能一致性：KVM、网络、集群、ZFS 和 Ceph 的行为都与用户在 x86-64 版本上的体验完全一致，”Proxmox Server Solutions 首席技术官（CTO）Thomas Lamprecht 表示。“直接在 NVIDIA Grace Hopper 系统上进行开发，使 Proxmox 从第一天起就在生产级硬件上完成了验证，而 NVIDIA 在上游内核方面的持续投入，也确保该平台能够随着 NVIDIA Grace 和 NVIDIA Vera 的发展持续演进。”

常见问题解答（FAQ）

❓ 问：Proxmox VE 的 arm64 版本是否属于技术预览版？

💡 答：不是。Proxmox VE arm64 版本在上述列出的平台上提供完整支持，并且与 x86-64 版本拥有相同的发布周期和支持周期。

❓ 问：arm64 是否提供企业仓库，并且是否提供企业支持？

💡 答：是。pve-enterprise 仓库现已支持 arm64，并且与 x86-64 一样，Proxmox 建议生产环境使用该仓库。拥有有效订阅的主机可以通过常规客户门户获得企业支持，服务级别与 x86-64 完全相同。

❓ 问：如何获取 arm64 主机的订阅？

💡 答：arm64 的订阅与 x86-64 订阅相互独立，目前需要单独申请。请联系销售团队获取报价。

❓ 问：其他 Proxmox 产品是否也会支持 arm64？

💡 答：Proxmox 已经针对部分产品（例如 Proxmox Backup Server）提供内部测试版本，并且有信心将其提升至正式发布标准。哪些产品优先支持取决于企业客户的需求，因此如果这对您很重要，请通过 Proxmox 的商务渠道联系。

❓ 问：哪些硬件获得官方支持？

💡 答：NVIDIA Grace Hopper 和 NVIDIA Vera 平台。其他基于 UEFI 的 ARMv9-A 或更新版本服务器硬件提供尽力支持；ARMv8-A 硬件通常也可以运行 (sysin)，同样属于尽力支持范围。

❓ 问：可以在 Raspberry Pi 或类似单板计算机上运行 Proxmox VE 吗？

💡 答：不可以。arm64 主机必须通过 UEFI 启动，并通过 ACPI 描述硬件信息。仅支持设备树的开发板以及传统启动方式均不受支持。

❓ 问：可以在一个集群中混合使用 x86-64 和 arm64 节点吗？

💡 答：技术上并未禁止，但混合架构集群不属于官方支持范围。请注意，虚拟机只能运行在对应架构的节点上，并且无法跨架构进行实时迁移。

❓ 问：可以将现有的 x86-64 节点上的虚拟机迁移到 arm64 节点吗？

💡 答：虚拟机数据可以通过离线迁移、备份恢复或共享存储方式进行移动，但虚拟机必须针对新的架构重新安装或重新配置后才能启动。

❓ 问：可以在 arm64 的 Debian 13 “Trixie” 上安装 Proxmox VE 吗？

💡 答：可以，安装流程与 x86-64 相同，请参阅：https://pve.proxmox.com/wiki/Install_Proxmox_VE_on_Debian_13_Trixie

❓ 问：软件包版本是否与 x86-64 相同？

💡 答：两个架构均基于相同源码构建，并跟踪相同版本。由于目前用于验证 arm64 架构的系统数量较少，部分软件包可能会在 arm64 上稍晚发布。

Proxmox VE 简介

Proxmox Virtual Environment，简称 Proxmox VE，是一款功能强大的开源服务器虚拟化平台，尽管它常被 VMware ESXi 和 KVM 等主流虚拟化方案所掩盖，凭借其免费和开源的特性，它非常适合家庭实验室爱好者和中小企业，这类用户的需求通常不同于大型企业。

Proxmox Virtual Environment

计算、网络与存储的一体化解决方案

Proxmox Virtual Environment（Proxmox VE）是一个完整的开源企业虚拟化服务器管理平台。它将 KVM 虚拟机管理程序与 Linux 容器（LXC）、软件定义的存储与网络功能紧密集成于一个平台 (sysin)。借助集成的基于 Web 的用户界面，您可以轻松管理虚拟机与容器、群集高可用性以及集成的灾难恢复工具。

企业级功能与 100% 纯软件架构使 Proxmox VE 成为虚拟化 IT 基础架构的理想选择，能够优化现有资源、提高效率，同时成本最小。您可以轻松虚拟化对性能要求极高的 Linux 和 Windows 应用负载，并可根据需求动态扩展计算与存储资源，确保数据中心具备未来发展所需的灵活性。
