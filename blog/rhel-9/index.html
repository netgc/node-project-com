Red Hat 官方发布

Red Hat Enterprise Linux 10.2 and 9.8 are here: The intelligent evolution of enterprise Linux

Red Hat Enterprise Linux（RHEL）10.2 与 9.8 正式发布，将操作系统从基础平台演进为关键应用、安全与创新的强大引擎。这些更新进一步强化了 RHEL 的核心能力，帮助 IT 领导者、开发者与管理员加速产品上市时间、简化混合云管理，并主动防御包括量子计算风险在内的高级威胁。这一整合式战略使您的组织能够基于全球领先的企业 Linux 平台实现创新、简化、保护与可信运行。

🐧 创新：加速您的开发节奏

企业创新依赖于为开发者提供最佳工具，并减少开发周期中的摩擦。RHEL 10.2 与 9.8 在这一领域带来了显著增强，尤其体现在前沿 AI 辅助能力以及核心开发工具链的全面升级。

面向命令行的增强 AI 辅助

命令行是 Linux 强大能力的核心，而我们正让它变得比以往更加智能。

  • goose 面向高级用户的命令：对于长期使用终端的高级用户，我们引入了 goose —— 一款先进的可选命令行 AI 助手（可通过扩展仓库获取）。在保留完全受支持的 RHEL 命令行助手的同时，goose 提供了更强大的体验，它连接至同一可信 AI 后端，并支持流式响应 (sysin)，以及与适用于 RHEL 的全新模型上下文协议（MCP）服务器（开发者预览版）进行集成。这意味着您能够更快速、更灵敏地获取所需的洞察与命令，从而减少搜索信息所花费的时间。

  • 改进的可视化输出：RHEL 命令行助手现已增强对彩色输出的支持。该功能可在输出中直观地区分命令、脚本与说明内容，使信息更加易读、易理解且易执行，从而提升管理员的工作效率。

业务价值：更快的问题解决速度，以及帮助新管理员更迅速地熟练掌握系统。这将转化为更高的开发者生产力以及更快的项目推进节奏。

全新开发工具集：更新能力，更强性能

保持领先意味着能够使用最新、性能最佳的重要语言与工具版本。RHEL 10.2 与 9.8 通过以下更新强化基础平台：

  • Go Toolset 1.26：新增 Green Tea 垃圾回收器、运行时性能与安全增强、HPKE 支持。

    • 影响：改善尾延迟、提升性能，并增强现代安全能力。

  • LLVM Toolset 21：新增 ThinLTO 后端（DTLTO），以及多个目标后端改进。

    • 影响：增强编译器优化能力，生成更快、更高效的应用程序二进制文件。

  • Rust Toolset 1.92：Cargo 原生工作区发布支持 (sysin)、调试改进、系统编程增强。

    • 影响：简化构建流程，并提升系统级开发可靠性。

  • Python 3.14：实时语法高亮、更智能的自动补全、扩展类型系统、面向未来的性能优化。

    • 影响：提升开发者生产力，并为下一代 Python 工作负载做好准备。

  • Ruby 4.0：新增 ZJIT 编译器、Ruby Box 定义分离、Ractor 改进。

    • 影响：显著提升 Ruby 应用性能，并增强并发能力。

  • Git 2.51：支持 stash 导出与导入、ORT 合并引擎加速冲突解决、新 Git backfill、稳定版 Git switch 与 restore。

    • 影响：提升代码管理效率，并实现更快速、更可靠的源码控制操作。

  • PHP 8.4：对象属性钩子、不对称属性可见性、惰性对象。

    • 影响：提供现代化语言特性，使 PHP 开发更加简洁且健壮。

  • OpenJDK 25：Generational Shenandoah、G1 的 Late Barrier Expansion、Ahead-of-Time profiling。

    • 影响：显著提升 Java 应用性能与稳定性。

  • PostgreSQL 18：异步 I/O 支持、更快速升级、虚拟生成列、UUIDv7。

    • 影响：显著提升数据库性能，并增强高级数据管理能力。

  • MariaDB 11.8：新增 VECTOR 数据类型与向量索引，默认字符集切换为 utf8mb4。

    • 影响：为现代数据工作负载做好准备，包括 AI/ML 向量处理与更广泛字符支持。

🐧 简化：通过镜像模式精简运维

RHEL 10.2 与 9.8 通过引入并增强适用于 RHEL 的镜像模式（基于 bootc）功能，降低运维开销，推动全新的操作系统部署与管理范式。可启动容器（bootc）镜像模式彻底改变了操作系统的部署、管理与更新方式。RHEL 操作系统本身被视为不可变容器镜像，从而天然具备一致性与韧性。

  • 通过 bootc 预下载更新：全新的 bootc 选项允许您先将操作系统更新下载至整批机器，而无需立即应用 (sysin)。这对于管理系统在线时间、防止意外重启以及按计划执行维护至关重要。

  • 通过可启动容器与 Virtualization Kit（BCVK）简化虚拟机部署：对于开发者与测试人员而言，BCVK 可简化从本地容器构建（例如使用 Podman）直接迁移至自动部署的临时虚拟机（VM）测试环境的流程，从而加快测试循环。

  • 高效容器存储：通过在容器存储中保留专用且独立的操作系统副本，我们减少了本地磁盘空间占用与网络带宽消耗。更重要的是，该架构通过保护核心操作系统文件免受容器相关操作（例如 podman system reset）影响，从而提升系统韧性。

  • 面向大规模环境的逻辑绑定镜像：这一创新使组织能够基于单一标准化基础镜像管理多样化系统配置。这减少了维护大量不同镜像的需求，简化了大规模异构环境中的维护与更新。

管理与升级自动化

除了镜像模式外，RHEL 还提供了用于简化传统管理任务的重要工具：

  • 增强版 RHEL 镜像构建命令：全新的命令行接口（CLI）通过消除持续运行服务的需求，简化了自定义 RHEL 镜像创建流程。这种设计更加适合容器化场景，并能够无缝集成至 CI/CD 流水线，实现镜像自动构建。

  • Red Hat Enterprise Linux 升级系统角色：这一 Red Hat Ansible Certified Content Collection 能够自动解决 Leapp 识别出的常见升级前问题。通过提供升级前报告并自动应用修复，它实现了更加平滑且可靠的升级流程，并减少人工干预。

业务价值：实现跨混合云环境的一致化运维，降低磁盘空间与网络成本，并减少维护窗口时间。全新的镜像模式能力可在大规模环境中提供更高稳定性与可预测部署。

🐧 防护：应对新兴威胁

在网络威胁持续增长的时代，RHEL 10.2 与 9.8 提供了超越传统防御模式的安全增强，以帮助应对当前漏洞以及未来诸如量子计算等生存级威胁。

面向不可变系统的客户可控安全机制

在镜像模式（bootc）中启用的 RHEL 10.2 Sealed Images（技术预览）带来了客户可控安全能力，为操作系统提供端到端加密完整性保护。

您的组织可使用自有安全启动密钥在构建阶段对镜像进行签名，并将目标系统配置为仅信任内部认证镜像 (sysin)。这构建了一条完整信任链，使每个组件在执行前与运行过程中均经过加密验证，从而降低主机遭篡改的风险。

通过 Red Hat Certificate System 11.0 应对量子威胁

量子计算机破解现有加密体系的威胁是真实存在的战略风险。与 RHEL 一同提供的 Red Hat Certificate System 11.0 有助于应对这一挑战。

  • 后量子密码学（PQC）：新版证书系统集成了 NIST 标准化 ML-DSA 签名，使您的公钥基础设施（PKI）能够满足面向抗量子算法的新兴 NIST 标准（FIPS 204）。现在开始采用这一能力，对于防御攻击者“现在收集、未来解密”的策略至关重要。

  • 面向大规模环境的自动化：证书有效期正在迅速缩短（预计到 2029 年可能低至 47 天）。手动续订已不可持续。Certificate System 11.0 引入了零接触部署功能，通过安全的一次性密码（OTP）自动完成证书签发。该功能可将 1,000 台设备原本需要一周的人工操作转变为几分钟内完成的自动化任务，从而在零信任架构中实现合规与安全。

业务价值：为 PQC 合规要求（可能最早于 2027 年实施）做好准备，降低因证书过期或管理不当带来的运维风险，并为混合云中的核心操作系统提供最高级别的加密完整性保障。

🐧 可信：可靠的升级与迁移支持

RHEL 的最后一个核心支柱是“可信”，这建立在 Red Hat 对稳定性、支持能力以及清晰发展路径始终如一的承诺之上。

简化迁移与升级路径

  • 通过增强版 Leapp 实现一步完成转换与升级：Leapp 现已增强，可通过单条命令直接转换至受支持的 RHEL 环境，并同时升级至更新的主版本。相比此前的两步流程，这种整合方式能够降低停机时间与复杂度。

  • 由 Ansible Automation Platform 驱动的 AI 引导式 RHEL 升级：我们发布了 Red Hat Ansible Certified Content，将 Red Hat 数十年积累的升级经验与最佳实践进行封装。这些内容倡导“快速失败、持续迭代”的方式，为原地升级提供经过验证的自动化流程。它能够将升级任务委派给最合适的团队，从而实现更高可靠性与可控性。

业务价值：减少升级期间停机时间，通过整合维护窗口降低运维成本，并确保您的 RHEL 迁移过程获得 Red Hat 最佳实践与认证自动化能力支持。

🐧 总结：RHEL 成为您的战略优势

Red Hat Enterprise Linux 10.2 与 9.8 是 Linux 操作系统的战略性演进，旨在通过将先进 AI 注入命令行、利用镜像模式实现运维简化、通过后量子密码学增强未来安全，以及借助 AI 引导升级提升稳定性，满足现代企业需求。

RHEL 被定位为跨混合云环境中一致、智能且安全的基础平台，从数据中心一直延伸至最边缘的设备，使您能够专注于推动业务持续向前发展。立即升级，释放 IT 基础设施的全部潜力。

RHEL 9 发布公告

2022 年 5 月 18 日，IBM 收购的红帽公司宣布推出红帽企业 Linux 9 (RHEL 9)，这是世界领先的企业 Linux 平台的最新版本。RHEL 9 为支持混合云创新提供了更灵活、更稳定的基础，并为跨物理、虚拟、私有和公共云和边缘部署部署应用程序和关键工作负载提供了更快、更一致的体验。

新增内容

RHEL 9 包括功能和增强功能，可通过使用通用、灵活的基础来支持创新并加快上市时间，从而帮助实现 IT 的长期成功。

主要特点和优势

以下是 RHEL 9 中包含的一些亮点。

  • 面向当今和未来的开发人员的新平台

    完成向 Python 3 的迁移，版本 3.9 将成为 RHEL 9 生命周期的默认 Python。Python 3.9 带来了一些新的增强功能，包括时区感知时间戳、最近的字符串前缀、后缀方法和字典联合操作，以帮助开发人员现代化现有的应用。

    RHEL 9 还使用 GCC 11 和最新版本的 LLVM、Rust 和 Go 编译器构建。RHEL 9 基于 glibc 2.34，具有 10 多年的企业级平台稳定性 (sysin)。

    最后，在 RHEL 中，链接时间优化 (LTO) 将首次在用户空间中默认启用，以对应用程序代码进行更深入的优化，以帮助构建更小、更高效的可执行文件。

  • 对未来 RHEL 版本的简单贡献路径

    组织现在可以开发、测试和贡献一个持续交付的发行版，该发行版在 RHEL 之前就可以跟踪。CentOS Stream 是一个上游开源开发平台，为下一个次要版本提供了无缝的贡献路径。RHEL 9 是第一个从 CentOS Stream 构建的 RHEL 主要版本，而 RHEL 9 Beta 最初是作为 CentOS Stream 9 提供的。所有未来的 RHEL 9 版本都将从 CentOS Stream 构建。

  • 新一代应用程序流

    在 RHEL 8 中引入应用程序流和模块打包的基础上，RHEL 9 中的所有打包方法都被合并到应用程序流中，包括模块、SCL、Flatpacks 和传统的 RPM，使其更易于使用。

  • 继续致力于多种架构支持

    开源软件通过防止工作负载被锁定到特定供应商，使用户能够更好地控制他们的数字化未来。RHEL 通过为需要不断发展的业务环境的用户启用不同的 CPU 架构，将这种控制扩展到源代码之外。无论您是在 x86_64、aarch64、IBM POWER9、Power10 还是 IBM Z 上运行工作负载，我们都能满足您的需求。

  • 容器改进

    如果您正在使用通用基础映像 (UBI) 容器镜像构建应用程序，则需要查看 RHEL 9 UBI 映像。可以使用标准 UBI 映像，以及 micro、minimal 和 init 映像。要获得完整的体验，请在完全订阅的 RHEL 9 容器主机上测试 UBI 映像，从而允许您从 RHEL 9 存储库中提取额外的 RPM。

  • 边缘的 RHEL

    RHEL 9 引入了自动容器更新和回滚，从而扩展了自动更新容器镜像的能力。Podman 现在可以检测更新的容器是否无法启动并自动回滚配置。与现有的操作系统级回滚一起，这为应用程序提供了新级别的可靠性。

  • 镜像生成器即服务

    RHEL 9 中的 Image Builder 增强功能可帮助组织节省时间并大规模提高系统一致性 (sysin)。借助新的 Image Builder as-a-Service，组织现在可以通过我们的托管服务构建标准化和优化的操作系统映像，并将其部署到选择的云提供商。

  • 身份和安全

    RHEL 9 添加的新功能有助于简化组织在部署新系统或管理现有基础架构时管理安全性和合规性的方式。RHEL 9 现在提供完整性测量架构 (IMA) 来动态验证操作系统的完整性，以检测它是否已被破坏。RHEL 9 也得到了增强，包括数字签名和哈希，可帮助组织检测整个基础架构中的恶意修改。

  • 自动化和管理

    组织现在可以访问 RHEL 9 Web 控制台中增强的性能指标页面，以帮助识别 CPU、内存、磁盘和网络资源使用高峰的潜在原因。此外，客户可以更轻松地将指标导出到 Grafana 服务器。还可以通过 Web 控制台进行内核实时补丁管理，以显着降低执行关键维护的复杂性。控制台还添加了一个简化的界面，用于在不使用命令行工具的情况下应用内核更新。

  • 预测分析

    Red Hat Insights 现在包含资源优化，它可以在公共云中正确调整 RHEL。资源优化通过评估性能指标来确定工作负载利用率来做到这一点。然后，Insights 提供可见性和建议，以针对工作负载需求优化到更合适的实例。Insights 还添加了恶意软件检测，这是一种安全评估，可分析整个企业的 RHEL 系统中已知的恶意软件签名，并提供风险的详细可见性。
