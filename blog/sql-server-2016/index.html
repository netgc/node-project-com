SQL Server 2016

Microsoft SQL Server 是一种关系数据库管理系统 (RDBMS)。应用程序和工具连接到 SQL Server 实例或数据库，并使用 Transact-SQL (T-SQL) 进行通信。

利用内置了所有功能（从内存中性能和高级安全到数据库内分析）的可扩展混合数据库平台，构建智能的任务关键型应用程序。

SQL Server 2016 功能亮点

行业领先

利用突破性的可扩展性、性能和可用性构建用于联机事务处理 (OLTP) 的任务关键型智能应用程序。

高级安全

保护静态和动态数据。据 NIST 漏洞数据库统计 (sysin)，SQL Server 连续 6 年被评选为漏洞最少的数据库。

数据库内高级分析

使用常用的 R 统计语言，直接在 SQL Server 数据库内分析数据，而无需移动数据。可在任何设备（在线或离线）上提供见解，成本仅为其他自助服务解决方案的五分之一。

专为混合云环境构建

获得一致的平台和工具，从而更轻松地在数据中心、私有云或 Microsoft Azure 之间移动工作负载。
