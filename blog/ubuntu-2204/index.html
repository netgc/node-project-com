发行说明

Ubuntu 22.04 LTS (Jammy Jellyfish) 已于 2022 年 4 月 21 日正式发布。

代号为 “Jammy Jellyfish” 的 Ubuntu 22.04 LTS 就在这里。本次发布延续了 Ubuntu 集成最新和将最伟大的开源技术转化为高质量、易于使用的 Linux 发行版。

Ubuntu Desktop 22.04 LTS 获得显着的可用性、电池和性能 GNOME 42 的改进。它具有 GNOME 电源配置文件和流线型工作空间过渡以及可以翻倍的重大优化 Intel 和 Raspberry Pi 图形驱动程序上的桌面帧速率。

Ubuntu 22.04 LTS 是第一个 LTS 版本，其中包含整个最近的 Raspberry Pi 设备组合支持 (sysin)，从新的 Raspberry Pi Zero 2W 到 Raspberry Pi 4。Ubuntu 22.04 LTS 为内存安全的系统级添加了 Rust 编程。它还使用新的加密算法迁移到 OpenSSL v3 以提高安全性。

对于追求时尚的人，Ubuntu Desktop 22.04 LTS 提供了十种不同的强调色，适用于 Yaru 的深色和浅色变体主题，以及迄今为止最广泛的社区壁纸选择。

最新的 Ubuntu Budgie、Kubuntu、Lubuntu、Ubuntu Kylin、Ubuntu MATE、UbuntuStudio 和 Xubuntu 也在今天发布。更多细节可以在它们各自的发行说明中找到这些官方口味部分：

https://discourse.ubuntu.com/t/jammy-jellyfish-release-notes/

Ubuntu 22.04 LTS 新特性

Linux kernel

Ubuntu 22.04 LTS 为每个产品线提供了不同的优化内核：

  • Ubuntu Desktop 将在最新一代的认证设备 (linux-oem-22.04) 上自动选择加入 v5.17 内核
  • Ubuntu Desktop 在所有其他几代硬件上使用滚动 HWE 内核 (linux-hwe-22.04)。滚动 HWE 内核基于 22.04.0 和 22.04.1 版本的 v5.15 内核 (sysin)。
  • Ubuntu Server 默认为非滚动 LTS 内核 v5.15 (linux-generic)。
  • Ubuntu Cloud 和设备与合作伙伴合作使用优化的内核 v5.15+。
