UTM for Mac 是一款基于 QEMU 的 macOS 虚拟机与模拟器应用，用于在 Mac 上运行和测试 Windows、Linux 等多种操作系统。

UTM 是什么？

UTM 是一款面向 iOS 和 macOS 的全功能系统模拟器和虚拟机宿主，基于 QEMU。简而言之，它可以让你在 Mac、iPhone 和 iPad 上运行 Windows、Linux 等多种操作系统。

QEMU（Quick Emulator）是一款开源的机器模拟器和虚拟化软件，由 Fabrice Bellard 于 2003 年创建。它通过动态二进制转换技术实现跨平台虚拟化，支持 x86、ARM、MIPS 等多种处理器架构。QEMU 既可以作为独立虚拟机运行完整的操作系统，也可与 KVM（基于内核的虚拟机）配合使用实现硬件加速虚拟化 (sysin)，这种组合方案能够提供接近原生性能的虚拟化体验。

QEMU 核心特点是跨平台虚拟化支持，支持 x86、ARM、RISC-V、PowerPC 等多种处理器架构，可在 Windows、Linux、macOS 等操作系统上运行，这意味着在 iOS 上也可以运行 Windows x86 系统。

UTM 和 QEMU 的关系可以概括为：UTM 是基于 QEMU 构建的图形化虚拟化与系统模拟工具。

快速入门

1、使用 “+” 按钮打开新的虚拟机向导。

2、 选择一个虚拟机以显示其详细信息；对虚拟机进行右键点击或使用 Force Touch 可打开 操作菜单 (actions menu)。

3、使用启动按钮快速启动虚拟机。

4、通过工具栏最右侧的图标打开 设置 (settings)。

5、在详情视图中，点击 “浏览…” 按钮选择一个 共享目录 ( shared directory)。

6、在详情视图中打开驱动器菜单，选择要挂载（或弹出）的可移动磁盘映像

UTM 5 新增功能

✅ 主要更新

  • （macOS）Windows 的 DirectX 图形支持：UTM 首次支持为 Windows 11 提供现代化的硬件加速图形功能。目前该驱动仍处于实验阶段，对游戏的兼容性也比较有限。
  • Linux 的 Vulkan 1.3 图形支持：Linux 虚拟机现在可以通过 Mesa 中的 VirtIO Venus 驱动支持 Vulkan 1.3。此外，借助全新的 Apple Core OpenGL 后端（仅限 macOS），还支持 OpenGL 4.1。
  • 快照：现在可以随时保存虚拟机的当前状态 (s)，并在之后通过新增的 Snapshots（快照）选项卡恢复到该状态。此功能适用于 macOS 和 iOS 26 上的 QEMU 虚拟机，以及 macOS 27 上使用 Apple Virtualization 的虚拟机。
  • （macOS）macOS 27 上的 Apple Virtualization：现在可以将 USB 设备直通给虚拟机、为 Linux 启用安全启动（Secure Boot）、以不保存更改的方式运行虚拟机，还可以通过新增的网络模式让不同的虚拟机相互通信。
  • （iOS）更出色的触控操作：手势响应更加迅速，并新增了鼠标中键点击、右键拖动操作，以及全新的触控拖动滚动模式。
  • （iOS）iPhone Duo：可以像合上笔记本电脑一样折叠 iPhone Duo，折叠后的下半部分可变成键盘或触控板，用于操作虚拟机。

✅ 注意事项

  • 更新后，处于挂起状态的虚拟机可能无法正常恢复。建议在更新 UTM 之前关闭所有虚拟机。
  • 现在支持的最低系统版本为 macOS 12 和 iOS 15。
  • （macOS）为了使用适用于 Windows 11 的新图形驱动，我们建议全新安装系统，因为该驱动仍处于实验阶段，使用它可能导致系统不稳定。安装虚拟机工具（Guest Tools）时，系统会提示你选择实验性图形驱动。如果你希望在已经使用旧版纯显示驱动（Display-only Driver）的系统上安装新驱动，则必须先运行 Guest Tools 安装 ISO 中提供的卸载脚本。
  • （macOS）Apple CoreGL 后端不支持 Vulkan 或 DirectX。
  • 由于缺少对几何着色器间接绘制（Indirect Draws）的支持，Linux 桌面无法在 Vulkan 模式下正常渲染。请将虚拟机配置为使用较旧的 VirGL Gallium 驱动。
