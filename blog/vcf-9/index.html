什么是 VCF

VMware Cloud Foundation（VCF）是一款私有云平台，在提供本地环境安全性、韧性与性能的同时，实现媲美公有云的规模与敏捷性，并降低总体拥有成本（TCO）。

VCF 可帮助企业通过更快的基础架构现代化、统一的云体验，以及更强的网络韧性与平台安全性，加速数字化创新。

VCF 可在任何环境中提供一致的私有云体验，无论是客户自管数据中心、边缘位置，还是任意云端终端。

VCF 同时支持传统工作负载以及容器、AI/ML 等现代工作负载，并通过基础架构即服务（IaaS）的自助式消费体验，帮助应用团队更快将现代化应用推向市场。

采用 VMware Cloud Foundation 的现代私有云平台

  • VMware Cloud Foundation 是一个全栈 IaaS 平台，可提供软件定义的计算、存储、网络、安全与管理能力。
  • 集成化自动化能力可通过自助服务平台部署虚拟机与容器，从而提升开发敏捷性。
  • 提供经过加固的平台能力，内置韧性、扩展与集群能力 (sysin)，以支持业务持续运行。
  • 在无需扩充运维人员规模的情况下，实现基础架构云化扩展，并在本地环境提供云化消费体验。
  • 提供自动化与编排能力，以简化 Day 0、Day 1 与 Day 2 生命周期运维任务。
  • 简化全栈部署流程。

VCF Installer 概述

VCF Installer 是一个专用虚拟机，用于帮助用户规划、配置与部署 VCF 及 vSphere Foundation 组件。

使用 VCF Installer 可以执行以下操作：

  • 下载部署 VMware Cloud Foundation 或 VMware vSphere Foundation 所需的二进制文件。
  • 规划所需的 VCF 或 VMware vSphere Foundation 部署规模与配置。
  • 部署并配置新的 VCF 或 VMware vSphere Foundation 平台。还可以为新的 VCF Fleet 复用现有的 VCF Operations 与 VCF Automation 实例。
  • 使用现有虚拟化基础架构并将其整合（Converge）到 VCF 或 vSphere Foundation 平台中。
  • 通过部署额外的 VCF Instance 来扩展现有 VCF Fleet。
  • 部署 VCF 管理服务与许可证服务器 (sysin)，以完成 vSphere Foundation 升级至 9.1。
  • 查看历史部署过程详情、下载密码以及下载 VCF 或 vSphere Foundation 部署的 JSON 配置规范。

VCF Installer 支持主版本、次版本以及维护版本，但不支持 Patch 或 Express Patch 发布。完成 VCF Installer 工作流后，可以手动应用补丁。

新增功能

VMware Cloud Foundation 9.1 | 12 MAY 2026

以下是 VMware Cloud Foundation 9.1 的关键特性与能力：

  • Enhanced NVMe Memory Tiering（增强型 NVMe 内存分层）

    Hypervisor 可将活跃页面分层至 DRAM，将冷数据页面分层至本地 NVMe，在无需增加额外 DRAM 的情况下扩展有效内存容量，并新增基于软件的镜像以及成本节省分析功能。

  • Extended vSAN Deduplication, Compression（扩展 vSAN 重复数据删除与压缩）

    内联数据缩减能力现已扩展至更多集群类型和工作负载场景，从而降低每逻辑 TB 所需的原始存储容量。同时新增对静态数据加密（data-at-rest encryption）的重复数据删除支持，并改进压缩能力。

  • vSphere Elastic Provisioning (Zero Touch)（vSphere 零接触弹性部署）

    可通过基于网络的镜像（UEFI、HTTP/S）自动在裸金属服务器上引导并配置 ESX，无需任何人工干预。

  • VCF Management Services（VCF 管理服务）

    VCF 9.1 新增统一运行时与组件集，用于统一生命周期管理与运维能力的架构：VCF management services。

  • VKS and VM Fast-Deploy（VKS 与虚拟机快速部署）

    通过链接克隆（linked clone）技术显著加快 VKS 与虚拟机集群的部署与升级速度，大幅提升运维敏捷性和价值交付速度。

  • Simplified Container-as-a-Service（简化版容器即服务）

    提供自助式 Namespace 创建能力，可继承 VCF 的镜像仓库、Ingress、配额与身份配置；无需完整 K8s 管理，即可更简单、更快速地部署少量容器。

  • Native Object Storage (Tech Preview)（原生对象存储（技术预览））

    为开发者提供自助式 S3 对象存储，同时由 IT 保持统一治理；可通过与块存储和文件存储相同的工作流部署、扩展与管理对象存储。

  • Live Patching for ESX for TPM-enabled hosts（面向启用 TPM 主机的 ESX 热补丁）

    补丁直接应用于正在运行的内核内存中，虚拟机可持续运行而无需维护窗口，可覆盖高达 80% 的补丁场景。

  • Continuous Compliance Enforcement（持续合规性强制执行）

    Advanced Cyber Compliance 现已支持持续合规修复以及针对整个 VCF 技术栈的统一安全态势管理。

  • On-prem Ransomware Recovery（本地勒索软件恢复）

    集成式网络恢复能力可将工作负载恢复至本地 VCF 隔离洁净室（isolated clean room）。
