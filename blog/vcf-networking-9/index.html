VCF Networking (NSX)

VMware Cloud Foundation Networking (NSX)

VCF Networking 为 VMware Cloud Foundation 中的工作负载提供高性能连接、网络服务以及敏捷运维能力。

重塑私有云网络

✅ 提供一致的工作负载连接能力

利用基于 EVPN 的交换网络互操作能力，在虚拟与物理工作负载域之间实现高效、高性能的连接。

✅ 加速应用部署

通过为应用团队提供网络服务的自助访问能力，加速应用交付 (sysin)。可通过 vCenter 或 VCF Automation 部署 VPC，将应用配置时间从数周缩短至数分钟。

✅ 简化运维与合规管理

通过基于 VPC 和组的更简化分段方式，实现增强的策略控制、多租户运维以及合规能力。

核心能力

VMware Cloud Foundation Networking (NSX) 核心能力

✅ 可扩展且灵活的网络能力

将网络与硬件解耦，以支持各种环境 (sysin)。能够轻松扩展并适应不断变化的业务与应用需求。

✅ 为应用团队提供云化体验

通过简单的一次性网络配置，以及基于 VPC 提供的自助连接与网络服务，加快工作负载部署速度。

✅ 与交换网络的互操作能力

通过 VCF Networking 与交换网络之间基于 EVPN-VXLAN 的互操作能力，为所有工作负载实现一致的端到端网络架构与运维模型 (sysin)。

✅ 多租户云运维

通过统一平台对 VCF 工作负载域中的连接与网络服务进行扩展、优化和管理，实现计算、存储与网络的一体化运营。

✅ 高性能连接能力

通过 ESX 主机与交换网络之间的直连，以及 Enhanced Data Path（EDP），简化架构并为 VCF 工作负载提供更快速的连接能力。

✅ 高级安全与合规能力

通过微分段与加密技术保护您的环境，并通过统一控制台管理安全、运维与合规。
