新增功能

Veeam Backup & Replication v11a 是版本 11 的更新版本，它解决了客户在原始版本上报告的问题，并添加了以下新功能和增强功能：

平台支持：

  • Microsoft Windows Server 2022 和 Microsoft Windows 10 21H1 现在支持作为来宾操作系统、Hyper-V 主机、用于安装 Veeam Backup & Replication 组件以及使用 Veeam Agent for Microsoft Windows 5.0.1（包含在 11a）。

    警告：避免将现有的基于 Server 2019 的 ReFS 备份存储库升级到 Server 2022 和 / 或将 ReFS 卷从 Server 2019 安装到新的 Server 2022 安装，直到 Microsoft 解决的 已知回归问题 ReFS 格式升级代码中。

  • Microsoft Windows 11 就绪 基于预发布版本的。当 GA 版本可用时 (sysin)，官方支持将需要对其进行全面回归测试。本文将在之后更新支持声明。

  • Microsoft Azure Stack HCI 版本 21H2 支持基于主机的 Hyper-V VM 备份。

  • RHEL/CentOS 8.4、Ubuntu 21.04、Debian 11、SLES 15 SP3、OpenSUSE Leap 15.3、Fedora 34 现在支持发行版作为来宾操作系统，用于安装 Veeam Backup & Replication 组件，以及使用 Veeam Agent 进行基于代理的备份 Linux 5.0.1（包含在 11a 中）。有关受组件支持的发行版的完整列表，请参阅发行说明文档的系统要求部分。

  • VMware Cloud Director 10.3 支持。 此外，v11a 支持在具有多个 vCloud Director 服务器的环境中部署 Veeam Self-Service Backup Portal。

  • VMware VMC 15 支持， 包括 VM 还原操作与使用 VDS 7.0 而不是 N-VDS 交换机的 NSX-T 3.0 网络的兼容性。

  • VMware vSphere 7.0 U3 准备就绪 基于预发布版本的。当 GA 版本可用时，官方支持将需要对其进行全面回归测试。本文将在之后更新支持声明。
