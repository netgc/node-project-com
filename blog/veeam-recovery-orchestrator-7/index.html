功能概述

一键实现干净恢复

  • 无缝恢复 全新

    持续进行勒索软件扫描，并确定最新的干净还原点，以快速还原干净数据。

  • 聚焦恶意软件 全新

    在 Veeam 威胁中心，突出显示威胁 (sysin)，并评估风险以及环境的安全评分。

  • 无中断地实施计划内故障切换 全新

    当需要制定和执行故障切换计划而不中断可推动业务发展的关键工作负载时，执行经过验证的细致编排恢复。

  • 自动化云恢复验证 全新

    在将内部工作负载恢复到 Microsoft Azure 时自动执行手动恢复后任务，以节省时间。

  • 企业集成

    使用 API 完美融入您的环境中，并在测试和执行期间运行自定义脚本。

  • 恢复至云端

    借助编排的直接还原到 Microsoft Azure，您的业务可通过基于云的灾难恢复获得额外的弹性。

  • 自动化测试

    按需执行无中断灾难恢复测试，确保达成所需的 RTO 和 RPO。

  • 动态文档

    自动生成和创建灾难恢复文档 (sysin)，以证明就绪度和合规性。

  • 一键恢复

    只需从 Web 界面点击一下，即可从任何位置轻松恢复单个应用程序或整个网站。

  • 基于角色的安全访问

    为应用程序所有者和运营团队授予安全访问权限并进行有效控制。

  • 应用程序验证

    确认您常见的企业应用程序在恢复后正常运行。

  • 即时测试实验室

    在不影响生产的情况下，使用备份和复制副本进行补丁测试。
