VeloCloud SD-WAN

VeloCloud 现已加入 Arista 广域网（WAN）解决方案产品组合！


图 1：VeloCloud 通过 Cloud WAN 连接 Arista

Arista 在企业园区有线与无线解决方案领域的领先地位，如今进一步扩展，纳入了业界领先的软件定义广域网（SD-WAN）与云广域网（Cloud WAN）解决方案，用于通过互联网将企业分支机构连接至总部。这一方案由 VeloCloud 提供支持——它是 Arista 产品组合中最新的成员。

在这个由 AI 工作负载深刻影响的高速数字时代，将强大的路由功能与 SD-WAN 技术相结合，使现代企业能够在分布式环境中实现对连接、安全与应用控制的集中优化与管理 (sysin)。

  • VeloCloud 安全与 AI 解决方案

    通过端到端加密与集成的第七层防火墙实现零信任网络，并借助 AI 简化 Cloud WAN 运维，同时针对由智能代理型 AI（agentic AI）与生成式 AI（genAI）带来的新型流量模式进行高级流量优化。

  • SASE 集成

    将业界领先的 VeloCloud SD-WAN 与主流安全服务边缘（SSE）解决方案结合，实现用户从任意地点到边缘、云与数据中心应用的可靠、安全与最优连接。

  • Arista WAN 路由

    提供企业级路由平台，支持物理、虚拟与云部署形态，均运行相同的 EOS 软件，以确保在园区、数据中心、云与广域网环境中的一致运维体验。

通过显著降低运维复杂度与成本，Arista 的先进产品组合实现了动态路径选择、应用感知路由与多种传输类型的无缝集成，从而为用户、设备与云应用提供高可靠、高性能的连接。这种灵活性让企业能够快速部署新站点、优化带宽利用，并迅速应对不断变化的业务需求 (sysin)。

VeloCloud SD-WAN 概述

基于软件定义网络（SDN）原则，VeloCloud 实现了从边缘到数据中心及云的融合云网络。通过端到端自动化、应用连续性与分支机构数字化改造，VeloCloud 为希望将业务拓展至数据中心之外的企业提供了现代化的高性能运营能力。

VeloCloud SD-WAN 专为当今的分布式企业设计。其底层基于 VeloRAIN 强大的 AI 网络架构，可优化企业网络中 AI 与现代工作负载的运行表现。

现代 SD-WAN 的优势

Benefits from Modern SD-WAN

  • 边缘增长的灵活基础：

    SD-WAN 已成为分布式企业边缘的基础，不仅用于构建混合 WAN 或云连接。

  • 支持多云运营：

    实现用户与分支机构安全地“到云”、“经云”和“与云”的连接，而无需消耗数据中心资源。

  • 提升运维效率：

    借助 AIOps 的能力快速定位根因并修复应用性能问题，简化运维复杂度。

  • 赋能企业员工：

    实现“随时随地办公”——安全、便捷且高效 (sysin)。

  • 灵活支持应用：

    VeloCloud SD-WAN 支持数百种主流安全服务边缘（SSE）提供商与虚拟网络功能（VNF）应用。

  • 应对新型业务场景：

    借助为数字化转型而设计的 SD-WAN 平台，在边缘场景中灵活引入新应用。

支持企业运营的关键能力

Capabilities to Support Enterprise Operations

  • 动态多路径优化（Dynamic Multipath Optimization）

  • 零接触部署（Zero-Touch Provisioning）

  • 深度应用识别（Deep Application Recognition）

  • 动态应用切片（Dynamic Application-Based Slicing）

  • 高可用性部署模型（High-availability Deployment Models）

  • 增强型防火墙服务（Enhanced Firewall Services）

  • 全球网关网络（Global Network of Gateways）

  • 通过 Orchestrator 实现集中管理（Centralized Management via Orchestrator）

VeloCloud SD-WAN 的差异化优势

The VeloCloud SD-WAN Difference

  • 云原生工作负载与应用性能：

    VeloCloud SD-WAN 与 SASE 支持广泛的服务生态，包括 AWS Cloud WAN、Azure Virtual WAN 以及 Google Cloud Network Connectivity Center。

  • AI 网络与 AIOps：

    VeloRAIN 是 VeloCloud 采用的参考架构，用于以智能化方式识别并优先处理应用。它引入了一种创新的基于应用层的网络切片方法，并利用 AI 对匿名化的实时数据进行分析，以自动化网络运维并动态调整策略。
