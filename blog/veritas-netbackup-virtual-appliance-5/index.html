NetBackup Virtual Appliance 产品说明

NetBackup Virtual Appliance 产品是一种可扩展的数据保护解决方案，旨在将 NetBackup 解决方案集成到您的虚拟环境中。它提供了现有 NetBackup 物理设备解决方案的替代方案，让您可以使用自己的硬件并利用现有的 NetBackup 专业知识。

NetBackup Virtual Appliance 产品提供以下解决方案：

  • NetBackup Virtual Appliance 主服务器

    NetBackup Virtual Appliance 提供了用于在虚拟环境中部署的专用 NetBackup 主服务器解决方案 (sysin)。它提供常规 NetBackup 主服务器的功能，但需要最少的现场基础架构管理专业知识。

  • NetBackup Virtual Appliance 组合的用于远程办公室和分支机构 (ROBO) 的主服务器和介质服务器

    NetBackup Virtual Appliance 为远程办公室或分支机构提供了组合的主服务器和介质服务器解决方案。它为数据保护要求较小的环境提供了现有 NetBackup Appliance 解决方案的低成本替代方案 (sysin)，并且需要最少的现场基础架构管理专业知识。您可以将 NetBackup 虚拟设备配置为链接回数据中心的 NetBackup，以复制远程办公室或分支机构数据。

  • 适用于数据中心 (DC) 的 NetBackup Virtual Appliance 介质服务器

    NetBackup Virtual Appliance 为数据中心提供介质服务器解决方案。它可以扩展实例数量和存储容量，以满足数据中心不断增长的数据保护需求。您可以使用 NetBackup 将数据从 NetBackup Virtual Appliance 复制到其他站点以进行灾难恢复。

NetBackup Virtual Appliance 为 NetBackup 配置和备份环境的日常管理提供了简化的解决方案。目标是提供一种解决方案，无需提供专门人员来管理其备份环境。

NetBackup Virtual Appliance 支持的功能

基础功能

该设备软件支持所有基本功能。

  • NetBackup Virtual Appliance Shell 菜单。

    shell 菜单是用于设备配置和管理的命令行界面。

  • 预安装了 NetBackup。

    NetBackup Enterprise Server 软件已安装并配置为与操作系统配合使用 (sysin)。此功能简化了现有 NetBackup 环境的部署和集成。

    备注：

    目前不支持在 NetBackup Virtual Appliance 上使用 NetBackup 版本 7.7 中发布的增强审核功能。不应在设备上配置或启用此功能。

  • 支持核心 NetBackup 软件代理。

    NetBackup 代理可优化关键数据库和应用程序的性能。

  • Symantec Data Center Security (SDCS) 集成。

    SDCS 代理是在您最初部署设备时安装和配置的。默认情况下，SDCS 使用基于主机的入侵防御和检测技术帮助保护设备。

  • AutoSupport。

    该设备可以监控关键组件并提供主动监控和消息传递 (sysin)。Veritas 支持人员使用此信息来解决您可能报告的任何问题。

  • 裸机恢复 (BMR) 集成。

    BMR 是 NetBackup 的服务器恢复选项。BMR 自动化并简化了服务器恢复过程。

  • 链路聚合

附加功能

根据虚拟设备类型，设备软件支持以下附加功能。

主服务器

  • 将介质服务器添加到 NetBackup 域。

    您可以将媒体服务器添加到该主服务器。主服务器管理备份、存档和恢复。

组合主服务器和媒体服务器

  • 媒体服务器重复数据删除池 (MSDP) 存储。

    MSDP 是一种嵌入式重复数据删除技术，可减少备份所需的空间量。

  • 高级磁盘存储。

    高级磁盘可以提供更快的恢复操作，但不像 MSDP 那样对空间进行优化。

    备注：

    AdvancedDisk 存储不支持自动映像复制 (sysin)。要复制 AdvancedDisk 存储上的数据，可以先将数据复制到 MSDP，然后再使用 MSDP 进行复制。

  • 检查点创建和回滚。

    检查点使您能够将设备恢复到特定状态。该状态是通过使用检查点来确定的。

  • VMware 虚拟机的备份。

    该设备支持 VMware 虚拟机的直接备份。该设备无需单独的备份主机即可备份虚拟机。

  • MSDP 云。

    您可以为 MSDP 云应用程序配置设备。

  • 即时访问。

    即时访问功能允许您从 NetBackup 备份映像创建即时访问 VM。虚拟机几乎立即可用，实现了接近于零的恢复时间目标。

媒体服务器

  • 媒体服务器重复数据删除池 (MSDP) 存储。

    MSDP 是一种嵌入式重复数据删除技术，可减少备份所需的空间量。

  • 高级磁盘存储。

    高级磁盘可以提供更快的恢复操作，但不像 MSDP 那样对空间进行优化。

    备注：

    AdvancedDisk 存储不支持自动映像复制 (sysin)。要复制 AdvancedDisk 存储上的数据，可以先将数据复制到 MSDP，然后再使用 MSDP 进行复制。

  • Copilot (Standard Shares only)。

    Copilot 使 Oracle 数据库管理员能够与 Veritas 设备管理员合作，执行简化的 Oracle 数据库备份和恢复流程。

  • 检查点创建和回滚。

    检查点使您能够将设备恢复到特定状态。该状态是通过使用检查点来确定的。

  • 恢复出厂设置。

    恢复出厂设置使您可以将设备恢复到原始出厂状态。

  • VMware 虚拟机的备份。

    该设备支持 VMware 虚拟机的直接备份。该设备无需单独的备份主机即可备份虚拟机。

  • MSDP 云。

    您可以为 MSDP 云应用程序配置设备。

  • 即时访问。

    即时访问功能允许您从 NetBackup 备份映像创建即时访问 VM。虚拟机几乎立即可用，实现了接近于零的恢复时间目标。
