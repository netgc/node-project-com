跨整个基础架构快速可靠地进行灾难恢复，可能并不容易，且成本高昂。Veritas System Recovery 能够主动保护笔记本电脑、服务器以及虚拟机 (sysin)，而不影响员工的工作效率或 IT 服务。这个强大的统一解决方案支持 IT 管理员随时随地迅速精准恢复所需内容，最大限度缩短停机时间。

确保关键业务数据的完整性

我们的一体化解决方案具有无与伦比的卓越性能，轻松实现数据保护。

运行简单化

采用单一界面保护企业环境中的笔记本电脑、服务器和虚拟机。

高效保护

最大限度减少存储空间占用，快速执行自动恢复，实现云韧性。

可靠恢复

确保可恢复至任意硬件环境，并自动复制备份至云。

本地灾难恢复

几分钟就可恢复正常生产 (sysin)，而无需数小时或数天。

  • 利用 Veritas 获专利的技术，从本地或异地目标位置快速恢复整个物理和虚拟系统，甚至可以恢复到裸机、不同硬件、远程位置或虚拟环境
  • 在还原文件和文件夹的同时，可搜索多个恢复点
  • 通过热映像技术克服存储控制器与硬件抽象层不兼容带来的障碍，即时还原到不同硬件平台
  • 创建一体化备份和恢复 USB 设备，快速启动和恢复任何系统

异地灾难恢复

自动备份到其他站点或云存储以进行保护。

  • 获专利的 LightsOut Restore 技术使管理员无需亲自到场，即可轻松远程恢复系统。
  • 可重复使用恢复点再恢复两个站点或设备。
  • 支持 AWS、Microsoft Azure、USB、NAS/SAN 和 FTP 存储。
  • 后台进程有助于减少完成恢复所需的资源

灵活的云存储

轻松与 Amazon S3 和 Microsoft Azure 集成。

  • 在创建时加密恢复点，然后再发送至云存储
  • 利用云存储作为辅助存储地点和设备的补充
  • 通过 Internet 使用 Amazon/Azure 账户、密钥和区段详细信息轻松恢复

不同硬件间还原

灵活替换所选的硬件。

  • 可裸机还原至其他硬件，不必苛求采用相同的存储、系统和组件。
  • 无缝处理还原流程中的驱动程序和组件更新
  • 迁移至不同硬件前无需准备

集中式管理和监控

通过单一管理面板实现全面可视化。

  • 通过一个综合性主页视图，您可以集中监控所有受管系统的当前保护状态

  • 直观的过滤选项可快速找到并隔离问题区域和安全漏洞

  • 持续监控环境中所有客户端的备份、许可证和版本状态
