基于 ML 的统一平台中的自动驾驶式 IT 运维管理

VMware Aria Operations（以前称为 VMware vRealize® Operations™）可自动化和简化 IT 管理，从物理、虚拟和云基础架构（包括虚拟机 (VM) 和容器）到这些基础架构支持的应用提供完整体系可见性 (sysin)。它可提供持续的性能优化、高效容量和成本管理、主动规划、智能修复和集成式合规性。它可以部署在本地，也可以作为服务使用。

  • 最大限度提高云环境运维的投资回报
    了解企业在当今的混合云和多云环境中部署 VMware Aria (vRealize Operations) 时可能实现的潜在投资回报 (ROI)、缩短的计划外停机以及可能实现的其他优势 (sysin)。

  • 加快 VMware Cloud on AWS 迁移之旅
    了解 VMware Aria (vRealize Operations) 如何简化从迁移评估和规划到在生产环境中实施混合云的混合云管理过程。

  • 跨多云环境统一可见性
    VMware Aria (vRealize Operations) 可在本地或作为服务交付 (sysin)，可跨私有云、混合云和多云部署满足现代 IT 战略的需求，包括部署基于虚拟机的工作负载和容器化工作负载。

  • 提高运维效率
    通过添加 VMware Aria Operations for Integration (vRealize True Visibility Suite)，为您的混合云提供数据深度使用情境。监控异构环境并做出明智的管理决策。

应用场景

  • 智能修复
    借助切实可行的洞察信息，更快地预测、预防和故障排除问题 (sysin)。借助从应用到基础架构的统一可见性，将指标和日志关联起来。此外，通过与 VMware Cloud Foundation、vSphere 7 with Tanzu、vSAN、VMware Cloud on AWS 和多个公有云（AWS、Microsoft Azure 和 Google Cloud Platform 等）进行原生集成，精简和集中管理 IT 运维。

  • 集成式合规性
    利用集成式合规性策略和偏差自动修复功能降低风险并针对 VMware Cloud 实施 IT 法规标准。利用六个即时可用的合规性模板（包括用于 PCI、HIPAA 或 SOX 的模板）确保您的环境符合通用法规标准，或者也可以创建您自己的自定义模板。

  • 持续性能优化
    在运维和业务目标的驱动下，通过实时预测性分析功能和人工智能驱动的操作来自动均衡工作负载、提高整合率、优化工作负载并调整其规模，同时主动避免争用 (sysin)，从而确保以最低成本获得所需应用性能。对单独的操作系统应用基于主机的安置策略或节省软件许可成本。

  • 高效的容量和成本管理
    通过基于 ML 的实时容量和成本分析，降低成本并提高效率。使用实时的、前瞻性容量分析引擎，提供优质的整合以及主动预测和规划。VMware Aria Operations (vRealize Operations) 直接关联容量和成本分析，以直观显示成本节约机会并加快决策制定速度。

比较各个版本

  • Standard

    具有基本管理功能的 VMware vSphere 统一运维平台。

    • Workload placement and balancing
    • Capacity management
    • Access to 35+ management packs
    • Per VM/Per CPU licensing

  • Advanced

    适用于 VMware SDDC、VMware Cloud on AWS、AVS、GCVE 和基于 VCPP 的混合云的运维管理平台。

    • All Standard edition features
    • Capacity and cost management
    • Customizable dashboards
    • Access to 70+ management packs
    • Per CPU/Per OSI (Operating System Instance) licensing

  • Enterprise

    针对 VMware SDDC、VMware Cloud on AWS、混合云、Azure、AWS、Google Cloud Platform、容器和应用监控的完全自动驾驶式运维管理和应用监控平台。

    • All Advanced edition features
    • Application monitoring
    • Native public cloud monitoring for AWS, Azure, and GCP
    • Access to 90+ management packs
    • Per CPU/Per OSI (Operating System Instance) licensing
