云管理套包

VMware Aria Suite（以前称为 vRealize Suite）和 vCloud Suite

VMware Aria Suite (vRealize Suite) 和 vCloud Suite 可为 VMware Cloud 及其他平台提供自助服务使用层、自动化框架和自动驾驶式后续运维。

笔者注：vCloud Suite = Aria Suite + vSphere

基本云管理

  • 什么是 VMware Aria Suite (vRealize Suite)？

    VMware Aria Suite (vRealize Suite) 是一种云管理解决方案 (sysin)。它集成了 VMware Aria (vRealize Cloud Management) 产品，可在本地部署环境中提供自动化、运维和日志分析。

  • 什么是 vCloud Suite？

    VMware vCloud Suite 是一种企业级云基础架构和管理解决方案 (sysin)。它将 vRealize Suite 与业界领先的计算虚拟化平台 vSphere 相结合。

  • VMware Aria Universal (vRealize Cloud Universal)

    灵活的 VMware 多云管理解决方案

  • 管理私有云

    了解如何使用 VMware Aria Suite (vRealize Suite) 和 VMware Cloud Foundation 功能管理私有云 (sysin)，以及如何审查分析人员的意见，并计算自己的投资回报。

主要功能

  • 基础架构的 DevOps

    为基于 DevOps 的基础架构交付提供基础架构即代码、基础架构流水线、GitOps、版本自动化和流水线即代码。

  • 自动驾驶式运维

    跨云环境从应用到基础架构 (sysin)，不断优化性能、容量、成本以及应用感知型智能修复和集成合规性。

  • 现代基础架构自动化

    通过策略审批、借助 API 进行置备、声明性状态执行、工作流编排、后期自动化和自动修复，在整个生命周期内实现 IT 服务自动化管理。

  • 数据中心虚拟化（仅限 vCloud Suite）

    在向 vRealize Suite 中添加 vSphere 时，通过以应用为中心的管理和原生安全性提高 VI 管理员的工作效率。加快 AI/ML、数据库和分析以及对时间要求严格的应用领域的创新 (sysin)。

产品组件

VMware Aria Suite (vRealize Suite) 中包含的产品：

  • VMware Aria Automation 8.18.1 - 多云基础架构自动化平台

    通过自助服务自动化提高敏捷性、生产力和效率。

  • VMware Aria Operations for Logs 8.18.7 - 集中式日志管理

    利用集中式日志管理、可见性和分析功能改进故障排除和安全性。

  • VMware Aria Operations 8.18.7 - 多云 IT 运维管理

    利用自动驾驶式运维功能优化、计划和扩展 SDDC 及云部署。

  • VMware Aria Suite Lifecycle 8.18 Patch 8 - 应用生命周期管理

    加快部署和升级、增强环境稳定性 (sysin)，并提高终端用户工作效率。

版本选项

vRealize Suite 和 vCloud Suite 在本地提供三个版本。也可作为 vCloud Suite 与 vSphere Enterprise Plus 一起提供。

  • Standard

    支持“自动驾驶式运维”应用场景，可通过预测性分析和智能警报提高应用性能和可用性。

  • Advanced

    通过混合云自动化与监管实现 Standard 应用场景及基础架构置备和管理。

  • Enterprise

    通过多云自动化与监管实现 Advanced 应用场景及应用置备和管理。
