2025-04-09，新增 Cisco (思科) 定制版（本站用户需要更新），特性相同。

2025-03-04，ESXi 6.7U3v (ESXi670-202503001) 发布，例行更新。

2024-10-30，新增 Lenovo (联想)、Inspur (浪潮) OEM 定制版，特性相同。

2024-09-01，更新 OEM BIOS 2.7，现已支持 Windows Server 2025。

除了需要兼容 RTL 网卡有 ESXi 6.7 系列定制版：VMware ESXi 6.7U3v macOS Unlocker & OEM BIOS 2.7 集成 Realtek 网卡驱动和 NVMe 驱动 (集成驱动版)。十多年前的其他机型绝大多数可以非官方支持 ESXi 7.0 甚至 8.0。Dell PowerEdge 11G 服务器因其配备的 RAID 控制器 PERC 6 和 7 仅存在 vmklinux 兼容驱动，无法使用 7.0 及更新版本，特定制此版本。

另外一些 HP Gen7 和 Gen6 的产品，由于历史悠久，如果不更换部件，部分配置机型无法支持到 ESXi 7.0 及更新版本，此次更新同时提供 HPE 定制版。

通用特性概览

前三个特性不再展开描述，可参看 ESXi 7.0 或 8.0 页面的相关说明。

  • macOS Unlocker：来自 GitHub 的 Unlocker 3，默认支持 Mojave，理论支持 Big Sur 及以上
  • OEM BIOS 2.7：使用上游最流行的 OEM BIOS/EFI64，现已支持 Windows Server 2025
  • LegacyCPU support，允许在不受官方支持的旧款 CPU 上安装 ESXi 6.7
  • UI fix：修复 VMware Host Client 无法将现有虚拟磁盘 (VMDK) 附加到虚拟机的问题
  • 非官方支持 Dell PowerEdge 11G 服务器以及 HP Gen6 和 Gen7
