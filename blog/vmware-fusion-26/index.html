VMware Fusion 26H1 新增功能

VMware Fusion Pro 26H1u1 | 03 SEP 2026 | Build 25689522

VMware Fusion Pro 26H1u1 包含安全性修复和错误修复。

  • 自动 Secure Boot 平台密钥修复：引入新功能，以简化虚拟机平台密钥（PK）修复流程，并解决 Microsoft Secure Boot 证书过期问题。

    • ESX 中的静默平台密钥更新：在客户机重启期间，此选项会自动更新启用了 Secure Boot 且未启用 vTPM 的虚拟机中的无效 VMW.NULLPK。
    • Capsule 平台密钥更新：在客户机重启期间 (sysin)，此选项不会中断基于 TPM 的应用程序，并提供一种安全机制，可安全地更新启用了 Secure Boot 和 vTPM 的 Windows 虚拟机中的无效 VMW.NULLPK。①

  • 此版本解决了 CVE-2026-59346 和 CVE-2026-59347 漏洞。

① 用于触发 PK 更新的 Capsule PK Update 驱动程序在 VMware Tools 13.1.5 中针对大多数 Windows 版本推出。在升级到 VMware Tools 13.1.5 或更高版本之前，为允许安装 PK 更新驱动程序，必须在客户机操作系统上安装 2026 年 7 月或更高版本的 Windows 累积更新。
