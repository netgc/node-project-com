VMware Cloud Foundation Installer (VCF Installer)

VCF Installer 概述

VCF Installer 是一个专用虚拟机，用于帮助用户规划、配置与部署 VCF 及 vSphere Foundation 组件。

使用 VCF Installer 可以执行以下操作：

  • 下载部署 VMware Cloud Foundation 或 VMware vSphere Foundation 所需的二进制文件。
  • 规划所需的 VCF 或 VMware vSphere Foundation 部署规模与配置。
  • 部署并配置新的 VCF 或 VMware vSphere Foundation 平台。还可以为新的 VCF Fleet 复用现有的 VCF Operations 与 VCF Automation 实例。
  • 使用现有虚拟化基础架构并将其整合（Converge）到 VCF 或 vSphere Foundation 平台中。
  • 通过部署额外的 VCF Instance 来扩展现有 VCF Fleet。
  • 部署 VCF 管理服务与许可证服务器 (sysin)，以完成 vSphere Foundation 升级至 9.1。
  • 查看历史部署过程详情、下载密码以及下载 VCF 或 vSphere Foundation 部署的 JSON 配置规范。

VCF Installer 支持主版本、次版本以及维护版本，但不支持 Patch 或 Express Patch 发布。完成 VCF Installer 工作流后，可以手动应用补丁。

VCF 9 部署路径简介

VMware Cloud Foundation 9（VCF 9）的一项重要工程目标是改进部署体验。VMware 不仅进一步简化了全新 VCF 实例的部署流程，还扩展支持更多类型的部署拓扑和用例。最终结果是为 vSphere 用户提供了一套更加简洁、高效、可复用的部署工作流，从而更轻松地迈向 VCF。

VCF 9 提供了多种现代化基础架构的部署路径：

  • 部署全新的 VCF 实例
  • 扩展现有的 VCF 资源池（Fleet）
  • 将现有的 vCenter 部署并入 VCF（融合）
  • 将 vCenter 部署导入 VCF

首先了解 VCF 9 的部署和扩展方式

VMware Cloud Foundation 9 是一次重要版本更新，新增了大量关键功能，并为私有云管理员带来了更集成的体验。

VCF 9 引入了新的 VMware Cloud Foundation Installer（VCF Installer）设备，提供了更灵活的部署工作流 (sysin)，以满足更广泛的用例需求：

  • 可使用 VCF Installer 部署全新的 VCF 实例，作为一个新 Fleet 的组成部分。

或

  • 客户可选择将额外的 VCF 实例部署到现有的 VCF Fleet 中，适用于多个环境。

每个 VCF 实例均基于 vSphere 和 vCenter Server、NSX、VCF Operations 和 VCF Automation 进行部署。配置 vSAN 后可实现完整的 SDDC 堆栈。

VCF Installer 还内置了将现有 vCenter 部署融合为 VCF 管理集群的工作流。在这种情形中，现有 vCenter 环境是指非 VCF 部署。执行融合操作时，VCF Installer 将部署到与现有 vCenter Server 设备相同的集群中 (sysin)。支持配置为 vSAN 的集群或配置了外部存储的集群。

完成融合后，该环境将成为一个完整可用的 VCF 实例，并可作为 VCF 进行管理、扩展和生命周期管理。

VCF Installer 的功能不止于此，还支持融合现有的 VCF Operations 实例和/或 VCF Automation 实例。VCF Installer 提供了更轻量、快速、可重复的工作流，加速用户迈向 VCF。

更详细地了解 VCF Installer 设备

VCF Installer 取代了此前版本中使用的 Cloud Builder 设备，提供了一套更灵活的选项，进一步简化了端到端私有云环境的部署。

它采用图形化工作流，无需再使用部署参数工作簿（Excel 表格）。VCF Installer 还内置了导入或融合现有 vCenter、VCF Operations 和 VCF Automation 实例的选项，无需使用 VCF 导入脚本。

此前的 Cloud Foundation 版本需要将 Aria Operations 和 Aria Automation 作为二次操作单独安装并管理生命周期。而从 VCF 9 起，VCF Installer 可直接部署包含计算、存储、网络、运维和自服务自动化在内的完整 VCF 堆栈，由 VCF Operations 管理整个堆栈生命周期。

VCF Installer 是如何工作的？

这个全新且非常轻量的 VCF Installer 设备内置了增强的部署工作流和大量新的配置选项。

用户可通过连接 Broadcom 支持门户下载软件二进制文件，方式是连接在线仓库（online depot）。与 Cloud Builder 不同，VCF Installer 本身并不包含软件二进制文件。

客户还可配置私有离线仓库（offline depot），供多个 VCF 实例共享使用。通过离线仓库，软件包只需下载一次，非常适合同时管理多个 VCF 实例的场景 (sysin)。

下载完成后，该设备可用于部署 VMware Cloud Foundation（VCF）或 VMware vSphere Foundation（VVF）。部署可以通过内置部署向导操作，也可以生成可复用的 JSON 配置文件，在 UI 中上传、查看和验证。JSON 配置也可在向导中上传并进行编辑。

VCF 实例既可以部署为新的 VCF Fleet，也可以部署到已有的 Fleet 中。VCF Fleet 可包含多个 VCF 实例，共享使用同一套 VCF Operations 和 VCF Automation 实例。

VCF Installer 用于初始配置管理集群，部署方式有两种：

  • 部署全新组件：vCenter Server、NSX、VCF Operations 和 VCF Automation 的虚拟设备。
  • 重用现有设备：vCenter Server、VCF Operations 和 VCF Automation。

选择融合现有 vCenter Server 时，VCF Installer 会将现有 vSphere/vSAN 集群转换为 VCF 管理集群，并在此过程中部署 NSX。

如果选择重用现有 VCF Operations 实例，建议将该实例所在的 vCenter Server 作为首个管理集群的 vCenter。

新的 VCF Operations、VCF Automation 和 NSX 实例可采用简单模型（单节点）或高可用模型（多节点）部署。

部署成功后，VCF Installer 会提供链接，打开 VCF Operations 控制台用于管理。

详细对比两种部署模型

  • 简单模型（Simple Model）：至少需要 7 个虚拟设备，包括 vCenter Server、SDDC Manager、NSX Manager 各一台，VCF Operations 包括 Operations Manager、Fleet Management 和 Collector 各一台，以及一台 VCF Automation 设备。若选择启用 Supervisor，还会部署一个 VKS 设备。部署完成后，可进一步配置日志、NSX Edge 安全连接、VIDB 等组件。

  • 高可用模型（High Availability Model）：推荐用于生产环境，至少部署 13 个设备，包括 3 台 NSX Manager、3 台 VCF Operations、3 台 VCF Automation，以及日志与 VKS 各 3 台。3 台节点实现硬件故障下的高可用性 (sysin)，便于生命周期管理、补丁和升级操作。

此外，还支持为部分组件配置 NSX 负载均衡器设备（未在图中展示）。

部署完成后，用户可以随时扩展其他组件。VCF Operations for Networks、HCX 及其他 VCF 高级服务（Add-ons）也可在部署后进行配置。

如何运维 VCF 9 环境？

从 VCF 9 起，私有云的运维由 VCF Operations 控制台统一完成。

VCF Operations 为云管理员提供了统一、功能丰富的运维体验，涵盖计算、存储、网络、Fleet 管理和生命周期管理。
