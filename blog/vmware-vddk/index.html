产品简介

虚拟磁盘开发工具包（Virtual Disk Development Kit，VDDK）是一组库和实用程序，使软件开发人员能够创建访问和操作虚拟磁盘的应用程序。这些虚拟磁盘用于 vSphere、Workstation 和 Fusion 等产品的存储。对于存储和备份应用程序的开发人员来说，VDDK 是一个非常有价值的工具。

VDDK 提供用于备份和恢复、克隆以及对虚拟磁盘执行其他操作的 API。借助 VDDK，开发人员可以创建用于执行虚拟机备份和恢复操作的应用程序，也可以创建用于生成虚拟磁盘克隆或快照的应用程序。VDDK 还包含用于在不同格式之间转换虚拟磁盘，以及从头创建虚拟磁盘的实用程序。

Q&A

问：你们一定对发布 VMware Virtual Disk Development Kit（虚拟磁盘开发工具包）感到非常兴奋。能告诉我们为什么开发人员应该关注它吗？

答：是的。借助 VMware Virtual Disk Development Kit，我们正在为合作伙伴打造一个全新的生态系统，使他们能够开发与 VMware 虚拟磁盘集成的解决方案。VDDK 是一个开放的 SDK，开发人员可以利用它来构建用于创建和访问 VMware 虚拟磁盘存储的前沿应用程序。

问：使用 VMware Virtual Disk Development Kit 有哪些典型的应用场景？

答：Virtual Disk Development Kit 可以方便地访问 VMware 虚拟磁盘存储。

这为应用软件厂商带来了广泛的应用场景，包括：

  • 创建虚拟机磁盘文件，用于存储物理机镜像的备份
  • 提供对虚拟磁盘的读取权限，从而实现对虚拟机进行离线、集中式的防病毒扫描
  • 提供对虚拟磁盘的写入权限，从而实现对虚拟机进行离线、集中式的补丁更新
  • 提供对虚拟磁盘的读取权限，从而实现对虚拟机进行离线的软件包分析

平台产品兼容性

为了支持 vSphere 的新版本，在大多数情况下，您应当使用与之对应的新版本 VDDK 对软件进行更新并重新编译。这是因为 VDDK 会持续更新，以支持 vSphere 中的新功能。从 5.0 版本开始，VDDK 的版本号与 vSphere 的版本号保持一致。

💡 笔者 (sysin) 注：VDDK 是向下兼容的，比如您获得了 VDDK 8.0.3，就可以支持 vSphere 8.0U3 及之前的所有旧版本，比如 vSphere 7.0 和 6.x。

自 2008 年推出以来，VDDK 一直向后兼容 VMware Workstation、ESXi 和 vCenter Server 等虚拟化平台产品。VMware Fusion 从未获得支持。

VDDK 组件的再分发

在使用 VDDK 开发能够运行于 VMware 平台产品上的软件应用程序之后，您可能需要对已经编译并集成到软件中的库组件进行重新打包。

要获得 VDDK 再分发资格，您必须加入 VMware TAP（Technology Alliance Partner，技术联盟合作伙伴）计划，并且级别达到 Select 或更高级别，同时还需要签署再分发协议。

如需申请 VDDK 再分发协议，请联系您的 VMware 联盟经理（Alliance Manager）。VMware 希望了解以下信息：

  • 您如何使用 VDDK；
  • 您计划在哪些产品中再分发 VDDK；
  • 您的公司名称；
  • 您的联系方式。

下载地址

Broadcom 撤下 VDDK 的公共访问权限

大约在 2026 年 8 月 25 日前后，Broadcom 的公共 VDDK 下载页面开始返回错误。所有版本、所有发布分支，都从标准公共开发者门户中消失了。没有博客文章，没有发布说明，没有向已注册开发者发送电子邮件——它就是突然无法访问了。

官方下载地址：https://developer.broadcom.com/sdks/vmware-virtual-disk-development-kit-vddk/latest/

原来的公共 VDDK 下载页面，如今返回 404 错误，而不是提供 SDK。

当受影响的用户联系 Broadcom 后，Broadcom Customer Care 给出了以下回复：

“To ensure the highest standard of security, reliability, and product features, the Virtual Disk Development Kit (VDDK) is no longer available for use or download. Broadcom continues to actively maintain a variety of APIs and SDKs to enable authorized technology alliance partners to build backup and recovery software solutions…”

“为了确保最高标准的安全性、可靠性和产品功能，Virtual Disk Development Kit（VDDK）现已不再提供使用或下载。Broadcom 将继续积极维护各种 API 和 SDK，以支持获得授权的技术联盟合作伙伴构建备份和恢复软件解决方案……”

—— Broadcom Customer Care 向受影响用户提供的官方回复

从字里行间来看，未来的模式将是受控访问：VDDK 显然仍在维护和分发，但只提供给拥有经过验证的客户权益（customer entitlements）或官方 Technology Alliance Partner（技术联盟合作伙伴）身份的组织。生态系统自 VDDK 早期以来一直依赖的那种“任何拥有免费开发者账号的人都可以自行下载”的模式，目前看来已经结束了——至少暂时如此。

简言之 Broadcom 不允许公开 VDDK 下载。
