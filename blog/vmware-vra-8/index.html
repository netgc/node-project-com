概述

VMware vRealize Automation 是一个支持自助式多云环境的现代基础架构自动化平台。借助 vRealize Automation，客户可以通过自助式自动化提高敏捷性、工作效率和效益，具体方法为：降低其 IT 环境的复杂性、精简 IT 流程并提供一个 DevOps 就绪型自动化平台。

易于使用的混合云基础架构自动化平台。

对混合和/或多云环境进行管理以支持 IT 运维、业务运营、DevOps、业务线和开发人员快速变化的需求，这项任务具有挑战性。基础架构和应用调配是半自动化的，有多个工具和脚本，这就导致效益和工作效率低下、不一致性以及安全和合规性风险。借助 vRealize Automation，用户可以在需要时获得所需的服务 (sysin)，DevOps 团队可以管理发布自动化流程，同时 IT 部门可以维持安全性和有效监管。

优势

  • 简单且易于设置、配置和管理

    在整个生命周期内轻松快速地设置和管理安全的混合云环境

  • DevOps 就绪型

    高度自动化的 DevOps 平台，具有基础架构即代码 (IaC) 并与大量 DevOps 和开发人员工具集成

  • 高可用性和可靠性

    在运行应用的整个生命周期内实现一致的自动化，并适应环境中的变化

  • 安全且合规

    与多云环境中的自助服务和监管保持一致的编排。

  • 缩短销售就绪时间

    通过灵活性和发布管道可见性加速软件交付

  • 任何云上的任何应用

    跨混合或多云环境运行任何虚拟机或基于容器的应用工作负载。

功能特性

  • 跨混合和多云环境保持一致的现代编排

    跨 VMware Cloud Foundation 本地部署、VMware Cloud on AWS 和原生公有云实现一致的现代基础架构自动化和管理。

  • 自助调配

    统一且一致的服务目录允许用户请求和调配基础架构和应用资源

  • 精细监管

    灵活的防护栏，包括跨所有云计算环境的基于角色的策略 (sysin)，可维护适当的安全性和合规性

  • 高级蓝图

    使用具有拖放界面的可视画布或整体以代码的形式对基础架构和应用进行建模

  • 不限云类型

    底层基础架构的抽象化允许用户设计从期望的终端抽象化出的每个服务/应用程序的蓝图

  • 用代码管理一切内容

    通过 YAML、GIT 集成和 API 优先的方法，一切内容都可以定义为代码，包括策略和蓝图

  • 生命周期管理

    在调配应用的整个生命周期中对其进行管理，包括调整大小、回收和停止使用

  • 可延展平台

    通过市场与大量通用工具和其他第三方工具集成 (VMware Solutions Exchange)

vRealize Automation SaltStack Config 8.7.0（内部版本 19359172）召回通知：

由于重大部署问题，vRealize Automation SaltStack Config 8.7.0（内部版本 19359172）已被召回。此次召回被认为有必要将 vRealize Automation 和 SaltStack Config 客户的系统停机潜在风险降至最低。

以下客户受到影响：

  • 使用 8.7.0 之前的 SaltStack Config 部署 vRealize Automation 的客户会发现，对 SaltStack Config 的 vRealize Lifecycle Manager (vRSLCM) 升级会导致失败。
  • 在新的 vRealize Automation SaltStack Config 8.7.0 安装中，运行 Salt 3004.1 的 Minion 无法连接到运行版本 3004 或更早版本的 Salt Master。
  • SaltStack Config 部署 8.6.2 和 8.7.0（重新发布之前）将遇到一个问题，即 master 无法定期更新其身份验证令牌。

注意：不使用 SaltStack Config 的 vRealize Automation 8.7.0 客户不受此问题的影响。

使用 vRSLCM 升级到 SaltStack Config 8.7.0 的客户可能会发现他们的系统不再响应，这意味着 SaltStack Config 无法向 Salt Minion 发出命令或接收来自 Salt Minion 的入站消息。

客户会注意到他们可以在 SaltStack Config 中接受 Salt Master 上的密钥，但 master.pub/minion_master.pub 文件永远不会下载到 minion 上的 /etc/salt/pki/minion/ 中。

请放心，我们团队的首要任务是尽快解决这些问题并为我们的客户恢复功能。感谢您的耐心和理解，因为我们日以继夜地寻找解决方案。一旦这些问题得到解决，我们将发布 SaltStack Config 8.7.0 的新版本。

解决办法：不要升级到 vRealize Automation SaltStack Config 8.7。如果您在此召回通知之前已升级，请回滚到 vRealize Automation Config 8.6.2。最后，在升级 Salt Minion 之前将您的 Salt Master 升级到最新版本。有关详细信息，请参阅 KB 88101。
