使用 vRealize Suite Lifecycle Manager 管理 vRealize Suite

vRealize Suite Lifecycle Manager 针对 vRealize Suite 产品提供完整的生命周期和内容管理功能。它通过自动执行部署、升级和配置来帮助客户缩短价值实现时间 (sysin)，同时将 DevOps 原则应用到 vRealize Suite 内容管理中。

优势

  • 缩短价值实现时间

    通过自动执行预先检查和验证，简化部署和升级流程。

  • 应用 DevOps 原则

    支持自动管理 CMP 内容，以及通过预先构建的内容管道轻松进行团队协作。

  • 最大限度减少日常管理工作量

    利用跨 vRealize 产品组合的运行状况监控，自动进行配置管理和偏差管理。

  • 实施最佳实践

    按照 VMware 推荐的参考体系结构和经验证的设计进行实施。

功能特性

  • 快速安装

    简单且灵活的部署模式 (sysin)，支持基于产品和解决方案的安装。自动化的环境复制和验证流程。

  • 轻松的日常管理

    利用运行状况监控功能自动进行配置管理和偏差管理。

  • 一键式升级

    利用环境快照功能简化升级和修补流程。

  • DevOps for CMP

    即时可用的管道可跨多个用户和不同环境自动执行 vRealize Suite 内容的捕获、版本控制、测试和部署。

  • 产品内电子市场

    与 VMware Solution Exchange 电子市场整合，可轻松访问和使用由 VMware 和生态系统合作伙伴提供的精选内容以及即时可用的构造块。
