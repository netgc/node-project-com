VMware vSAN

存储虚拟化软件
vSAN

利用企业级存储虚拟化软件 VMware vSAN 降低存储成本和复杂性，该软件提供了通往超融合基础架构 (HCI) 和多云的最简单途径。

vSAN 概述

VMware® vSAN™ 将集群中所有 ESX 主机的本地或直连容量设备聚合起来，创建一个在 vSAN 集群中所有 ESX 主机之间共享的单一存储池。

您可以使用需要共享存储的 vSphere 功能，如 vSphere HA、vSphere vMotion 和 vSphere DRS，而无需外部共享存储。

  • 跨工作负载的性能

    vSAN 提供高吞吐量和低延迟的存储能力 (sysin)。为获得最佳性能，您可以将 vSAN Express Storage Architecture™（vSAN ESA）与高性能、基于 NVMe 的 TLC 闪存设备一起使用。

  • 面向各种规模部署的敏捷扩展

    vSAN 提供灵活的扩展方式，从小至两个节点（加见证人）的集群，到最多 64 个节点的集群。无论是通过向集群添加节点进行横向扩展、通过向节点添加磁盘进行纵向扩展，还是通过分离式架构独立扩展计算和存储资源，vSAN 都能让您自定义性能与容量，以优化存储资源并降低成本。

  • 统一运维与生命周期管理

    vSAN 在从边缘到云的环境中提供一致的运维体验，通过单一 UI 实现对计算和存储的完整可视性及生命周期管理。

  • 存储容量与效率

    通过优化的压缩方式提升存储效率。单层架构选项消除了缓存层的需求 (sysin)，进一步提高存储效率。vSAN 允许您使用 RAID 5 或 RAID 6 以高效率存储数据，并提供接近 RAID 1 的性能。

  • 内置文件服务

    vSAN 支持通过单一工作流来配置文件共享，并为块存储和文件存储提供统一的存储控制平面。vSAN 文件服务可集成 Active Directory，并支持 Kerberos 网络身份验证及多数主流协议。vSAN 文件服务可用于双节点部署和跨站集群部署。

  • 面向虚拟机的基于策略管理

    您可以通过基于策略的管理执行一致的、以虚拟机为中心的运维。在 vSAN ESA 中，按 VM 设置策略可提升管理灵活性，实现压缩策略或基于每台虚拟机定制数据服务。

新增功能

VMware vSAN 8.0 Update 3 | 2024 年 6 月 25 日 | ISO 内部版本 24022510

vSAN 8.0 Update 3 引入了以下新功能和增强功能：

许可

  • 基于容量的许可。VMware Cloud Foundation 5.2 中基于订阅的许可授权客户使用以下容量：每个 VCF 核心许可证 1 太比字节 (TiB) 的 vSAN 容量，以及通过基于容量的附加模块许可证提供的额外容量。

灵活的拓扑

  • 在 vSAN ESA 上支持延伸集群。在 VMware Cloud Foundation 5.2 中，vSAN Express Storage Architecture 完全支持延伸集群拓扑。这样，VCF 便能够配置工作负载和管理域 (sysin)，从而为工作负载和数据提供站点级别的恢复能力。

  • vSAN Max 作为主体存储。VCF 5.2 支持将 vSAN Max 作为主要的集中式共享存储。这样，除了聚合式 vSAN HCI 集群外，VCF 还可以为工作负载域配置解聚式 vSAN Max 集群以提高灵活性。

  • vSAN 文件服务最多可具有 250 个文件共享。vSAN 8.0 Update 3 通过将 vSAN ESA 上每个集群的共享数量增加到 250 个，提高了 VMware Cloud Foundation 中本机文件服务的可扩展性。

数据保护

  • 利用 ESA 可扩展快照实现 vSAN 本地数据保护。通过 vSAN data protection，您可以使用直观的新 UI 捕获本地快照，并将其存储在 vSAN 数据存储中。使用保护组可轻松地为虚拟机定义虚拟机成员资格、快照调度、保留时间和不可变条件。您可以使用这些快照恢复、还原或克隆虚拟机，以增强保护级别。

  • 与 VMware Live Cyber Recovery (VLCR) 集成，可更快速地进行勒索软件恢复。vSAN data protection 与 VMware Live Cyber Recovery (VLCR) 集成在一起 (sysin)，可捕获时间点快照以实施云端勒索软件防护，而且 VLCR 提供了一些工具，可用于保护站点外数据并在隔离恢复环境 (IRE) 中恢复虚拟机以在还原到内部部署之前对其进行分析。VLCR 使用本地快照，并且仅更新从 IRE 到生产的更改（增量），从而大幅缩短了还原时间。

提升的恢复能力

  • 拥堵修复。vSAN 8.0 Update 3 增强了 vSAN OSA 早期检测和修复各类拥堵的能力，从而防止出现集群范围的 I/O 延迟。

  • 自适应删除拥堵。vSAN 现在可为 vSAN OSA 中的仅压缩磁盘组提供自适应删除拥堵功能，从而提高 IOPS 性能并提供更可预测的应用程序响应。

增强的管理

  • 主动硬件管理。vSAN 8.0 Update 3 引入了一种从首选服务器供应商处收集关键存储设备遥测的新方法，可实现对硬件问题的预测性管理。主动硬件管理利用 OEM 供应商通过 API 集成到 vCenter 中的预测性故障监控工具（设置并配置 OEM 硬件支持管理器后），帮助您对硬件维护做出更明智的决策。

  • 为 vSAN ESA 禁用静态数据加密。在 vSAN ESA 集群上启用静态数据加密后，您可以随时将其禁用。vSAN ESA 现在支持对静态数据加密执行以下操作：启用加密、禁用加密、浅层重新加密和深度重新加密。

  • vSAN ESA 中适用于 NVMe 存储设备的可自定义警报阈值。vSAN 8.0 Update 3 允许您自定义设备耐用性的警示阈值，从而针对特定集群、主机、磁盘供应商，甚至单个设备量身定制这些阈值。

  • vSAN I/O 行程分析器集群级别视图。vSAN 8.0 Update 3 允许您同时对多个虚拟机运行性能分析。您一次最多可以选择 8 个虚拟机 (sysin)，并快速对每个选定的虚拟机执行分析。

  • 使用 Aria Operations 增强了对 vSAN Max 的感知。VMware Cloud Foundation Operations with VCF 5.2 增强了 vSAN Max 集群在其整个用户界面中的可见性。这样，Aria Operations 便能够跟踪资源利用率和运行状况。

  • Aria Operations 中的联合 vSAN 运行状况监控。最新的 Aria Operations 针对跨多个 vCenter 的集群引入了联合 vSAN 集群运行状况监控。
