Windows Admin Center 2606 发布 - 适用于所有环境的 Windows Server 远程管理工具

Windows Admin Center is your remote management tool for Windows Server running anywhere—physical, virtual, on-premises, in Azure, or in a hosted environment—at no additional cost.

Windows Admin Center 是适用于在任何地方（物理环境、虚拟环境、本地环境、Azure 或托管环境）运行的 Windows Server 的远程管理工具，且无需额外费用。

概述

使用 Windows Admin Center 重新构想服务器管理

  • 在 Azure 中管理 Windows Server

    在 Azure 门户中使用 Windows Admin Center 加强对 Windows Server 的监督，实现无缝且精细的虚拟机管理。使用熟悉的 Windows Admin Center UI 轻松执行维护任务。由于此版本的 Windows Admin Center 专为云打造，因此可获取为所有其他 Azure 服务提供可靠性的支持基础结构。

  • 简化服务器管理

    使用熟悉而现代化的工具（例如，重新构想的服务器管理器和简化的 Microsoft 管理控制台工具），从单个基于浏览器的图形用户界面管理所有服务器环境 (sysin)。随时随地管理 Windows Server 实例 - 本地环境、Azure 或任何云中。

  • 无缝运行混合环境

    使用 Windows Admin Center 中的 Azure 混合服务，将 Windows Server 的本地部署扩展到云环境 (sysin)。将 Azure 用于：

    • 备份和灾难恢复。
    • 用于进行监视、威胁防护和更新管理的集中管理
    • 用于计算、文件服务器和存储的额外容量。

新增功能

Windows Admin Center 2606 版本现已正式发布

2026 年 6 月 25 日

微软宣布，Windows Admin Center 最新版本 2606 现已正式发布！

本次更新重点围绕平台整体的可靠性、可访问性、安全性以及用户体验进行改进，依据客户反馈和开发合作伙伴报告的问题进行了优化。该版本带来了重要的质量提升，使日常管理工作更加顺畅、可靠。

2606 版本是一个仅包含管理模式（Administration Mode）的发布版本。

Windows Admin Center 2606 新特性如下。

平台更新

  • 修复了在非英语操作系统的独立服务器上安装时，错误提示“不支持高可用性安装”的问题
  • 修复了用户在网关设置（Gateway Settings）的“访问（Access）”选项卡中无法添加包含空格的允许组（Allowed Groups）的问题
  • 强化了整体安全防护能力
  • 解决了主要的可访问性问题
    • 改进了关键管理场景中的键盘导航、对话框可访问性、屏幕阅读器支持以及 ARIA 合规性
    • 常见工作流程现在更易于通过辅助技术进行操作，并有助于提升对可访问性标准的符合程度

扩展更新

  • GPU 工具现已支持 Windows Server 2025 Standard Edition（标准版）
  • 修复了 Cluster Manager 扩展低于 5.2.6 版本中存在的卷删除操作问题
  • 修复了启动计划任务后任务状态未更新的问题
  • 导入虚拟机（Import VM）
    • 在导入虚拟机流程的“审核（Review）”选项卡中新增网络摘要信息
    • 修复了导入虚拟机流程中“审核”选项卡的“存储摘要（Storage Summary）”部分未正确显示 VHD 目标位置的问题
    • 修复了导入虚拟机流程“审核”选项卡中虚拟机名称显示不正确的问题
  • 修复了在虚拟机设置中复制物理硬盘无法正常工作的问题
  • 将 Gen2 虚拟机的最大网络适配器数量从 8 个提升至 64 个（Gen1 虚拟机仍然最多支持 8 个）
  • 更新了安全（Security）工具中的安全启动（Secure Boot）逻辑与状态显示，提供更清晰的信息和后续操作建议
  • 改进了平台及以下工具的错误处理机制 (sysin)：
    • 文件与文件共享（Files & File Shares）
    • 进程（Processes）
    • 虚拟机（Virtual Machines）
    • 服务（Services）
  • 软件定义网络（SDN）
    • 虚拟网络（Virtual Networks）
      • 现在会阻止删除正在被虚拟网关使用的虚拟网络，以及阻止删除或编辑正在使用中的虚拟子网。此前，客户可能会误修改这些资源，从而导致配置部署状态失败。
      • 实施了关键缺陷修复，例如允许从虚拟子网资源中移除网络安全组（NSG）。
    • 虚拟网关（Virtual Gateway）
      • 新增主机 IP 地址输入字段，以支持 L3 Fast Path 功能中的关键修复。
      • 新增带宽分配单位设置选项，允许用户自定义带宽单位。
    • 逻辑网络（Logical Networks）
      • 修复了一项问题，使用户能够使用默认网络策略（无地址前缀）更新逻辑网络。

合作伙伴生态系统

如果没有开发合作伙伴的支持，Windows Admin Center 的管理体验将无法如此完整。他们通过 Windows Admin Center 提供硬件和固件管理能力，使管理工作更加高效便捷。

自 Windows Admin Center 上一个正式发布版本以来，已有两家合作伙伴更新了其扩展。

  • Dell OpenManage Integration 扩展已升级至 3.6.0 版本，包含以下改进：
    • 硬件告警轮询（Hardware Alert Polling）
      • 提供可配置的硬件告警轮询和严重性阈值设置，确保在所有服务器和集群中及时且一致地接收通知。
    • Windows Server 2025 的 WDAC 支持
      • 通过 Dell 提供的补充策略，在启用 Windows Defender Application Control（WDAC）的 Windows Server 2025 上支持 OMIMSWAC。
    • 自定义硬件告警配置
      • 支持在集群级别或单节点级别配置或移除 iDRAC 硬件告警，提供对告警类别、子类别及严重级别的精细控制。
    • 保修状态改进
      • 提高保修信息报告的准确性，对于无法获取节点数据的情况标记为“Unknown（未知）”。
      • 在工具提示中新增节点级保修信息 (sysin)，便于快速了解情况和诊断问题。
    • Azure 策略注册配额处理
      • 当 Azure 策略注册因配额限制失败时，提供明确提示和解决指导，帮助用户快速处理问题。
    • 增强硬件配置策略
      • 扩展 HCP/SCP（本地部署）和 Azure 注册策略的兼容性，在 AC Power Recovery 设置中将 “On” 或 “Last” 均视为合规状态。
    • BitLocker 改进
      • 在更新和集群扩展过程中，通过可靠地暂停和恢复 BitLocker 保护来提高管理稳定性。
      • 无论任务状态为失败、取消还是成功完成，均可恢复到原始保护状态。
    • 新增对 Azure Local 多云平台（APEX MC）的支持
    • 新增对 PowerEdge 17G 型号 R7725xd 和 R770AP 的支持
    • 新增通过 Remote NDIS 适配器连接 iDRAC 时的 IPv6 支持
    • 增强 HCI Configuration Profile，在全闪存配置中支持每台服务器至少使用两块存储驱动器作为 Azure Stack HCI 操作系统盘
    • AX 16G 集群现支持混合处理器代际部署，可同时运行基于 Sapphire Rapids 与 Emerald Rapids 的节点，从而提升部署灵活性
  • Fujitsu ServerView Health 扩展已更名为 FSAS Technologies ServerView Health，扩展 ID 为 fsastech.sme.serverview.health-extension，同时已升级至 Angular 15
  • Fujitsu ServerView RAID 扩展已更名为 FSAS Technologies ServerView RAID，扩展 ID 为 fsastech.sme.serverview.raid-extension，同时已升级至 Angular 15

系统要求

默认支持以下版本：

  • Windows Server 2016 中文版、英文版下载 (2026 年 10 月更新)
    • Windows Server 2016 OVF (2026 年 10 月更新) - VMware 虚拟机模板
  • Windows Server 2019 中文版、英文版下载 (2026 年 10 月更新)
    • Windows Server 2019 OVF (2026 年 10 月更新) - VMware 虚拟机模板
  • Windows Server 2022 中文版、英文版下载 (2026 年 10 月更新)
    • Windows Server 2022 OVF (2026 年 10 月更新) - VMware 虚拟机模板
  • Windows Server 2025 中文版、英文版下载 (2026 年 10 月更新)
    • Windows Server 2025 OVF (2026 年 10 月更新) - VMware 虚拟机模板

旧版系统需要额外配置。
