关于 XenServer

​

XenServer 是一个虚拟化平台，允许组织创建和管理虚拟化服务器基础架构 (sysin)。它旨在优化 Windows 和 Linux 虚拟机的交付，为数据中心虚拟化提供强大且可扩展的解决方案。

XenServer 提供实时迁移、快照和克隆功能以及资源池等功能，从而允许高效管理虚拟化工作负载。它为运行应用程序和服务提供了一个安全且高性能的环境，使其成为希望简化其服务器基础设施的企业的合适选择。

Cloud Software Group (CSG) 强调 XenServer 与 Citrix 产品的集成，从而创建全面的虚拟化和应用程序交付解决方案。我们的目标是通过集中管理和高效资源利用来提高 IT 运营的灵活性、敏捷性和成本效益。总体而言，XenServer 被定位为可靠的虚拟化解决方案，适用于为其服务器环境寻求强大且多功能平台的企业。

XenServer 8 是 XenServer 的最新版本。它是 Citrix Hypervisor 8.2 累积更新 1 的后续版本，并包含许多新功能。

为什么选择 XenServer 8

  • 您希望尝试 XenServer 的最新功能，并且可以定期更新您的主机和池。

    Citrix Hypervisor 8.2 累积更新 1 和 XenServer 8 之间的一个显著变化是，我们开始通过频繁更新机制持续提供功能和修复。

  • 您希望在环境中使用 Windows 11 VM。

    XenServer 8 提供对 Windows 11 VM 和 vTPM 的支持。

  • 您是 Citrix Virtual Apps and Desktops 用户，希望在包含许多针对您的环境优化的功能的虚拟机管理程序上运行工作负载。

在上述任何一种情况下，XenServer 8 都适合您。

XenServer 版本

XenServer 可轻松管理各种工作负载类型、各种操作系统以及复杂的存储或网络需求，即使对于最具挑战性的业务用例也是如此。

XenServer 是针对 Citrix 平台优化的虚拟机管理程序。通过各个级别的无缝集成，XenServer 利用硬件级功能来提供高清用户体验、增强的安全性并简化运营管理。
